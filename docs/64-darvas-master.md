## §1 最高权威：原著方法论骨架

### 1.1 达瓦斯的盈利模型（本系统的存在理由）

原著的盈利从来不是「赢的次数多」，而是三个因子的乘积（〔正文〕第二部分起反复出现）：

```
                 ┌────────────────────────────────────────────┐
                 │        达瓦斯盈利模型 = π × ω × τ           │
                 └────────────────────────────────────────────┘
   小止损 π      「止损位设在突破的箱体上轨下面一点点」〔问答〕
        │        每次亏损被机械地钉死在极窄区间
        ▼
   高赔率 ω      赢家不做主动止盈：「没有任何理由卖掉一支正在上涨的股票」〔正文·第10章〕
        │        止损只上移、永不下移，让利润跑过多个箱体
        ▼
   极右偏 τ      突破新高 + 放量 + 金字塔加仓 → 利润集中在极少数长持赢家
        │
        ▼
   数学性质      低胜率 × 高赔率 × 正期望，靠「输小赢大」复利
```

本系统 14 年账本对该模型的实测（1,142 笔，2005–2018）：胜率 18.6%、赔率 6.63、PF 1.51、
均笔 +1,063、t = 2.23——**模型存在但很薄**：把均笔打到 0 只需每笔少赚 1,063 元。

### 1.2 箱体：原著的定义（三日法则）与本系统实现 ✅

原著箱体定义（〔问答〕原话归纳）：

```
 价格
  ▲        上轨候选
  │          ┌──┐            「当股价连续 3 天未能触及或突破前期创下的新高点时，
  │      ────┤  │             箱体上轨才能确立」
  │  高     │  │ 3日      「只有上轨确立之后下轨才能确立，方法正好与上轨相反」
  │  │      │  │ 无新高   「新箱体的下轨是股票自己走出来的，不是人为预测出来的」
  │  ▼   ───┤  │
  │          └──┘ 3日
  │              无新低
  └──────────────────────────────► 时间
        forming ──► confirmed ──► broken_up（买点）/ broken_down（止损）
```

本系统实现（`internal/box/engine.go` 状态机）**忠实复刻**：forming（3 日无新高确认上轨）→
forming（3 日无新低确认下轨，期间创新高则箱体作废重启）→ confirmed → broken_up / broken_down。
三日法则参数化（`ConfirmDays` 默认 3）。「**上轨确立之前不定下轨**」这一时序细节与原著一致。
单测含书中案例断言（35 用例）。

### 1.4 原著三段式 vs 本系统单腿（差异的结构示意）

```
 原著（三段式，价格逐级抬高）              本系统（单腿，一次定生死）
 ─────────────────────────────           ─────────────────────────
 价格                                      价格
  ▲   腿3 加码 ●─── 止损3                    ▲        单腿 ●─── 止损在下轨下
  │      ───────                            │          ────────────────
  │   腿2 确认 ●─── 止损2                    │    （等下一个箱体？不存在——
  │      ───────                            │     两日不赚已被 time_stop 平仓）
  │   腿1 试探 ●─── 止损1                    │
  │      ─────── 箱体1  箱体2  箱体3          │      ─────── 箱体1 →（强平）
  └───────────────► 时间                    └───────────────► 时间
  赢家随箱体阶梯变大                          赢家被钉死在首仓尺寸
```

**因果颠倒（本项目 2026-11-06 复审的关键结论，`00 §4.1`）**：
当年废止加仓的理由是「量化时代不需要，一加就是顶」。但那次否决发生在 `staledays=2` 的物种上——
**2 日强平使「持有到下一个箱体」根本不可能发生，在这个前提下加仓当然无效**。
不是加仓无用才砍，是砍了才使加仓无用。

## §3 市场层：温度计与闸门

### 3.1 MA60 闸门：它是开关，不是刹车（R27）

现行 `gate.ma60.mode=stop`：指数收盘 < MA60 → 全市场停买。14 年实测结论：

```
 关闸期间信号持续累积（每月仍有数百个信号）
        │
        ▼
 指数回到 MA60 上方
        │
        ▼
 累积单在同一天一次性释放（2018-11-19 单日开 10 笔，17 笔亏损）〔R27〕
```

**A2「重开冷却」假说已判伪**（`55 §12`）：重开首波胜率 18.7% vs 常态 18.5%（p=0.56）；
表面显著的「长关闸更差」（31.3%→8.6%，p=0.0005）在**按年分层后归零**（MH 单侧 p=0.76）。
→ 长关闸事件只发生在坏年份，坏年份里所有建仓都差。**闸门不是坏开关，是坏天气的代理变量**（R29）。

### 3.2 温度计：温1–温8 与 2×2 全景（`48 §二~§四`）

| 指标 | 定义 | 判定 |
|---|---|---|
| 温1 涨跌家数比 | A/D 比，滚动 250 日 z | **作闸门是反向的**：牛态开仓净亏，猴态贡献 77% 利润 |
