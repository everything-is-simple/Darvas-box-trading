## 已知未修缺陷（挂账，不挡主线）

以下三条来自 2026-11-04 设计与实现差异审查（原文见 [归档 54](archive/54-new-baseline-audit.md) §3），**已知而未修**，
不影响回测的确定性重放，但**不能当成已解决**：

| 项 | 事实 | 何时处理 |
|---|---|---|
| 成交三步无事务 | `ledger` 写 `fill` → 扣现金 → 改持仓分三次提交，中途崩溃会留下半截状态 | 回放是确定性重放，重跑即恢复；待主线验收后单独修 |
| 生产任务错误被吞 | `pipeline.RunDaily` 对六个任务取 `r2, _`，任务失败不改变总 error | 生产运维问题，与本次验收无关，单列任务 |
| ingest 失败仍置 ok | 单文件解析失败/flush 失败只记日志，当日任务仍标 `ok` | **灌库验收必须独立核对文件数/日期覆盖/失败数**（53 §六），不得只看 `ok` |

`LastCompleteDate` 只取「六任务 ok 的最大日」、`db_complete()` 只校验端点与任务计数——**都不能证明中间无缺日**，
故第 3 步必须独立逐日对账（见上「执行顺序」第 3 条）。

3. **真实账本验收**：交易日历逐日比对六任务、撮合、权益快照、持仓跨年、参数/二进制/源库身份；复核无除权强平、原价/复权因子、无因子股票和回测终点。`db_complete()`、`LastCompleteDate()` 的最大日期/任务计数**不足以证明中间无缺日**，必须独立逐日校验。先验收再发布收益。

5. **样本外**：在研究参数冻结前不触碰 2019+ 数据作参数选择；需要时只按预先冻结的切分独立验收，不回填选参。

## 研究与结论纪律

- 只使用达瓦斯理论；现有 MA60 仅作已登记的大盘闸门，不将其他技术指标引入买点规则。
- 先立可证伪假设与分带，再做 A 类分布分析；需要改变规则才做 B 类回测。一次只变一个因素，固定引擎、行情、参数和对照库身份；不并发、不写生产库。
- 每档同时报告样本数、胜率、每单位净利、保本胜率、PF、前 3 笔赢家贡献与剔除前三后的净利；明确未复权、左截断、幸存者偏差。保本胜率必须用 `|平均亏损| / (平均盈利 + |平均亏损|)`；旧 LB-4 等报告该列及缺口列有错，未重算前不可引用。
- 净利明确区分**权益快照首末差**（含浮盈）与**平仓已实现盈亏**；连续单库回报不等于分年独立起跑后串乘。任何指标必须注明行情口径、库身份、期间和版本。
- 旧研究已否决 P3-8 升势/最高箱筛选、大赢家追加、50% 权益闸门；已维持 `position.staledays=2`、`sell.discount=0.97`。这些只是旧样本裁定，**新账本未重算前不声称最优或适用于新基线**。已完成实验的证据和限制见 [报告索引](experiments/README.md)，不再维护第二份队列。

## 判定口径（什么算「显著」）

1. **样本**：每单位净利 n≥30 才下结论；regime 类另报有效段数 m≥20，**n 与 m 并列报告**。
2. **方向**：保本胜率 = `|平均亏损| / (平均盈利 + |平均亏损|)`；实际胜率 − 保本胜率 ≥+2pp 有 edge、±2pp 内无、≤−2pp 负 edge。
3. **集中度**：前三赢家占 gross_win >60% 必须标「少数交易撑起」，并同时报**剔除前三净利**。
4. **跨年**：逐年符号必须列出；连续 ≥2 年同符号才初步认可。B 类裁判口径 = **改善年数 ≥3 且唯一负值落在噪声门槛内**。
5. **噪声门槛**：旧 `±600 元/年`、`3% 收益率`、`35% 集中度` 全部出自旧基线（A M1 / 不复权 / 分年库），
   **新基线重跑后必须重标**（48 §五 已标「待回填」）；重标前不得用旧门槛判新账本。
6. **禁挑单点**：不得挑单点最优档；分带切点是预设规则，禁按结果合并/拆分/挪界。
