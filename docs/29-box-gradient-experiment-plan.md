## 一、背景与目标

### 1.1 问题
- 14 年回测（2005-2018）账本基线加法账 +842,801，但利润高度集中（t1 甜区贡献约 76%）；
  复利口径下 baseline 曾 **水下 1,657 个交易日（占样本 49%）**——「五年没回本」。
- 两个未解决的痛点（用户 2026-10-25 提出）：
  1. **固定单位头寸管理**在大盘趋势不适合时回吐太多（2011 −85,243、2010 −53,345、2008 −79,655）；
  2. **缺少移动止损上移与主动减仓**，利润回吐无法保护。
- 五年 570 笔硬结论（docs/05 M10.5）：**唯一赚钱因子 = 持有时间；最大出血口 = 短持 6-10 日止损（−164,781）**。

### 1.2 目标
对 box 理论的 10 个维度逐一做**梯度分布验证**，得到每维「哪个梯度带有钱赚」的概率分布统计，
把有 edge 的带固化为规则，最终收敛出一套**入场（买什么/何时买）+ 仓位（买多少）+ 出场（何时卖）**
完整、经 14 年多牛熊段验证的交易系统。

### 1.3 覆盖度盘点（2026-10-28，交易闭环五环对账）

### 2.2 两类实验（成本差 10 倍）
- **A 类：分带统计（概率分布）**——已有交易按条件分带，统计四项口径。**大多数不需要新回测**。
- **B 类：规则验证（策略回测）**——把「某带有 edge」变成规则重跑，每轮约 14 小时。
- **铁律：A 先 B 后。** 跳过 A 直接跑 B 是最大的浪费。

### 2.3 单因子轮换（OFAT）
每次实验**只动一个因子**，其余固定为当前基准；禁止全组合遍历。

### 2.4 代表年粗筛（压缩 B 类成本）
B 类先跑代表年：**2007（单边牛）/ 2010（震荡）/ 2013（脱钩牛，闸门反例年）/ 2018（洗耳光熊）**
（原 2011 可由 2018 替代覆盖单边熊），显著才补全 14 年。

### 2.5 四项固定汇报口径
每一带必报：**胜率、每单位净利、保本胜率、利润集中度（前三赢家）**+ PF + 缺口 + **剔除前三净利**。
「剔除前三」是识破假 edge 的关键列，缺一不报。

### 2.5.1 概率统计是唯一裁判（用户 2026-10-28 定调，永久生效）

> 「我们的验证试验，始终重视概率与统计。」——所有实验结论只能由**分布**得出，不得由单点、个案、
> 叙事或直觉得出。以下是硬规矩：

1. **只认分布，不认单点**：任何参数结论必须给出**梯度分布**（分带/分档的胜率、每单位净利、保本胜率、
   利润集中度），禁止用「某一档最好」直接采纳。
2. **禁止挑最优档**：P0-1 教训——/top 20–25% 每单位 +1,228 全表最高，1% 加密后碎成窄缝，峰是假象。
   看到「总账最优」必须**再降一级粒度**复核是否成片。
3. **必报剔除前三**：剔除前三赢家后翻负的带 = 假 edge，不得采纳。
4. **样本门槛**：n≥30 才下结论；regime 类须 n 与 m（有效段数）并列，m≥20 才可信。
5. **跨年一致性**：连续 ≥2 年同符号才初步认可；单年盈利不可外推。
6. **噪声门槛**：单年复利终值差 <3% 视为噪声（=该参数不敏感、无信息），不得据此改默认值。
7. **先 A 后 B**：A 类（分带概率统计，零成本）先做；A 类有 edge 才上 B 类（规则回测）。
   跳过 A 直接 B 是最大浪费。
8. **单变量**：一次只动一个因子（OFAT），其余固定为新基线。

### 2.5.2 结果引用口径：权益变动 ≠ 已实现（2026-10-29 定，引用前必读）

回测库里**没有一个字段叫「年净利」**。所有报告里的"净利"都是 `equity_snapshot` 首末差，
即**权益变动**，它包含年末还挂着的未平仓浮盈。写成公式：

```
权益变动 = Σ(已实现 realized_pnl) + 年末未平仓浮盈 + 残差
残差 = 未计入 realized_pnl 的佣金 / 印花税 / 过户费（恒为负，量级 0.007%）
```

五年实测（`var/bt/base/bt_baseA_<年>.db`，2026-10-29 复核）：

| 年 | 权益变动 | 已实现 | 年末浮盈 | 残差 | 年末未平仓 |
|---|---|---|---|---|---|
| 2005 | −5,068 | −7,381 | +2,379 | −66.9 | 13 只 |
| 2007 | 1,143,999 | 963,551 | +180,507 | −58.3 | 2 只 |
| 2010 | −8,382 | −33,254 | +24,907 | −35.6 | 3 只 |
| 2013 | −3,111 | −7,703 | +4,612 | −20.4 | 2 只 |
| 2018 | −49,698 | −49,698 | 0 | 0.0 | 0 只 |

**引用纪律：**

1. **默认写「权益变动」，标口径。** 账户层面（复利、MDD、资金曲线）只能用权益变动。
2. **讨论出场规则 / 止损有效性 / 每单位净利时，必须用已实现**——浮盈是市场给的，不是规则挣的。
3. **禁止把两者混用**：2007 拿 1,143,999 去除以笔数，等于把两笔没卖出的浮盈摊进出场规则的成绩里。
4. **差幅最大的年份恰恰是牛市年末**（2007 差 18 万 = 15.8%），所以"牛市表现好"这个结论里
   有一部分只是"没卖"。
5. 复现命令：`python scripts/base_export_trades.py --identity`（打印上表，只读年库）。

> （量的是过程、看抛压是否枯竭），而本实验的量比定义是**突破当日成交量 / 前 50 日均量**（量的是

### 止损随 box 上移 · 事件研究（维度 8/9，A 类零成本，队列 2.1-1，2026-10-29 立项）

> **背景（docs/00 §3.7 第 6 点的落地）**：箱体是「活的生命体」（突破当日即开新箱、阶梯往上叠、
> 2007 实测 63% 的票反复突破），但「箱体 → 止损」这个映射用的是**死基准**：
> `raiseStops`（planner.go:448）有两条限制 —— ① 新箱下轨必须**已 3 日确认**；② **入场箱体自身不参与上移**。
> 结果：**票涨得越快，新箱确认越慢，止损越追不上**；大赢家冲到数倍时，止损可能仍钉在入场老位置。
> 这是「箱体生命观」与「实现」之间唯一尚未打通的一环。

**⚠️ 与 P2-5 的界限（防自相矛盾，必读）**：
- P2-5 否掉的是 **trail%（百分比驱动的移动止损）**——「盈利回吐超 X% 就走」，无证据；
- 本项是 **箱体驱动的止损上移**——「新 box 的下轨才是止损位」，与价格百分比无关，是原书 L2618/L2719
  的原文规则（「新箱体下轨牢固确立后才上移止损到新下轨下一点点」）。
- **两者不是同一件事，P2-5 的否决不适用于本项。** 本项要验的是「上移**来得及来不及**」，不是「该不该上移」。

**前置工程测试（A0/A1，零策略变更，2026-10-29 吸收自生命周期审计）**：
统计上移滞后之前，必须先确认「Box 身份与事件日期可信」。原因是：持久层只存**重算后的状态投影**
（`box` 表无 `start_date` / `invalidated_date` / 迁移事件账，见 docs/00 §3.7 第 1.1/6 点），
若直接拿重建结果推「本可上移日」，可能把窗口截断或 ID 复用造成的假象当事实。故：
- **A0 确定性契约**：① 终态不可逆（broken 不回到 confirmed）；② 终止当根 K 线只开一个新 forming；
  ③ 相同 K 线+参数重复 Scan 逐字段幂等；④ 全量重算 / 每日增量 / 最近 800 根窗口三者逐日比对 Box、
  Signal、PlanOrder，差异必须解释为窗口/输入语义，不得默认忽略。
- **A1 生命周期可观测性**：对每个 Box 构造事件视图（首次观测 / 上轨确认 / 下轨确认 / confirmed /
  broken_up / broken_down / invalid），区分「事件发生日期」与「系统首次观测日期」；800 日窗口左边界
  截断的实例标**左删失（出生未知）**，末端仍活跃的标**未终结（右删失）**，不伪造生死日期。
- **结论句**：**先验证轨迹（A0/A1）→ 再确认 Box 身份可信 → 最后才做下方「上移滞后」统计**。
  仍属第 8/9 维，**不新增第十一维、不改队列序号**。

**A 类分析口径（零成本，只读 14 年库，不跑回测）**：
1. 对每一笔已平仓（1328 笔）重算持仓期内：**本可上移的次数与幅度**（按每日最新非 forming 箱体下轨）
   vs **实际上移的次数与幅度**（从 `position.stop_price` 历史 + `plan_order.reason_json` 的 raiseStops 记录）；
2. 分带「**上移滞后天数**」= 本可上移日 − 实际上移日：`0 / 1–3 / 4–10 / >10 / 从未上移`；
3. 每带必报四项固定口径 + **MFE、回吐金额、回吐率**（与 P2-5 同源口径，可直接横向对照）；
4. **关键判据**：若「滞后大」的带 **剔除前三后净利显著更低** 且 **回吐率显著更高** → 上移不及时确是出血口，
   收紧条件（缩短确认日 / 入场箱体也参与上移 / 价格快涨时按比例抬）值得做 B 类；
   若各带差异落在噪声内（<3%）→ 「追不上」不是问题，维持现状，本项关闭。

**判定与门限**：A 类有 edge 才立项 B 类改代码；B 类须「复利终值更高 **且** 最差 MDD 不更差」双指标同时满足。
禁止以「box 是活的所以止损该跟着活」的叙事直接改代码——**叙事不是证据**（§2.5.1 第 1 条）。

**产物**：`docs/experiments/e17_stop_ratchet_framework.md`（跑前定稿，零结果纯规则）+
`e17_stop_ratchet_report.{html,md}` + `_data.json`；生成器 `scripts/e17_stop_ratchet.py`。

### 大赢家加仓放大（维度 10，A 类零成本先行，2026-10-29 立项）

> **背景**：系统利润高度集中——P2-5 实测 46 笔大赢家（MFE>50%）贡献 +1,133,049，是系统全部利润；
> 其余约 1282 笔合计为负。但现行仓位是「均等首买 + 一律不加码」（0017），大赢家拿得住却吃不满。
> 2007 实测：1147 只票中 718 只（63%）出现 ≥2 次突破信号——「连续突破」是箱体理论的正常现象，
> 说明大赢家的上涨途中确实存在**可识别的加仓机会**（更高 box 的再突破）。

**A 类分析（零成本，立项前先做）**：
1. 取 14 年全部大赢家（MFE>50%），统计每笔持仓期间**突破信号密度**（持有期内 broken_up 事件数 / 持有天数）；
2. 分带「信号稀疏 / 中等 / 密集」，看各带的**后续涨幅（MFE）与最终盈亏**分布；
3. 关键判据：若「信号密集带」的后续涨幅显著高于稀疏带 → 说明「连续突破」本身是更强的做多信号，
   加仓（在更高 box 再突破时追加）有概率依据；若各带差异落在噪声内 → 加仓无 edge，维持不加码。

**门限纪律**：
- 与「量化时代不需要金字塔」（用户 2026-10-28 定调，0017/0019 已废 `risk.*`）**表面冲突**——
  但那次废除的依据是「A 股一加就是顶」的**叙事**，非概率统计。本实验用 A 类分布重新裁决：
  有 edge 才考虑恢复加仓逻辑（B 类回测），无 edge 则彻底坐实「不加码」并关闭此话题。
- 禁止凭「大赢家该加仓」的直觉直接改代码；A 类必须先出「信号密度 vs 涨幅」的分布。

## 八、判定标准（什么算「显著」，统一口径）

1. **每单位净利**：符号稳定 + n≥30 才下结论；n<30 标注「样本不足」。
2. **保本胜率 vs 实际胜率**：差值 ≥ +2pp 有 edge，±2pp 内无 edge，≤−2pp 负 edge。
3. **跨年一致性**：必须看逐年符号；连续 ≥2 年同符号才初步认可，单年盈利不可外推。
4. **利润集中度**：前三赢家占 gross_win >60% 的带标注「少数交易撑起」。
5. **段级有效样本**（regime 类）：m（段数）≥20 才可信；n 与 m 必须并列报告。

## 十、红线（违反即停止）

1. 唯一理论：只做 box 理论，禁入均线/MACD/其他指标作为入场信号（MA60 仅限 regime 分桶与仓位闸门）。
2. 回测期间不改参数、不并发、不碰源库/生产库；回放只用 scratch 库。
3. 单因子轮换：一次只动一个因子。
4. 不把单年结果泛化为规律；四项口径缺一不报。
5. 字段化重跑必须保证除新增字段外与基线 100% 一致。
6. 样本外（2019 后两段）规则定稿前不参与任何参数选择，只做最终校验。
7. 2019+ 样本外暂停使用（2026-10-26 拍板）；比赛场地只有 2005–2018。
