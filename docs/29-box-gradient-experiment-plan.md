## 当前事实与未完成项

- `49` 的 B–F 阶段已有工程实现及局部实测，但旧连续库 `bt_baseA_cont.db` 为 schema v28 产物，**不是新基线**。不要把阶段通过写成新基线整体验收通过。
- **行情现状**：运行时仍读未复权 `daily_bar`；撮合器仍用 `dividend_event` 在除权日强制清仓。后复权 `daily_bar_adj`、读表切换、清仓下线均是 [53](53-data-spec-new-baseline.md) 的**待实施目标**，不是已上线能力。
- **攻防现状**：`pos.regime_scale.mode=off` 是基线；`on` 目前仍返回恒等乘数 1.0。[48](48-regime-attack-defense-design.md) 是待验证设计，不是已生效策略。
- **检查范围**：`scripts/check_consistency.py` 与 `scripts/param_ledger.py --check` 校验静态契约/参数，不证明行情覆盖、交易日连续、复权一致或收益。既有源码差异的审计快照见 [archive/54](archive/54-new-baseline-audit.md)，其中已修项、行号和旧建议不能直接当当前待办；以代码与下列验收重查。

## 执行顺序（严格依赖）

1. **数据口径**：按 [53](53-data-spec-new-baseline.md) 核对 tqcenter 实测前提并实现后复权行情导入、股票/指数分流、除权清仓下线。保持原表作为原价对照；同步更新 [01](01-requirements.md)、[03](03-erd.md)、[04](04-api-contract.md) 的**当前实现状态**，未完成前不得描述为已上线。
2. **连续单库重建**：按 [49](49-baseline-rebuild-charter.md) 用全新源库/二进制在 2005-01-01 至 2018-12-31 串行重建。`44` 的 49 个生效键冻结、身份与参数快照落库，任何续跑 `--set` 拒绝。分年库只作冒烟/历史对照，正式基线只有连续单库。
3. **真实账本验收**：交易日历逐日比对六任务、撮合、权益快照、持仓跨年、参数/二进制/源库身份；复核无除权强平、原价/复权因子、无因子股票和回测终点。`db_complete()`、`LastCompleteDate()` 的最大日期/任务计数**不足以证明中间无缺日**，必须独立逐日校验。先验收再发布收益。
4. **攻防 B 类**：完成前三步后，以新账本复算 [48 §五](48-regime-attack-defense-design.md) 的基准指标与噪声阈值，实现 L1 状态、乘数传导，再验证 `off` 逐单等价与 `on` 的预注册判据。旧基线 974,937、18.9%、±600、35% 不作新基线判据。
5. **样本外**：在研究参数冻结前不触碰 2019+ 数据作参数选择；需要时只按预先冻结的切分独立验收，不回填选参。

## 研究与结论纪律

- 只使用达瓦斯理论；现有 MA60 仅作已登记的大盘闸门，不将其他技术指标引入买点规则。
- 先立可证伪假设与分带，再做 A 类分布分析；需要改变规则才做 B 类回测。一次只变一个因素，固定引擎、行情、参数和对照库身份；不并发、不写生产库。
- 每档同时报告样本数、胜率、每单位净利、保本胜率、PF、前 3 笔赢家贡献与剔除前三后的净利；明确未复权、左截断、幸存者偏差。保本胜率必须用 `|平均亏损| / (平均盈利 + |平均亏损|)`；旧 LB-4 等报告该列及缺口列有错，未重算前不可引用。
- 净利明确区分**权益快照首末差**（含浮盈）与**平仓已实现盈亏**；连续单库回报不等于分年独立起跑后串乘。任何指标必须注明行情口径、库身份、期间和版本。
- 旧研究已否决 P3-8 升势/最高箱筛选、大赢家追加、50% 权益闸门；已维持 `position.staledays=2`、`sell.discount=0.97`。这些只是旧样本裁定，**新账本未重算前不声称最优或适用于新基线**。已完成实验的证据和限制见 [报告索引](experiments/README.md)，不再维护第二份队列。
