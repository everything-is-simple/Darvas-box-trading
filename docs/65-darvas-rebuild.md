### 3.2 「原著意义的牛市」定义（1a 第三行）

从案例反推（他不空仓硬扛熊市，也从不预测拐点），原著的牛熊判定是**四层一体**：

1. **影响面层**：牛/熊 = 影响几乎所有股票的主循环（S4）——判据是「多数票同向」，不是指数点位。
2. **体感层（实操通道）**：判牛熊的唯一落地 = 自己的持仓与买点表现。止损接连触发 → 自动清空（S8/S9）= 离场；买点重新有效 → 重新进场。指数只提供强/弱二值背景板（S4/S5），从不构成开/关（S3/S13/S14）。
3. **结构层**：牛市 = 多数强壮，熊市 = 多数病歪歪（S7）——广度方向兼容，但零数值。
4. **转势层**：早期信号在个股不在指数（S11），新牛市领涨股 ≠ 旧领涨股（S12），牛皮市更易出大涨股（S18）。

> **定义（本仓口径）**：原著意义的牛市 = **「突破买点在多数候选上仍然有效、止损不被接连触发、
> 清仓后仍有票可买」的市况**；其反面即熊市。它是**组合层体感**，不是市场层前置条件。

**对现行系统的含义**：现行 MA60 硬开关 + 温度计前置闸门，把原著的「组合层体感」错装成
「市场层前置开关」——架构哲学层面的错位，比某个阈值对不对更根本。**1b 量化时的优先序**：
