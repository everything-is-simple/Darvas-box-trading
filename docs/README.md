## 引用规则（新增文档必读）

1. **SSoT 互引**：00-06 之间用 `docs/0X-*.md` 短路径，由 `check_consistency.py` 校验存在性。
2. **引用归档稿**：07+ 已归档的用 `archive/NN-*.md` 路径（如 `archive/12`），且明确一次「核心内容已沉淀至」。
3. **引用当前行动纲领**：docs/18 是现役指挥中心，整改完成后归档。
4. **新文档命名**：继续顺号（19、20...），加二级标题前缀（如 `19-foo.md`）。归档时加 `archive/` 前缀保留原文件名，git mv 保历史。

## 一句话总结

**7 个 SSoT 是事实源，docs/18 是当前指挥中心，archive/ 是历史。新工作不新建文档，回到 SSoT 沉淀。**
