## 〇、术语速查（本仓唯一口径，勿混）

> **为什么有这一节**：历史上「t/T + 数字」被四套互不相干的东西混用，读到 `T2` 分不清是「涨幅强度指标」还是「挂账待办」。2026-11-06 起统一为三个中文词根，**以后文档和对话只用下表名称，且必须带全名+作用**。

| 词根 | 编号 | 全名 | 作用 | 落点 |
|---|---|---|---|---|
| **档** | 档1 / 档2 / 档3 / 档4 | 阶梯仓位四档（距 52 周高点距离） | 决定「买多少」：档1≤5% 3单位 / 档2 5–10% 2单位 / 档3 10–20% 1单位 / 档4 20–40% 0.5单位（>40% 拒买） | `01 §6`、`44 §二` |
| **温** | 温1–温8 | 市场温度计八指标 | 决定「现在是什么市」：温1 涨跌家数比 / 温2 涨幅强度 / 温3 行业家数比 / 温4 行业强度 / 温5 涨停家数 / 温6 跌停家数 / 温7 创新高 / 温8 创新低 | `48 §二` |
| **挂** | 挂4–挂8 | 挂账待办清单 | 记录「被挂起、非阻塞」的后续任务：挂4 参数对账 / 挂5 出口分解 / 挂6 raiseStops / 挂7 跌停逃顶 / 挂8 boxscan 提速 | `60 §2.4` |
| **实验** | A/B/K/P + 数字、E19-xx | 实验臂编号 | A=既有任务（A1 删档4、A5/A6 大盘感知）、B=出场端、K=三书吸收、P=消参工程、E19=历史实验 | `60` |
| — | `T02010` 式 | 通达信行业码 | 外部数据，5 位数字，非本系统术语 | `57 §5` |

**关键区分**：`档4`（仓位）≠ `温4`（行业强度）≠ `挂4`（参数对账）——三个词根永不混。参数键名 `pos.newhigh.units.t1~t4`（代码字段）与 `newhigh_t1~t4`（sizing_basis 枚举）保留小写 `t`，仅存在于代码/表结构中，文档正文一律写「档N」。

## 五、引用规则

1. 新规则先更新对应事实源，再更新释义文档和代码引用；**不要新建平行规则**。
2. 归档内容只用 `archive/...` 明确引用，且必须说明它是历史材料，不是现状。
3. 参数表禁止手改 `44 §二` 生成区；改代码默认值 → 写 migration → `python scripts/param_ledger.py --write`。
4. Schema、接口、时刻表或参数发生变化，同一提交同步更新对应文档并运行 `python scripts/check_consistency.py`（现 14/14）。
5. **账本重跑或收官数字变化**：`python scripts/doc_anchors.py --write` 重算锚点快照并重写 `55 §11.10`，否则 C8 红。
6. 实验报告不回写生产规则；只有明确裁定后，才把结论沉淀到 `29`、`44` 或对应 SSoT。
7. **引用章节号前先确认它还在**：`55` 2026-11-06 两次重编（§17→§11、§18→§12、原 §19–§21→§13；
   原 §3/§4 已归档且**编号留空**，看到 §2 直接跳 §5 不是漏页）。旧快照的章节号一律改引
   `archive/55-full-snapshot-2026-11-06.md`。
8. **不要再写「计划」类内容到别处**：`60` 是唯一队列与看板；`56` 已归档，任何 `56 §x` 的引用都失效。
9. 改完文档先跑 `python scripts/check_consistency.py`：**C9 会抓死链与悬空章节号**，别再靠手工 grep。
