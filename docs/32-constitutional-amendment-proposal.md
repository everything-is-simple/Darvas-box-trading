## 二、被证伪的 vs 被验证的（本提案的核心区分）

第 0 条第三次修正证伪的是 **C 判据择时动作**；本次验证通过的是 **MA60 仓位闸门**。两者不是同一件事：

|      | 第三次修正证伪的（2026-10-23）                  | 本次验证通过的（2026-10-27）             |
| ---- | ------------------------------------- | ------------------------------- |
| 判据   | C 判据（20 日箱体换层，箱体语言）                   | 上证收盘 vs MA60（指数均线）              |
| 动作   | ①开仓放大器（升2平1降0.5 改开仓）②熊市闸门（5 日持续下跌即触发） | 仓位闸门（MA60 下方不生成首买单）             |
| 触发对象 | 入场决策（何时买/买不买）                         | 仓位决策（买多少），入场信号不动                |
| 证据   | 五年回测六轮：−28k~−58k，错杀牛市回调               | 14 年 14/14 跑：Σ改善 +132,136，三判据全过 |
| 结论   | **维持证伪，继续禁止**                         | **验证通过，允许作为仓位工具**               |

**一句话**：被六轮枪毙的是「用箱体换层做择时」；活下来的「用指数均线管仓位」从未被那六轮测过——P0-3 已示三口径 Jaccard 仅 0.08，**不同尺子不能互相继承判决**。

## 四、证据摘要（详见 gate_report §七）

- 双口径：Σ已实现 +132,136 / Σ年末权益 +103,193，两口径同号；

## 五、本提案**不**做的事

1. **不改入场规则**：突破买入、3% 触发、黑名单、止损链全部原样；
2. **不生产化**：`darvas serve` 生产二进制仍是旧语义；MA60 闸门若要进生产，需独立发布决策（不在本提案范围）；
3. **不终止第三轮设计**：docs/31 双指数确认分级闸门（A 类后验待启动）是已登记的后续轮次，本提案不预断其结果；
4. **不复活任何被证伪项**：C 判据开仓放大器、200 日均线、默认箱体扫指数（`docs/00` §5.6.8 否决项）维持禁止。
