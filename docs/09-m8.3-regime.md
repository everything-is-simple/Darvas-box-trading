## 1. 定位与目标

把 M8.2 撮合器模拟出的成交数据，按**牛/熊/猴**市场体制切段，输出权益曲线/回撤/胜率/
暴露时间的 HTML 报告——为「大盘闸门要不要加」提供**证据**，不做主（PROMPT P4 附加纪律 3：
回放只给证据，大盘闸门属新规则，由用户拍板）。

## 2. 体制标注规则（核心决策 · 禁摘樱桃）

**要求**：客观、事先、可复现——任何日期的体制只能用「该日期及之前」的数据判定，
禁止事后看结果挑窗口（樱桃挑选）。

**规则（动量法）**：以 sh000001 上证指数为市场代理，每个交易日 D：

```
momentum(D) = close(D) / close(D 之前第 N 个交易日) - 1
momentum >  +bull_thresh → 牛（bull）
momentum <  -bear_thresh → 熊（bear）
其余                    → 猴（range，震荡）
```

参数（走 param，M8.4 可扫）：

| 参数 | 默认 | 说明 |
|------|------|------|
| `regime.window` | 60 | 动量窗口（交易日，约一季度） |
| `regime.bull_thresh` | 0.10 | 牛阈值（+10%） |
| `regime.bear_thresh` | 0.10 | 熊阈值（-10%） |

> 定参依据（2026-10-19 落地验证）：120 日对 2024 政策牛（120 日动量最高 +13%）太迟钝
> 标不出牛；60 日动量可达 +26%，故 window=60 / 阈值 ±10%。阈值敏感性留 M8.4 扫描。

**为什么用动量而非均线/箱体**：
- 纯价格统计，零未来信息，机械可复现，最满足「禁摘樱桃」。
- 不引入 MA/均线等任何其他理论（守住铁律 §2 单一理论；体制标注是统计工具，非交易规则）。
- 达瓦斯箱体标注需处理「突破后持续期」的映射，复杂且易争议，初版不采用。

**已知代价（诚实声明）**：趋势跟随固有滞后——牛熊转换初期动量未到位，会标为 range。
这是「不用未来信息」的必然结果，不是 bug；阈值敏感性交由 M8.4 参数扫描。

## 3. 分体制聚合统计口径

- **切段**：权益曲线按「连续同体制日」切成段，每段统计天数/收益率/最大回撤/成交笔数/
  胜负/暴露天数。
- **收益率**：段末权益 / 段首权益 - 1（复利合并到体制汇总）。
- **最大回撤**：段内 equity_snapshot.drawdown 最负值。
- **成交归因**：fill 按 fill.date 归入当日体制。
- **胜率**：closed position 按 close_date 归因，realized_pnl > 0 为胜。
- **暴露时间**：段内有持仓（market_value > 0）的天数占比。

---

## 4. 报告结构（HTML，零外部 JS）

1. 总览：交易日数、起点权益、总收益率、最大回撤。
2. 分体制汇总表：牛/熊/猴各一行（段数/天数/收益率/最大回撤/成交/胜率/暴露时间）。
3. 分段明细表：每个连续同体制段一行。
4. 权益曲线：SVG 散点折线，点色=当日体制（红牛/绿熊/黄猴，中国涨红跌绿惯例）。

## 5. 已知限制与后续

- 代理选择：只用 sh000001，未考虑个股分化（结构性行情下指数可能失真）。后续可加
  深证成指/全A等权，但初版单一代理够「大盘闸门」决策。
- 数据覆盖：perf_test.db 仅 2024-01 起（2.7 年）。跑 2014-2026 全历史需先从 TDX 灌
  全量多年数据（另一任务）。
- 阈值敏感：bull/bear_thresh 与 window 是拍脑袋默认值，M8.4 参数扫描定最优。
