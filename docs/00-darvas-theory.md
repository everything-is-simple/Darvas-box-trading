## 2. 达瓦斯的四大目标（系统存在的意义）

1. **要买对股票** → 初选 + 跟踪池解决「买什么」
2. **要在正确的时间买入** → 箱体突破信号解决「何时买」
3. **尽量减小损失** → 箱体下轨止损解决「何时卖（错的时候）」
4. **尽量扩大利润** → 金字塔加码 + 箱体阶梯跟踪止损解决「买多少/卖多少」

### 四大工具

| 工具 | 系统对应模块 |
|------|-------------|
| 价格与成交量 | `ingest`（日线数据）+ `screener`（放量/新高筛选） |
| 箱体理论 | `box`（箱体引擎） |
| 自动买单（停损买单） | `planner`（次日停损买单计划） |
| 止损卖单 | `planner`（止损卖单计划）+ `position`（移动止损） |

### 基本策略（达瓦斯原话）

> "我将慢步跟随一轮上升趋势，并以随股价不断上移的止损卖单作为保险措施。当趋势继续时，我将补仓。而当趋势反转时呢？我就像小偷一样迅速撤离。"

## 3. 箱体的机械化定义（可计算规则）

原著用文字描述箱体，系统采用业界通行的**三日法则**机械化版本（与原著语义一致，已被多个公开实现交叉验证）：

### 3.1 箱体上轨（Top）
1. 股票创出一个**新高**（理想：52周新高）；
2. 若**连续3个交易日**未能再创新高 → 该高点成为**箱体上轨**；
3. 计数期间若又创新高 → 上轨候选更新为新高点，**重新计数**。

### 3.2 箱体下轨（Bottom）
1. 上轨确立后，跟踪其后的**最低点**；
2. 若**连续3个交易日**未再跌破该低点 → 该低点成为**箱体下轨**；
3. 计数期间若又创新低 → 下轨候选更新，重新计数；
4. **下轨确立前若创出新高** → 该箱体作废，从新高重新开始（原箱体从未完成）。

### 3.3 箱体状态机

```
forming ──3日确认上轨──→ forming_bottom ──3日确认下轨──→ confirmed
   │                          │                                │
   │ 创新高（重置）            │ 创新低（重置）                 │ 收盘价 > 上轨 且放量
   ↓                          ↓                                ↓ (前箱体状态)
 重置上轨候选              重置下轨候选               broken_up ──→ 开始新箱体(forming)
                                                              │
                                                              │ 收盘价 < 下轨
                                                              ↓
                                                          broken_down（止损信号）
```

### 3.4 箱体阶梯（金字塔）

- 上升箱体序列：`[$17/$24] → [$24/$27] → [$31/$35] → [$35/$40]`
- **新箱体下轨 ≈ 前一箱体上轨**（允许±3%容差）
- 每次向上突破 → 止损位上移到**新箱体下轨下方**
- 箱体金字塔开始向下 → 全面撤离信号

## 4. 买入规则

### 4.1 达瓦斯三段式买入（金字塔）

| 腿 | 触发条件 | 仓位 | 止损 |
|----|---------|------|------|
| 第1腿·测试单 | 跟踪池股票放量突破箱体上轨 | 小仓位（风险1%） | 被突破箱体上轨（突破点）下方 |
| 第2腿·确认单 | 突破后形成新箱体且再突破 | 中仓位（风险2%） | 新箱体下轨下方 |
| 第3腿·加码单 | 又一箱体再突破（最多3腿） | 大仓位（风险2%） | 最新箱体下轨下方 |

> 达瓦斯实际操作：500股 → 1,200股 → 1,500-2,000股。系统按风险百分比换算（见《01-requirements》§6）。
> 2026-10-18 原书校对修正（B1）：首腿初始止损原误挂"突破箱体下轨下方"，应为**被突破箱体上轨（突破点）下方一点点**——首腿=小风险预算+紧止损；新箱体确立后止损照常上移至新箱体下轨下方（腿2/3及止损上移规则不变）。

### 4.2 突破有效性判定（成交量确认）

- 突破日成交量 ≥ **50日均量 × 2**（参数化，默认值，可调）
- 无量突破 = 假信号，忽略
- 突破后3日内跌回箱体内 = 失败突破，止损离场

### 4.3 绝不做的事

- ❌ 在箱体**内部**买入（箱体内波动全是噪音）
- ❌ 在突破**之前**抢先买入（预测突破是赌博）
- ❌ 突破失败后「等它回来」（跌回箱体=错了，立即出场）

## 5. 卖出规则

### 5.1 止损卖出（保护本金）
- 收盘价跌破**当前箱体下轨** → 次日以停损方式全部卖出
- 止损单只上移，**永不下移**

### 5.2 获利了结（保护利润）
- 无目标价位，不主动止盈
- 止损位随箱体阶梯上移，直到最终被触发
- 「没有理由卖掉一支正在上涨的股票」

### 5.3 卖出数量
- 达瓦斯纪律：**一次全出**，不逢高减仓、不摊薄

## 6. 初选筛选条件（进入跟踪池的唯一通道）

| # | 条件 | 达瓦斯原话/依据 | 默认阈值 |
|---|------|----------------|---------|
| 1 | 流动性 | 只买主板上市股（NYSE/AMEX），要有报价制度 | 日均成交额≥5000万元，排除ST/北交所/次新 |
| 2 | 相对强度 | 「股市下跌时逆市而动的股票，风向变化时上涨最快」 | 20日RS>1.2（vs 上证指数） |
| 3 | 成交量放大 | 「成交量从10,000股放大到126,700股」 | 5日均量/20日均量 ∈ [2.0, 5.0] |
| 4 | 箱体形态 | 上升箱体形成中或刚突破 | 三日法则 confirmed 或刚 broken_up |

**基本面（盈利增长+成长行业）**：达瓦斯要求盈利能力不断提高。受限于本地数据源（TDX无财务数据），设计为**人工复核项**：系统输出候选池后，人工标注「盈利增长「盈利增长✓/✗」，未标注默认视为✓并记录在案。**不引入任何自动基本面模型。**

### 排除清单（达瓦斯用亏损换来的）

- ❌ 打听消息 / 听经纪人建议 / 华尔街格言 / 谣言
- ❌ 前一轮牛市的领涨股
- ❌ 长期持有下跌股票（「自诩保守的投资者是纯粹的赌徒」）
- ❌ 柜台市场股票（→A股对应：新三板/北交所/流动性差的品种）

## 7. A股制度适配（显式映射表）

> 原则：只做**制度性转换**，不做**理论性混合**。左列是原著规则，右列是A股等价物，一一对应。

| 达瓦斯原著（美股1950s） | A股适配 | 理由 |
|------------------------|---------|------|
| NYSE/AMEX主板 | 沪深主板+创业板+科创板 | 流动性与制度等价 |
| 停损买单（stop-buy order） | 券商APP「条件单/触发委托」 | A股无原生stop单，用触发委托模拟 |
| 止损卖单（stop-loss order） | 券商APP「止损条件单」 | 同上 |
| T+0 当天止损 | T+1：次日开盘优先止损 + 单股仓位≤20% | 制度约束的补偿 |
| 无涨跌幅限制 | 突破确认：收盘>上轨×1.03 且非一字板 | 涨停板下追不进/诱多区分 |
| 电报每日一次报价 | 系统每日15:30后读取TDX收盘数据 | 同样的「远离盘面」纪律 |
| 52周新高 | 52周新高（一年新高） | 直接沿用 |

### 涨停板细分规则

| 情形 | 处理 |
|------|------|
| 一字涨停板 | 买不进 → 放弃，不追 |
| 涨幅8-9%放量板 | 符合突破买入 |
| 连续涨停 | 不追，等箱体重建后再评估 |

## 8. 每日纪律（达瓦斯的时间观）

达维斯在环球巡演中操作，**每天只在固定时间收一次电报报价**，其余时间完全不看行情。这是体系的隐性支柱：

1. **决策基于收盘价**，不基于盘中波动（盘中波动=噪音）
2. **固定时间做固定的事**，其余时间远离市场
3. **订单预先挂好**（停损买单/止损卖单），盘中无需人工判断
4. 名成后在交易大厅做日内交易亏掉10万美元的教训 → **本系统不做任何日内逻辑**

系统的调度器（`scheduler`）就是这条纪律的程序化：见《01-requirements》§4 每日时间表。

## 9. 单一理论原则（Negative Scope）

以下概念在本系统中**明确不存在**（出现即视为设计违规）：

- MALF / Pivot / Range / Lifespan
- 立花K1-K11 / 回档布网 / 2ATR止损
- 均线系统（MA金叉死叉作为买卖依据）※ 仅作为初选辅助统计输出，不作信号
- 布林带 / MACD / KDJ 等任何指标信号
- 逆势抄底 / 左侧交易 / 网格
- 欧奈尔杯柄、Minervini VCP等形态学

> 维护方式：代码评审检查清单 + `internal/contract` 包的接口面审计（见《06-consistency》）。
