## 第 0 条 · 最高原则（贯穿始终）

> **达瓦斯交易系统的最高原则：「众人恐慌我更恐慌，众人贪婪我更贪婪」。**
>
> 我始终保持冷静，追随着市场，随着市场的牛熊猴变化我的仓位——牛市放大下注（贪婪），
> 熊市大幅缩仓（恐慌），震荡市轻仓试单（观望）。仓位不是固定的，是市场的函数。
>
> 这一原则是本系统「市场宽度+单位制仓位」（M8.8）的宪法依据，高于任何单一交易规则；
> 任何与「仓位随市」冲突的具体参数，均让位于本原则。
> 落地约束：仓位以「单位（=2% 权益）」计量，**牛市总敞口≤70%、永远留 30% 现金**
> （5 试探+30 主力+15 预备=50 单位）；熊市/猴市纯试探系统（≤10% 敞口）。

## 2. 达瓦斯的四大目标（系统存在的意义）

1. **要买对股票** → 初选 + 跟踪池解决「买什么」
2. **要在正确的时间买入** → 箱体突破信号解决「何时买」
3. **尽量减小损失** → 箱体下轨止损解决「何时卖（错的时候）」
4. **尽量扩大利润** → 金字塔加码 + 箱体阶梯跟踪止损解决「买多少/卖多少」

### 四大工具

| 工具 | 系统对应模块 |
|------|-------------|
| 价格与成交量 | `ingest`（日线数据）+ `screener`（放量/新高筛选） |
| 箱体理论 | `box`（箱体引擎） |
| 自动买单（停损买单） | `planner`（次日停损买单计划） |
| 止损卖单 | `planner`（止损卖单计划）+ `position`（移动止损） |

### 基本策略（达瓦斯原话）

> "我将慢步跟随一轮上升趋势，并以随股价不断上移的止损卖单作为保险措施。当趋势继续时，我将补仓。而当趋势反转时呢？我就像小偷一样迅速撤离。"

## 3. 箱体的机械化定义（可计算规则）

原著用文字描述箱体，系统采用业界通行的**三日法则**机械化版本（与原著语义一致，已被多个公开实现交叉验证）：

### 3.1 箱体上轨（Top）
1. 股票创出一个**新高**（理想：52周新高）；
2. 若**连续3个交易日**未能再创新高 → 该高点成为**箱体上轨**；
3. 计数期间若又创新高 → 上轨候选更新为新高点，**重新计数**。

### 3.2 箱体下轨（Bottom）
1. 上轨确立后，跟踪其后的**最低点**；
2. 若**连续3个交易日**未再跌破该低点 → 该低点成为**箱体下轨**；
3. 计数期间若又创新低 → 下轨候选更新，重新计数；
4. **下轨确立前若创出新高** → 该箱体作废，从新高重新开始（原箱体从未完成）。

### 3.3 箱体状态机

```
forming ──3日确认上轨──→ forming_bottom ──3日确认下轨──→ confirmed
   │                          │                                │
   │ 创新高（重置）            │ 创新低（重置）                 │ 收盘价 > 上轨 且放量
   ↓                          ↓                                ↓ (前箱体状态)
 重置上轨候选              重置下轨候选               broken_up ──→ 开始新箱体(forming)
                                                              │
                                                              │ 收盘价 < 下轨
                                                              ↓
                                                          broken_down（止损信号）
```

### 3.4 箱体阶梯（金字塔）

- 上升箱体序列：`[$17/$24] → [$24/$27] → [$31/$35] → [$35/$40]`
- **新箱体下轨 ≈ 前一箱体上轨**（允许±3%容差）
- 每次向上突破 → 止损位上移到**新箱体下轨下方**
- 箱体金字塔开始向下 → 全面撤离信号

## 4. 买入规则

### 4.1 达瓦斯三段式买入（金字塔）

| 腿 | 触发条件 | 仓位 | 止损 |
|----|---------|------|------|
| 第1腿·测试单 | 跟踪池股票放量突破箱体上轨 | 试探仓：名义≤权益5%且≥200股（原书200-500股适配） | 被突破箱体上轨（突破点）下方 |
| 第2腿·确认单 | 突破后形成新箱体且再突破（无持仓新入场） | 确认单：风险2% + 单股上限 | 新箱体下轨下方 |
| 第3腿·加码单 | 又一箱体再突破（最多3腿）；**或** 持仓未触及止损且价在买点上方7%内（第②通道） | 加码单：持仓×5倍，加码后总名义≤20% | 最新箱体下轨下方 |

> 达瓦斯实际操作：500股 → 1,200股 → 1,500-2,000股。系统按风险百分比换算（见《01-requirements》§6）。
> 2026-10-18 原书校对修正（B1）：首腿初始止损原误挂"突破箱体下轨下方"，应为**被突破箱体上轨（突破点）下方一点点**——首腿=小风险预算+紧止损；新箱体确立后止损照常上移至新箱体下轨下方（腿2/3及止损上移规则不变）。
> 2026-10-18 原书校对补全（B4，动态仓位）：原书"小仓试探→确认放大→自设上限"结构落地——腿1试探仓钳制到 [200股, 权益5%名义]（原书200-500股是小账户绝对数；A股适配：500股茅台≈75%权益不可行，故上限按名义比例）；腿3加码=持仓×risk.scale（默认5，原书3-10倍），加码后总名义不超过risk.maxpos（20%）；腿2为无持仓新入场，维持风险公式2%。无新表结构，参数见 migrations/0005。
> 2026-10-20 补全（M8.6，第②通道）——**原书有两条加码规则**，此前只实现跨箱体加码（第①条，罗瑞拉德案例：28.75→35→36.5→38.625）。第②条见布鲁斯案例（原书 line 1504）："当我看到公司股价没有触及止损位后，我开始继续补仓"，5 笔 50.75→53.625（+5.7%）**在同一箱体内完成、不等新箱体**。量化边界取欧奈尔"加仓要在买点上涨5%以内"并放宽到 7%（`risk.addon_max_premium`）。五条件：盘中最低未触及止损 + 收盘≥上次成交价（不摊低）+ 收盘≤首腿价×1.07（不追高）+ 首腿状态（第一版至多加一次）+ 高优先级信号优先。

### 4.2 突破有效性判定（成交量确认）

- 突破日成交量 ≥ **50日均量 × 2**（参数化，默认值，可调）
- 无量突破 = 假信号，忽略
- 突破后3日内跌回箱体内 = 失败突破，止损离场

### 4.3 绝不做的事

- ❌ 在箱体**内部**买入（箱体内波动全是噪音）
- ❌ 在突破**之前**抢先买入（预测突破是赌博）
- ❌ 突破失败后「等它回来」（跌回箱体=错了，立即出场）

## 5. 卖出规则

### 5.1 止损卖出（保护本金）
- **首腿初始止损**：买入同时挂止损单，价位=被突破箱体上轨（突破点）下方一点点（原书 L2526：箱顶 45 → 止损 44⅞，约 -3%）。✅ **已实现（ST1，2026-10-21）**：planner 持仓期每日挂 `trigger=pos.StopPrice` 的 initial_stop 卖单，与箱体下轨止损并存、先到先触发。
- **移动止损**：收盘价跌破**当前箱体下轨** → 次日以停损方式全部卖出
- 止损单只上移，**永不下移**

### 5.2 获利了结（保护利润）
- 无目标价位，不主动止盈
- 止损位随箱体阶梯上移，直到最终被触发
- 「没有理由卖掉一支正在上涨的股票」

### 5.3 卖出数量
- 达瓦斯纪律：**一次全出**，不逢高减仓、不摊薄

## 6. 初选筛选条件（进入跟踪池的唯一通道）

> **⚠️ 2026-10-21 逐项对照书重新审计**：下面前三行（流动性/相对强度/放量）的**数字阈值全是工程假设，原著只给了定性描述，没给数字**。逐条标注「原著原文」vs「我们的假设」，供后续回测校准。

| # | 条件 | 原著原文（行号） | 我们的假设 | 差距 |
|---|------|----------------|-----------|------|
| 1 | 流动性 | L583「柜台市场并没有上市股票那样严格的报价制度」；L890「股价不活跃的股票……不会大幅上涨」；L481「上市证券=在 NYSE/AMEX 挂牌交易的股票」 | 日均成交额 ≥5000 万元，排除 ST/北交所/次新 | **原著只要求"上市+活跃"，没给金额**；5000 万是 A 股规模适配的拍脑袋数 |
| 2 | 相对强度 | L1273「股市下跌时逆市而动……风向变化时上涨最快」；L706「只要看到某支股票表现强于市场」；L1275「抗跌的股票=盈利趋势大幅向上」 | 20 日 RS（个股涨幅/上证涨幅）≥1.2 | **原著只说"逆市/抗跌/强于市场"，无量**；RS≥1.2 是我们拍的；且原著 RS 的参照是"大市/同行业"，我们只比上证 |
| 3 | 成交量放大 | L1371 罗瑞拉德「成交量 126700 股，与之前正常 10000 股相比**显著放大**」；L863「平常不活跃的股票突然活跃……一定不正常」 | 5 日均量/20 日均量 ∈ [2.0, 5.0] | **原著只定性"显著放大"，唯一数字是罗瑞拉德单例（12.67 倍）**；[2.0,5.0] 区间是我们拍的，且**上限 5.0 是凭空加的**（原著没说要"不能太大"） |
| 4 | 箱体形态 | 三日法则（§3 已机械化定义） | confirmed 或刚 broken_up | ✅ 忠实原著（⚠️ "刚 broken_up"分支因 ST4 长期死掉，R1 修复） |

**关键结论（三个假设的诚实定位）**：

1. **流动性 5000 万**：原著依据是"上市+有报价制度+活跃"，A 股等价物应是"排除 ST/北交所/退市风险股 + 有流动性"，**"5000 万"这个具体数字是纯假设**，可保留作初筛但需回测校准（太严会漏掉小盘强势股，太松会放进僵尸股）。
2. **相对强度 RS≥1.2**：原著依据最弱——达瓦斯说的是"逆市而动"（熊市里抗跌），**不是"跑赢大盘 20%"**。我们的 RS 公式（个股涨幅/上证涨幅）在牛市里几乎人人达标、在熊市里把"抗跌但仍在跌"的股票也筛掉了，**语义和原著有偏差**。
3. **量比 [2.0,5.0]**：下限 2.0 对应"显著放大"还算合理；**上限 5.0 是错的**——原著唯一案例是 12.67 倍（罗瑞拉德），且反复强调"成交量越大越好"（L1372「稳步上涨+成交量放大=有价值」）。上限反而把最强势的票挡在门外。

**基本面（盈利增长+成长行业）**：达瓦斯要求盈利能力不断提高（L1275「抗跌的股票=盈利趋势大幅向上」）。受限于本地数据源（TDX无财务数据），设计为**人工复核项**：系统输出候选池后，人工标注「盈利增长✓/✗」，未标注默认视为✓并记录在案。**不引入任何自动基本面模型。**

### 跟踪池淘汰规则（原书校对补全，2026-10-18）

达瓦斯对初选池与持仓的退出纪律（此前未实现，B2 补全）：

| # | 规则 | 达瓦斯原话/依据 | 系统实现 |
|---|------|----------------|---------|
| 1 | 太晚规则 | 突破后「四天都收在突破点之上」还没买=看到太晚，放弃 | screener：broken_up 后 ≥ `screen.latedays`(4) 个交易日 → 不入候选池 |
| 2 | 两亏拉黑 | 同一股票两次亏损交易 → 不再碰 | poolsync：`realized_pnl<0` 交易满 `pool.maxloss`(2) 次 → watch=blacklisted，永不再入池 |
| 3 | 条件挂起 | 「停传报价」：基本面/走势存疑时暂停跟踪，突破X再传 | `darvas pool suspend <code> --resume <价>`：收盘 ≥ 激活价自动恢复跟踪（suspended 不占跟踪名额） |
| 4 | 跟踪数量 | 「一次只关注 5～8 支」 | ⚠️ **2026-10-21 用户拍板修正**：原书 L1074「我自然被迫将操作目标缩小到为数不多的几支股票，**以便节省费用**」——5-8 支是 1950 年代电报费（12-15 美元/股/天）倒逼结果，**不是策略原则**。系统无此成本（CPU+SQLite），故废弃硬上限：`pool.maxwatch` 降级为软参考（仅日志告警，不拒绝入池）；**有就进、无就 0**，资金预算（M8.8 单位制 50 单位）是唯一真正约束 |
| 5 | 不获利3周 | 开仓3周仍不获利 → 退出，资金换到别处 | planner：开仓 ≥ `position.staledays`(15) 个交易日且收盘 ≤ 成本 → time_stop 卖单 |

watch 状态机对应：`watching → pending`（买单生成）`→ holding`（成交）`→ exited`（清仓）；`watching → suspended`（人工挂起）`→ watching`（激活）；任意活跃态 `→ blacklisted`（两亏）。

### 已交易股票历史库（原书校对补全，2026-10-18）

达瓦斯自称**全书最重要的内容**：对每笔已完成的交易做记录，避免重复犯错。三记录制度：

| # | 记录 | 落库位置 | 录入方式 |
|---|------|---------|---------|
| ① | 买入理由 | `plan_order.reason_json`（六问答案） | 自动（planner 生成计划时） |

- **战绩视图**：`darvas review list [code]`——每股交易次数/胜负/总盈亏/最新教训；单股模式列每笔明细，未写复盘的仓位给出录入命令提示。

### 股票池五池模型（2026-10-21 用户最终定义）

> 达瓦斯的选股是一条**五池漏斗**：前三个池是**流入路径**（快照→跟踪→交易），后两个池是**反馈结果**（赢家加权、黑名单拉黑）。原书行号指 `[OCR]_我如何在股市赚了200万_20261016_2002.txt`。

| 池 | 名称 | 含义 | 原书依据（行号） | 系统落库 | 状态 |
|----|------|------|----------------|---------|------|
| 1 | **每日快照池** | 全市场扫描结果，源头 | L1895「每周翻周刊挑……每次只增加一支」+ L1063 四条件 | `candidate` 表（append-only 快照） | ✅ |
| 2 | **持续跟踪池** | 只看不买，盯突破 | L1063「还运行在箱体里才继续关注」 | `watch`（stage=watching） | ✅ |
| 3 | **交易池** | 真买+加码 | L1063-1075「观察满意才下达停损买单」 | `watch`（pending/holding）+ `position` | ✅ |
| 4 | **赢家池** | 老朋友，下次优先纳入池 2 | L1995 Thiokol「久经考验的老朋友」 | 无独立表，B3 历史库记录战绩 | ❌ 未实现 |
| 5 | **黑名单池** | 吃两次亏永不再碰 | L1143「吃两次亏我再不碰」 | `watch`（stage=blacklisted） | ✅ |

**流转路径**：

```
池1 每日快照 ──入池──→ 池2 持续跟踪(只看不买) ──再发信号──→ 池3 交易(真买)
                                                              │
                                    ┌─ 赚钱 ──→ 池4 赢家(加权) ──回池2 优先纳入
                                    └─ 亏1-2次 ─→ 池5 黑名单(永不再碰)
```

**关键澄清（2026-10-21 用户纠正）**：
- 「候选池」和「观察池」**不是两个池**，而是「每日快照→持续跟踪」这一条流入路径上的**两个阶段**，对应系统 `candidate` 表和 `watch(watching)` 表的工程拆分。
- 系统**实际是五池**，不是四池：因为快照（append-only 瞬时结果）和跟踪（有生命周期的持续状态）语义不同，值得分开——用户拍板按五池理解。
- 前三池是**流入漏斗**（越往下越少），后两池是**反馈结果**（从交易池回流），不是并列的五张表。

**两个差距（G1/G2 已于 2026-10-21 落地实现，均经盘书确认有原著依据）**：

- **G1 观察缓冲 ✅ 已实现**：
  - **原著书证**：L1895「当我看到一支感兴趣的股票……会要求经纪人把它的报价发送过来。**我每次只会增加一支**。然后……**在决定是否值得投资前，仔细研究这支股票**」；L1063「如果电报报价表明还运行在箱体里，我就打算**继续关注**……观察它是否在向新箱体突破」。
  - **实现**：planner 生成首腿买单前，检查 `watch.added_date` 距 planDate 的交易日数 < `pool.min_watch_days`(3) 则跳过（条件挂起，不占名额）；pyramid 加码不受限。参数 migration 0012，单测 `TestPlannerMinWatchDays` / `TestPlannerMinWatchDaysExpired`。

- **G2 老朋友优先纳入 ✅ 已实现**：
  - **原著书证**：L1995「我和 Thiokol 现在是**久经考验的老朋友**了」；L1997「我给予 Thiokol 的止损条件总是比其他股票宽松得多，其中**部分原因在于**，我真的对这支股票很有"感觉"，**另外也是因为，我充分利用了特别认购账户提供的便利**」。
  - **关键澄清**：止损放宽**确有其事**，但达瓦斯给了三个理由——①投缘"感觉"、②特别认购账户（融资/保证金便利，A 股无等价物）、③曾两次免于提前售出的实证。**最终仍守住纪律**：L2000「但我还是决定由我设定的止损位来最后拍板」。
  - **实现**：`TradeRepo.IsOldFriend(code)`（最近连续 2 笔平仓均盈利）判定老朋友；planner 遍历信号前对老朋友 breakout 稳定排序排前，竞争试探预算时优先成交。**止损不动**（放宽止损的三理由不可复制）。亏损计数照常累加，亏 1 次照常处理、亏 2 次照样进池 5 黑名单。单测 `TestIsOldFriend`。

## 8. 每日纪律（达瓦斯的时间观）

达维斯在环球巡演中操作，**每天只在固定时间收一次电报报价**，其余时间完全不看行情。这是体系的隐性支柱：

1. **决策基于收盘价**，不基于盘中波动（盘中波动=噪音）
2. **固定时间做固定的事**，其余时间远离市场
3. **订单预先挂好**（停损买单/止损卖单），盘中无需人工判断
4. 名成后在交易大厅做日内交易亏掉10万美元的教训 → **本系统不做任何日内逻辑**

系统的调度器（`scheduler`）就是这条纪律的程序化：见《01-requirements》§4 每日时间表。

## 10. 体制标定的教训（M8.7 证伪 → M8.8 替代，方法论沉淀）

> 本节记录一次干净的方法论示范。详见 `archive/12-m8.7-regime-root-cause.md`、`archive/13-m8.8-breadth-unit-sizing.md`。

**教训**：用箱体引擎标指数 = 套错了工具。sh000001 全历史 0 个 confirmed 箱体（2016-2018 全熊、零切换）被一查就证伪的硬数据证伪，随即退役，不修补、不降级保留、不在报告里含糊带过。三版判定标准（动量法 60±10% / 箱体法多数投票 / 箱体法单一指数）**全是我们自己的工程假设，达瓦斯原书无此量化定义**——这是诚实承认假设边界、不为假设找借口的纪律。

**替代**：M8.8 改用系统自身 box.Scan 扫出的全市场 broken_up/broken_down 事件流统计 20 日宽度比率（内生法，不向外求指数箱体）。但 M8.8 自身仍待验收（见 docs/18）。

**宪法级保留**：第 0 条「众人恐慌我更恐慌，众人贪婪我更贪婪」不随 M8.7 退役而撤回——它高于任何单一标定技术。第 0 条的落地由 M8.8 单位制承担，M8.7 失败只是其**技术前提**失败，不是规则方向失败。
