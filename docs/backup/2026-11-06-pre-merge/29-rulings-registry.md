## 二、判定口径（什么算「显著」）

> 与 `60 §4` 判据总则**同一套**，此处保留原始表述，`60 §4` 是执行侧唯一副本。冲突以 `60` 为准。

1. **样本**：每单位净利 n≥30 才下结论；regime 类另报有效段数 m≥20，**n 与 m 并列报告**。
2. **方向**：保本胜率 = `|平均亏损| / (平均盈利 + |平均亏损|)`；实际胜率 − 保本胜率 ≥+2pp 有 edge、±2pp 内无、≤−2pp 负 edge。
3. **集中度**：前三赢家占 gross_win >60% 必须标「少数交易撑起」，并同时报**剔除前三净利**。
4. **跨年**：逐年符号必须列出；连续 ≥2 年同符号才初步认可。B 类裁判口径 = **改善年数 ≥3 且唯一负值落在噪声门槛内**。
5. **噪声门槛**：`±1,719 元/年`（新基线已重标）。旧 `±600 元/年`、`3% 收益率`、`35% 集中度` 全部出自旧基线，**作废**。
6. **禁挑单点**：不得挑单点最优档；分带切点是预设规则，禁按结果合并/拆分/挪界。

## 四、研究与结论纪律（仍有效）

- 只使用达瓦斯理论；现有 MA60 仅作已登记的大盘闸门，不将其他技术指标引入买点规则（`00 §9`）。
