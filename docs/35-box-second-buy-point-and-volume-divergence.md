## 0. 一句话总纲

一套 box 结构，有**上轨**和**下轨**。两套买点各盯住一条轨：

- **darvas-box-upbreakout 盯 box 上轨**：交易「向上突破」。顺势追突破，低胜率、长持、吃大肉；（已实现）
- **darvas-box-pinbar 盯 box 下轨**：交易「向下假跌破形成的长下影 Pinbar」。逆势抄反转，或高胜率、短持、吃小肉。（未立项）

两者**不是**两套并列系统，而是**同一批机会在上下两条轨上的两种切入**：
一个在突破上轨时顺势追，一个在假跌破下轨时逆势抄。

> **方向边界（永久写死）：本系统是 A 股多头系统，只做多、弃看空。**
> 原书的 pinbar 是双向信号（长下影=看多、长上影=看空）。本系统只取**看多 Pinbar**（长下影、下轨假跌破反转向上）这一半；
> 「看空 Pinbar」（长上影、上轨假突破反转向下）是原书的做空信号，**弃用**，绝不把看空信号误当买点。

量不是单独的指标，量是**分歧**；**放量是改变的力量，缩量是维持的力量**，而这两句话的含义又取决于趋势所处的位置——这正是当前 P1-4 量比实验在问的东西。

## 1. 上轨三分：低胜率是数学，不是缺陷

对「向上突破上轨」之后的路径，切分（各约 1/3）：

1. 上突破，且是真突破；
2. 上突破，失败；
3. 上突破，失败后再次真突破。

**「各约 1/3」目前是经验假设，不是实测概率。** 但它立刻推出一个硬结论：

> 单一 upbreakout 买点，真突破只占约 1/3；有 2/3 的突破会先失败。
> 所以**低胜率是这套形态的天性，不是系统缺陷。**

这一条解释了系统里那些「看起来保守」的设计为什么对：

- **早止损是命门**：既然 2/3 会失败，止损慢一点，就是把有限的失败损失放大成不可控的亏损；
- **时间止损（staledays）不是多余**：很多失败突破不会立即崩，而是「涨不动了」，等它耗着就是浪费仓位和机会成本；
- **让利润奔跑是另一条腿**：正期望靠的是那 1/3 真突破里的少数大赢家（P2-5 已实测：46 笔 MFE>50% 的大赢家贡献了系统全部利润 +1,133,049）。

**所以系统的本质是一句话：低胜率形态里，用止损压住亏损的厚尾，用大赢家补齐收益的右尾。**

### 1.1 达瓦斯原书依据（box 理论原文 + 一个关键事实）

upbreakout 的思想来源是达瓦斯《我如何在股市赚了200万》第 4 章「发展箱体理论」。关键原文（OCR 核对）：

> 股价总是沿着这一趋势展开一系列波动，或者我将其称为「箱体」。股价会在高低点之间不断波动，围绕这一涨跌波动区间画出的区域就代表一个箱体。
>
> 当我感兴趣的某支股票的股价波动箱体，像金字塔一样层层叠加，且当时股价正处在最上面的一个箱体里时，我开始关注这支股票。
>
> **当我时刻关注的走势是，向上突破到下一个股价更高的箱体时，我就会买进。**
>
> 一旦跌破本箱体的下轨，就意味着股价正在跌回一个更低的箱体里……只要股票在上涨我就不应卖出，应该在股价箱体开始反转的时候卖出（配合不断上移的止损卖单）。

**★ 一个必须写死的关键事实：达瓦斯原书没有「量比」这个门槛。**

- 他的买入判据是**纯价格**：突破箱体上轨就买，跌破下轨就卖，止损随箱体上移。
- 量在他书里只是观察项，不是判据——而且突破时往往还是**放量**的（原书：大莱卡「最后一次突破时的周成交量达到 52 600 股，是拆细以来最大的一周」）。
- **所以系统里那个 2× 量比闸门不是达瓦斯的，是后人加进来的「放量突破确认」观念。** 这正是 P1-4 量比实验在验证的真问题：这个后加的闸门该不该留，不是「达瓦斯原教旨对不对」。

## 2. 下轨三分（pinbar 的镜像）：同一个 1/3 结构，倒过来看

pinbar 盯的是**下轨**，它的切分是上轨三分的**镜像**——向下跌破下轨后：

| # | 路径 | 占比 | 性质 |
|---|---|---|---|
| 1 | 向下跌破下轨，又收回 box | 1/3 | 假跌破（收回来了） |
| 2 | 向下跌破下轨，收回 box，**再次下破** | 1/3 | 先假后真（中间回过 box 一段时间） |
| 3 | 向下跌破下轨，收不回来 | 1/3 | 真跌破 |

把上轨三分和下轨三分并排放，对称轴一目了然：

| | 上轨（upbreakout 视角） | 下轨（pinbar 视角） |
|---|---|---|
| 1/3 | 真突破 | 假跌破（收回） |
| 1/3 | 失败 | 先假后真（收回又跌破） |
| 1/3 | 失败后再真突破 | 真跌破（收不回） |

**这是本文最重要的一个结构观察：pinbar 的三分不是新发明，它就是 upbreakout 三分在镜子里倒过来。** 同一个「1/3 / 1/3 / 1/3」的数学结构，一个从上方突破看，一个从下方跌破看。

但「镜像」只说明了**结构对称**，还没说明 pinbar **为什么**高胜率。要回答这个「为什么」，必须回到《裸K线交易法》原书——下一节是关键。

## 3. 从《裸K线交易法》读到的 pinbar 本质

### 3.1 Pinbar 不是「动作」，是一根 K 线

许佳冲自己给 Pinbar 的定义只有一句话：

> **主影线长度超过整根 K 线长度 2/3 的 K 线，就是 Pinbar。**

展开就是锤线（长下影）和流星线（长上影）。所以：
- **看多 Pinbar** = 长下影线 = 盘中一度深跌、收盘又拉回 = 在关键位下方「向下假突破」留下的痕迹；
- **看空 Pinbar** = 长上影线 = 盘中一度冲高、收盘又回落 = 在关键位上方「向上假突破」留下的痕迹。

**关键辨析：动作只是过程，Pinbar 是过程结束后留下的一根带长影线的 K 线，信号是这根线本身。**

### 3.2 核心机制：假突破形成影线 = 市场说谎

书里最关键的一段（5.3.2 假突破概念）：

> 假突破是指价格突破了关键位之后，又折返到该关键位突破以前的价格，并且向反方向运行，即突破失败。
> 假突破是机构洗盘，暴露了机构的真实意图——**就是突破的反方向**。
> **假突破一般发生在关键位，很有可能形成影线，也就容易出现 Pinbar。**

再用书里「匹诺曹鼻子」的比喻点透：

> 影线越长 = 说谎越厉害。市场先骗你说「要跌」（长下影），它真正的意图是「要涨」。

**翻译到我们的 box 语境，pinbar 盯下轨的机制就通了：**

- box 下轨 = 一个现成的**关键位**（水平位）；
- 价格向下刺破下轨又收回 = 一次**向下假突破**（假跌破）= 在关键位下方留出长下影 = 一根**看多 Pinbar**；
- 这根 Pinbar 的含义是：市场在 box 下轨「说谎了」，真正的意图是**反转向上**。

**所以 pinbar 是反转信号，不是顺势信号。** 它赌的是「下轨假跌破 → 反转向上」，跟 upbreakout 赌的「上轨真突破 → 顺势向上」方向相反、机理不同：

| | 方向 | 赌什么 | 机制 |
|---|---|---|---|
| upbreakout | 顺势 | 上轨真突破 | 突破上轨即追，吃趋势大肉 |
| pinbar | 逆势 | 下轨假跌破反转 | 假跌破收回后抄底，吃反转小肉 |

### 3.3 书里的交易纪律（将来 pinbar 立项的可复算骨架）

《裸K线交易法》第 6 章给了一套完整的研判 + 入场 + 止损规则，逐条可转成可复算字段：

**研判准则「2 + 5 = 7 条」，至少满足 2+2 才可交易：**
- 两个基本条件（必须全满足）：① 处于明显的关键位；② 处于明显的高位或低位；
- 五个细节项（至少满足 2 个）：① Pinbar 在盘面上明显；② **有假突破**（作者最偏爱）；③ 实体含于左眼内、且幅度大于左眼；④ 顺较大级别趋势；⑤ 盈亏比 ≥ 1.5:1。

**入场：** 以「突破入场」最常用——右眼突破看多 Pinbar 的最高价时买入（信号成立）；或回调 38.2%/50% 入场博更高盈亏比。

**止损：** 信号影线极值（看多 Pinbar 的最低点下方）；反向突破影线 = 信号彻底失败。

**止盈：** 下一个关键位。**在 box 语境里，下一个关键位往往就是 box 上轨（或更高）**——这正是 pinbar「从下轨吃到上轨」的波段空间，也就是「小肉」的边界。

**硬纪律：** 每笔盈亏比必须 ≥ 1.5:1，达不到不交易（止损 = 影线极值，止盈 = 下一关键位，取最悲观口径）。

## 4. 为什么是「筛选」，而不是「预测」

- 我们**不预测**某一次突破是真还是假；
- 我们做的是**后验的带状统计**：把历史成交按某个条件（强度、量比、高度、距新高）切成带，看每一带的胜率 / 每单位净利 / 保本胜率 / 利润集中度 / 剔除前三，找出「哪一带系统性地更好或更坏」。

这是「条件验证」，不是「信号预测」。它的产物不是「下次买这个」，而是「这个条件值该定在哪、该不该加/减严」。

**这也是为什么反复强调「剔除前三赢家」和「跨年一致性」**：筛选的目标是找到**成片的、稳定的 edge**，而不是被两三笔大赢家撑起来的假象。

## 5. 「量 = 分歧」，以及它为什么需要一个「阶段」坐标

这套「量 = 分歧」直接来自《简简单单做股票》（与 darvas-box 手法同源，作者只是简化了达瓦斯的下单——不加仓、只下一单）。书里三句原话是这套框架的骨架：

> 成交量代表的就是分歧，这是成交量的本质。买方和卖方的分歧越大，成交量就越大。
>
> **放量是改变的力量，缩量是维持的力量。**
>
> 量重要与否必须与所处位置关联。

把它展开，是「趋势位置 × 分歧」的两维表（书里原文的合并）：

| 位置 | 放量（分歧大） | 缩量（分歧小） |
|---|---|---|
| 突破阻力位（上轨/前高/密集区） | 对抗强、阻力强、突破费力（易假突破） | **主力无分歧、控盘强、突破干净有效** |
| 趋势中段 | 动能延续（燃料） | 趋势维持（无反抗，健康） |
| 跌势已成（趋势末端） | **改变的力量 = 反转/转机先兆** | 维持下跌 |

书里最反直觉、也最关键的那句原话：

> 在前期震荡密集区，一般来说阻力很强，但**如果稍微放量就能突破它，则说明主力因为某种原因无分歧**。

**这一句正是「缩量涨，一直涨」的理论来源：**

- **突破阻力位时，分歧小（缩量）才是好事**。缩量突破 = 主力无分歧 = 控盘强 = 突破干净、更可能延续；放量突破 = 分歧大 = 对抗强、阻力强 = 突破费力、更可能是洗盘或假突破。

**由此，「放量是改变的力量，缩量是维持的力量」还推出一个此前没点破的对称：**

- upbreakout 盯上轨，赌「突破后维持向上」→ 偏爱**缩量**（分歧小、无反抗、维持）；
- pinbar 盯下轨，赌「跌破后反转」→ 偏爱**放量**（分歧大、改变的力量、反转先兆；书里「跌势已成的放量是趋势转变的先兆」正好对应下轨假跌破）。

⚠️ **纪律边界（必须写死）**：这套框架里「主力有没有分歧、有没有控盘」是**不可直接观测的**，不能写成事实因果。要让它变成可验证的东西，必须先有可复算的「位置」定义——只能用 box 序列、突破次序、距 52 周高点、持有路径这些**客观字段**来定位置，禁止看图事后划分。

## 6. 当前 P1-4 量比实验，正是「量=分歧」的第一块实证

这里把新思路和正在跑的实验焊在一起——**它们不是两件事，是同一件事**：

- 当前实验问的是：**突破当日量比低（分歧小）的单子，被 2× 闸门挡掉，是不是误杀？**
- 用「量=分歧」的语言翻译：**上轨突破时分歧小（缩量）可能意味着主力无分歧、控盘强、突破更干净——「缩量涨，一直涨」；2× 闸门等于默认「突破必须放量（分歧大）才有效」，这个默认值本身该不该动？**

初步信号（2015 全年，volmult=1.0 档；实验仍在进行中，非终值）：

- 1–2× 低量比带：n=65，总盈亏 +296,701，胜率 38%，剔除前三 +158,668；
- 2–5× 正常放量带：n=29，总盈亏 −5,246，胜率 28%，剔除前三 −39,571；
- 账户全年净利 +322,292；对照基线（volmult=2.0 档）全年 +24.2 万，放开门槛多赚约 8 万。

跨年方向（2012）：低量比带少亏（−44 vs −427），与 2015 同向，方向一致且超噪声——**H4（2× 门槛是对的）正在被推翻**。

**如果这个方向被四年数据坐实，那结论的深层含义就是：上轨突破时分歧小（缩量）不是缺陷，反而可能意味着主力无分歧、控盘强、突破更干净。** 这正是《简简单单做股票》里「稍微放量就能突破阻力 = 主力无分歧」的实证版。

**注意：本节的 P1-4 数字是进行中快照，正式结论以 `docs/experiments/e17_volmult_report` 为准。**

## 7. 两套买点：同一批机会的两种切入

### 7.1 互补本质：一个顺势追，一个逆势抄

| | 盯的轨 | 方向 | 入场时机 | 赌什么 | 胜率直觉 | 持仓直觉 |
|---|---|---|---|---|---|---|
| upbreakout | 上轨 | 顺势 | 突破即追 | 上轨真突破 | 低（约 1/3 直接真） | 长（让利润奔跑） |
| pinbar | 下轨 | 逆势 | 假跌破收回、突破 Pinbar 高点后进 | 下轨假跌破反转 | 可能高（反转信号 + 过滤） | 短（从下轨吃到上轨） |

**如果 pinbar 的胜率直觉成立，它的机制不是「另一种赚钱法」，而是「把 upbreakout 里『失败后再真突破』的那一段，换成一个胜率更高、但单笔更小的入场」。** 这正是「一套 box、两套买点」的互补逻辑——一个吃大肉（少数长持），一个吃小肉（高胜率短持）。

### 7.2 为什么现在不能做、以及 2019+ 数据的深意

- 现在不做：先把 upbreakout 彻底定型，否则两套信号混在一起，无法归因。
- **2019+ 数据现在不用的真正原因，是要留作 pinbar 的样本外**：如果现在就拿 2019+ 去调 upbreakout 的参数，等 pinbar 立项时，这块样本外已经被污染了。

**2019+ 冻结因此有了一层此前没写透的战略含义：它是给第二套买点预留的「干净赛场」，不是简单的「暂停」。**

### 7.3 将来立项必须先写死的事（按原书补全）

- pinbar 的可复算定义：主影线 > 整根 K 线长度 2/3；看多 Pinbar = 长下影 + 收盘收回 box；
- 关键位 = box 下轨（水平位，现成可复算）；假跌破 = 最低价 < 下轨 且 收盘价 > 下轨；
- 入场 = 右眼突破 Pinbar 最高价（信号成立）或回调 38.2%/50% 入场；
- 止损 = Pinbar 下影线最低点下方；反向突破影线 = 信号失败；
- 止盈 = 下一个关键位（box 上轨 / 前高）；
- 硬纪律 = 每笔盈亏比 ≥ 1.5:1；
- 两套买点同时出现的优先级、资金占用、组合口径；
- 先独立验证 pinbar 的胜率 / 每单位净利 / 持仓时长，再谈组合。
