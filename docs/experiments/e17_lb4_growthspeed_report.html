核心结论

  • 2005–2018 共 1481 笔已平仓交易，其中可复算成长速度 1481 笔、不可复算 0 笔。
  • 成长速度四带每单位净利：+1,015（4–5 日） / +718（6–7 日） / +328（8–10 日） / +320（11 日+）。
  • 成长速度四带胜率：24.9% / 24.8% / 20.2% / 20.3%。
  • H1（成长速度与突破质量单调相关）成立（递减相邻对 3/3）；H2（慢速确认箱体突破质量差）不成立。

读法：成长速度是「箱体两条轨道从确认到闭合花了多少交易日」（top_confirmed→bottom_confirmed），不是寿命（下轨确认→突破）、 也不是阶梯速度（相邻两级隔多久）、不是谱系深度（第几级）。本实验只报相关性分布，不下因果结论（框架 §1.2）。
