## 〇、一句话结论

**Box 的轨迹（身份 + 事件日期）在系统的三种重建路径下逐日全等、可信、可追溯**：
759 票 × 238 交易日 = 180,642 票日，全量真值（A）与生产 800 窗口路径（B）的尾箱与
最新 confirmed 锚 **100% 全等**；共同后缀内事件 **零差异**；增量预过滤路径（C）的
状态恒等式 **50/50 抽查全对**。第 2 项止损上移研究可以把重建结果当事实使用——
但必须遵守 §七 使用须知（两条边界）。

## 四、判据勘误留痕（docs/06 §7.3 两阶段修订）

初版框架 §3.2 判据「洁净箱体 = top_confirmed ≥ 窗口起点+10；洁净事件 = 事件日 ≥ 起点+50」
**被首跑证伪**：missing_clean=165 / spurious_clean=376 / c_loss=115，硬失败。

根因：top_margin 只保证箱体输入落在窗口内，**不保证 A/B 家谱「同箱同史」**——800 窗口重启后
B 家谱与 A 定义性分叉，B 重启箱可整窗口分叉后再同步；A 的洁净箱在 B 中可能以不同分段路径存在。
修订：洁净区改**共同后缀**（从尾往前语义键逐箱相同的段）；C 路删「洁净事件永久丢失」判据，
改**恒等式抽查**。全程见框架 §3.2 勘误段（2026-10-29）。

另一处补账（A1，非判据）：初版对「终态日期早于观测窗（2013）的全史实例」静默跳过（29,805 个），
按纪律补显式计数 `pre_window_terminated`，不入删失账、不入存续分布——补账后 §一 对账恒等式闭合。

## 七、研究使用须知（放行第 2 项的边界，引用本结论前必读）

1. **非池票的 box 状态滞后 p50≈17 交易日是「池=∅ 上界」的固有语义，不是缺陷**：
   C 路（RescanIncremental 池外路径）84% 的票日不重算。止损上移研究只读**持仓票**
   （必在 watch 池内、每日重扫）⇒ 不受此滞后影响；但任何把池外票当日状态当
   「当日真值」的用法都是错的（滞后分布见 §3.2）。
2. **B 路分叉区事件不可见 ≠ 生产 DB 丢失**：trunc_zone_A/B（17,456 / 822）是 800 窗口
   重启家谱的窗口语义，生产研究需要全史事件时用 A 路重放（回放累积），不要查
   生产 box 表——生产表只保状态投影 + 被引用箱（复用键仅 10，折叠罕见但存在）。
3. **身份真空天 23.9%**：近四分之一票日 DB 身份键为 (0,0)（上轨未确认，跨日不可区分）。
   涉及「box 出生日」的研究一律以 A 路重放的实例序为准，不信 DB 行身份。
4. 终态占比里 invalid 占 33.1%——作废重启是常态而非异常；止损研究的事件口径
   （broken_up/broken_down）已天然排除 invalid，无需额外过滤。
