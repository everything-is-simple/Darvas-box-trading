# E17 滚雪球复利统计：baseline vs baseline+（2005–2018）

> 生成器：`scripts/e17_snowball.py`（只读 28 个回测库的 `equity_snapshot`，逐日链式复利）
> 复利口径：`level_d = level_{d-1} × (total_d / total_{d-1})`；跨年直接衔接（每年首日权益恒 = 1,000,000，因子 = 1）
> 命名：**baseline** = E17 基线（gate=off）；**baseline+** = E17 + MA60 仓位闸门（stop，B-2）

---

## 一、一句话结论

- **加法口径**（现有总账）：baseline +842,801（+84.28%）→ baseline+ +974,937（+97.49%），差额 +132,136（相对提升 +15.7%）。
- **滚雪球口径**（14 年复利）：1,000,000 → baseline **2,610,550**（+161.1%，年化 **+7.09%**）；baseline+ **2,961,561**（+196.2%，年化 **+8.06%**）。
- 复利终值差 **351,011**（baseline+ 多 +13.4%），小于加法差额的直观感受——因为复利会把早年亏损的「拖累」也一起放大。

**同一条曲线，两种算法差了一倍**：加法说 14 年赚 84%（年化 4.5%），复利说赚 161%（年化 7.1%）。差在哪：加法把 2008/2011 的亏损当成「减掉一笔钱」，复利把它们当成「本金变小后重新起跑」——后者才是真实资金的命运。

## 四、算法（可复现）

```
level = 1,000,000
for year in 2005..2018:
    prev_total = 1,000,000          # 该年首日权益（回测每年从 100 万起跑）
    for (date, total) in equity_snapshot[year]:
        level *= total / prev_total # 逐日复利因子
        prev_total = total
        record(date, level)
```

**HARD 校验（脚本内断言，失败即不产物）**：
1. 28 个库齐全（baseline / baseline+ × 2005–2018）
2. 逐年链式因子 ≡ 该库年末权益 / 1,000,000（容差 1e-6）
3. 逐年交易日数之和 ≡ `metrics.days` 之和
4. 年度复利收益 ≡ `metrics.ret`（容差 1e-5）
5. Σ年净利 ≡ `metrics.pnl` 之和

## 五、诚实边界（结论必须携带）

1. **这是「按年收益率的复利推演」，不是连续交易路径的重跑**。真连续跑时，第 5 年的下单金额会基于复利后的更大权益，整手取整、7 只持仓上限、黑名单冷却的边界行为都会变化；本推演假设「收益率尺度不变」，误差来自取整与结构约束。
2. **跨年强制衔接**：年末未平仓头寸按市价结算后带入下一年起点（回测的 equity_snapshot 已含浮盈浮亏），真实账户跨年不会平仓，此处忽略隔年跳空差异。
3. **容量未计**：资金放大后，单票 2% 权益的绝对金额上升，A 股流动性与冲击成本未建模（14 年复利到 260–300 万仍属小资金，影响可忽略）。
4. **无风险利率取 0**：夏普为相对指标，不改变两者比较。
5. **baseline+ 的优势仍受 2013/2017/2018 拖累**：复利口径下这三年把「本金变小」的效应也放大了，其改善幅度（+13.4% 终值）小于加法口径的直观感受（+15.7%）。

## 六、擂台规则建议（给下一个挑战者）

1. **新 baseline = baseline+**：14 年末 **2,961,561**（+196.2%），CAGR **+8.06%**，最大回撤 **-8.03%**，Calmar **1.00**。
2. 挑战者的判据不再是「Σ净利更高」，而是 **同期复利终值更高 且 最大回撤不更差**（双指标，防「靠加杠杆赢」）。
3. 逐年收益率必须公开，禁止只报终值——复利终值对单年极值极敏感（2015 一年贡献了终值的相当比例）。
4. 样本外（2019+）暂不可用（用户 2026-10-26 拍板），任何挑战者只能用 2005–2018 擂台。
