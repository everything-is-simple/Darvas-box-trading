核心结论

  • 2005–2018 共 1481 笔已平仓交易，其中止损从未上移（ratchet=1.0）995 笔（67%），上移过 486 笔。

  • 结论：raiseStops 没有「追不上」的问题。未上移的票 97% 从未涨过 30%（本来就没涨、本来就该亏），真正「涨了很多却因止损钉在低位而倒亏」的受害者仅 1 笔（995 笔里涨过 30% 却亏的），体量可忽略。「上移幅度 vs 净利」的梯度是内生性，不是可干预缺陷。维持现状，不做 B 类。
口径：ratchet = position.stop_price / position_leg.stop_after。 stop_after 是 leg1 建仓时写入的初始止损（= 被突破箱上轨 × 0.97）， stop_price 是清仓时的最终止损。ratchet=1.0 = 止损从未上移； >1.0 = 止损已被 raiseStops 抬到初始位之上。这是「总上移幅度」的成本归一化代理，非每次上移的事件账。
内生性（本文最关键的口径声明）：止损上移本身是「股价大涨」的结果——股票涨了， 箱体才往上叠，raiseStops 才把止损往上抬。所以「上移多 → 赚得多」很可能是同义反复，不是因果。 因此不能只看总净利梯度，必须看「剔除前三赢家后」低上移带是否仍显著更差，以及回吐率是否显著更高（框架 §5 转 B 门槛）。

内生性拆解（本实验的真正判据）

「未上移 → 净利差、回吐高」这个相关，到底是「止损没跟上」的可干预缺陷，还是「本来就没涨」的自然结果？ 关键区分是：未上移的票里，有没有「曾经大涨、却因止损钉在低位而回吐倒亏」的受害者？

未上移的 995 笔里，曾浮盈 >30% 的只有 33 笔（占 3%）， 其中最终亏损的 1 笔。也就是说：97% 的未上移票从来没涨过 30%——它们不是「涨了没跟上止损」，是「压根没涨、本来就该亏」。

最终裁定：维持现状，不做 B 类
真正「涨了很多却因止损钉在低位而倒亏」的受害者仅 1 笔，体量可忽略。「止损上移幅度 vs 净利」的梯度是内生性（涨得多→止损自然上移→赚得多），不是 raiseStops「追不上」的可干预缺陷。raiseStops 规则无需改动：3 日确认 + 入场箱不参与 两条限制都不构成出血口。本项关闭为观察结果，不做 B 类补事件账。
