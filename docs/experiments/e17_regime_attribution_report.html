1.3 统计口径（每桶齐备）

胜率 = 盈利笔数/已平仓笔数；每单位净利 = Σpnl/Σunits（1 单位 = 2% 权益；E17 阶梯 t1=3 / t2=2 / t3=1 / t4=0.5）； 保本胜率 = |avgLoss|/(avgWin+|avgLoss|)；缺口 = 胜率 − 保本胜率；PF = 毛盈利/|毛亏损|； 集中度 = 前三赢家/毛盈利；剔除前三净利 = 净利 − 前三赢家合计。 n / m：n 是名义笔数，m 是该桶覆盖的 regime 段数——同一段内的多笔交易共享同一大盘状态， 不是独立观测；m < 20 一律不给裁定。
