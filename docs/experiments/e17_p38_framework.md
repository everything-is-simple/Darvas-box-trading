## 一、一句话结论

达瓦斯"买什么"的最后一块，验证「升势」（箱体顶底双抬）与「最高 Box」（本轮趋势最高 / 历史最高两种口径）
是否构成可采纳的**买入准入门槛**。升势为**硬门槛**（拦截非升势票），最高 Box 为**二次择优**（多候选中只留最高）。

## 二、原书依据（查 OCR 原文，2026-11-03 逐条核对）

文件：`F:\《股市浮沉二十载》\2011.usa.达瓦斯.我如何在股市赚了200万\...\我如何在股市赚了200万.达瓦斯_20260322_095344.md`

| 概念 | 原书原文（OCR 行号） | 提炼 |
|---|---|---|
| **升势** | L1312「股价波动箱体，像金字塔一样层层叠加，且股价正处在最上面的一个箱体里」；L1328「我需要的是股价不断进入更高箱体的股票，而不是不断进入更低箱体的股票」 | 箱体**层层抬高**（整个区间上移），不是只看上轨 |
| **最高 Box（历史）** | L3709/L3804「我严格遵守创历史新高的原则」「我只对那些突破前期高点的股票感兴趣，90% 达不到」 | 原书口径是**创历史新高**（绝对历史最高箱顶） |
| **趋势反转** | L1482「当股价箱体的金字塔开始向下时，就表明到了抛出的时候」 | 升势的否定信号 = 箱体不再抬高、开始走低 |

**关键结论**：原书对「升势」的定义是**箱体金字塔层层叠加**（顶底都抬高），对「最高 Box」是**创历史新高**。
但原书从未给「一轮上升趋势的起点」精确锚——它是跟随式的，只凭「金字塔是否还在向上叠」判断。
故「本轮趋势」的起点需要我们用**近 N 日窗口**代理（达瓦斯自己看"过去 4~6 个月"，见 L3848 问答）。

## 三、口径（用户 2026-11-03 逐条拍板）

| 项 | 最终口径 | 依据 |
|---|---|---|
| **升势判定** | **顶底双抬**：当前 Box 的 `top > 前箱 top` 且 `bottom > 前箱 bottom` | 原书"金字塔层层叠加"= 整个箱体区间上移；用户补充"箱有顶有底" |
| **最高 Box 口径** | **两种都做对比**：① 本轮趋势最高（近 N 日最高箱顶）② 历史绝对最高（该票全部箱体 top 极值） | 原书是"创历史新高"；用户建议"本轮趋势最高"，并要求两种比较 |
| **最高 Box 用途** | **准入门槛**（非最高不买），且作**二次择优** | 用户拍板 |
| **组合方式** | **升势硬门槛 + 最高 Box 择优**（升势先拦截，最高 Box 在多候选中选一） | 用户拍板 |
| **窗口 N** | **多档对比 60 / 120 / 250** | 用户拍板（对应"本轮趋势"的滚动窗口） |
| **本轮范围** | **直接改引擎**（新增参数，默认 off） | 用户拍板 |

### 3.1 参数设计（新增 4 键，全部默认 off/0，保基线等价）

| 参数键 | 默认 | 含义 |
|---|---|---|
| `buy.uptrend_only` | `off` | `on` 时拦截非「顶底双抬」的买入 |
| `buy.highest_box_mode` | `off` | `off` / `trend`（本轮趋势最高）/ `alltime`（历史最高） |
| `buy.highest_box_window` | `120` | `trend` 模式下，近 N 交易日的最高箱顶窗口（60/120/250） |

> 说明：`highest_box_mode=off` 时无最高 Box 过滤；`trend` 用近 N 日（按 broken_date 距信号日）最高箱顶；
> `alltime` 用该票自上市以来全部箱体的 top 极值。两者都要求「当前 Box.Top == 该极值」才算"处于最高 Box"。

### 3.2 前驱链的口径

- 「前箱」= 当前 Box 的 `prev_box_id` 指向的那个 Box（沿 `box.prev_box_id` 链，LB 系列已验证前驱链完整 100%、0 断链）。
- `prev_box_id = 0`（首级箱体）时：**保守放行**（无前驱可比，视为升势成立）——LB-2 已证首级箱体仅 9/1481（≈0.6%），影响可忽略。
- 前驱获取失败（库内无该 id）：保守放行，不拦截（避免数据缺失造成误杀）。

## 四、数据可得性（全部已核实，无需新增 repo 方法）

`BoxRepo.Ladder(code)` 已一次返回该票全部箱体（含 `id/top/bottom/prev_box_id/broken_date`），
升势与最高 Box 两种口径都可在内存里从 Ladder 结果计算，**无需像上一版草稿那样新增 BoxByID**。

- 升势：取当前 box 的 `prev_box_id`，在 Ladder 结果里找对应前驱，比较 top/bottom 双抬。
- 本轮趋势最高：Ladder 里筛 `broken_date ∈ [信号日 − N 交易日, 信号日]` 的 box，取 top 极值。
- 历史最高：Ladder 里取全部 box 的 top 极值。

`box.status` 在库内是 **TEXT**（`forming/confirmed/broken_up/broken_down/invalid`），
`contract.BoxStatus` 底层也是 string，`Ladder`/`LatestNonFormingBox` 已用 `var status string` 正确读取。
**上一版草稿（Claude）的 `BoxByID` 用 `var status int` 扫 TEXT 是必崩 bug，本框架明确排除该写法。**

## 五、判据（沿用项目统一口径）

分带必报：胜率 / 每单位净利 / 保本胜率 / 利润集中度 / PF / 缺口 / **剔除前三赢家净利** + 逐年一致性。

- **升势硬门槛**：`on` vs `off` 的端到端对比（同库、同参数集、仅差 `buy.uptrend_only`）。判据：`on` 档剔除前三净利 ≥ off 档、且改善年数 ≥ 3（参考 LB-4 B 类裁判口径），才值得采纳。
- **最高 Box 择优**：`off` / `trend×{60,120,250}` / `alltime` 六档，看「只买最高 Box」是否改善。判据同上；若多档全在噪声内，则登记"最高 Box 无可采纳梯度，维持不筛"。

### 5.1 `alltime`（历史最高箱）已于 2026-11-03 13:20 否决 ⛔

用户裁决「这档不用再试」。**依据（2007 单年，n=98 → 56）**：

| 指标 | off 基线 | alltime | 变化 |
|---|---|---|---|
| 交易笔数 | 98 | 56 | −42（只保留 57%） |
| 已实现净利 | 457,133 | 29,555 | **−93.5%** |
| 剔除前三净利 | 214,934 | **−78,100** | **转负** |
| 胜率 | 33.7% | 23.2% | −10.5pp |
| PF | 2.81 | 1.15 | 几乎不赚钱 |
| edge（胜率−保本率） | +18.4pp | +2.4pp | 优势消失 |
| 利润集中度 | 34.1% | 48.3% | 更依赖大赢家 |

成本收益核算：**挡掉 74 笔赚钱交易（合计 +438,110），只换回 32 笔（合计 +13,362）——33.8 倍。**
统计：每笔净利 Welch t = −1.61（p=0.110，五档中最接近显著且方向最差）；胜率 Fisher 精确 p = 0.202。

> 口径本身的问题：「自上市以来最高」在 A 股等于"只买上市后一路创新高的极少数票"，
> 1990–2007 的老股历史箱体极值远高于当下，实际退化成"只选次新股/超级强势股"，样本量腰斩且选到的都是末段。
> **连带 `up_all`（升势+alltime）一并作废**——破坏来自 alltime 这个选择器，叠加升势救不回来。
> 已跑的 `all_2007` 库保留作证据，不再新增；扫描队列 28 → 20 库。


> ⚠️ 内生性警告（血泪教训）：升势/最高 Box 天然与「强势股」高度相关（P0-3 已证 MA60 下方负 edge、
> M9.0 已证甜区≤15%），须用**剔除前三 + 受害者计数**两把刀拆掉"强势股内生性"再下结论，
> 不得把「涨得多的票自然满足升势/最高」当成"升势/最高 Box 本身是 edge"。
