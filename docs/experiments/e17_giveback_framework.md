## §1 实验目的与边界声明

### 1.1 本轮要回答的三个问句

1. 已平仓交易在持仓期间**最大浮盈（MFE）有多少**、最后**回吐掉多少**？回吐率的分布长什么样（中位数/分位/直方图）？
2. 回吐是**长持赢家的病**（浮盈很大但吐掉大半）还是**短持亏损单的必然**（本来就没浮盈）？——这决定 P2-6（移动止损）该不该立项。
3. 按持有天数分带后，每单位净利的符号是否复现 `docs/05` M10.5 的「**持有时间 = 唯一赚钱因子**」？

### 1.2 本轮明确回答不了的六件事

| # | 回答不了 | 原因 |
|---|---|---|
| 1 | **移动止损能赚多少** | 本实验只量化「回吐了多少」，不模拟「在哪止盈」。任何「理论上可多赚 X」都只是**上限**：真实移动止损会在假信号上被反复切碎，且无法卖在最高点。规则模拟必须走 **B 类**（P2-6）。 |
| 2 | **因果** | 回吐率与持有天数、波动率、市场环境高度混杂。牛市浮盈大→回吐绝对值大是机械结果，不是「牛市该止盈」的证据。 |
| 3 | **入场端是否更值得改** | 本实验只测出场端。即使 H1 成立，也不能推出「P1-4 该降级」——两个维度互不排斥，优先级由 `docs/29` §五统一裁定。 |
| 4 | **MFE 的精确值** | 库内 `adj_factor` 恒 1.0（**未复权**）。持仓期间若发生除权除息，除权前的高价会把 MFE 抬高、回吐率被打成「虚假的大」。§3.5 登记了诊断与稳健性切片，但**无法修复**，只能标注污染面。 |
| 5 | **样本外有效性** | 2005–2018 是全部参数被选定所用的同一段历史（`docs/29` §八.6）。结论只用于提假设。 |
| 6 | **日内路径** | 只有日线。同一天内先冲高后跌停与先跌停后冲高在数据上不可区分，MFE 因此是**日频上界**（真实可交易浮盈 ≤ 本口径）。 |

### 1.3 结论句式模板（强制措辞）

跑完写结论时，必须按以下句式组织，不得省略括号内的限定项：

> 在 2005–2018 的 1328 笔已平仓交易中，可检验 __ 笔、不可检验（MFE≤0）__ 笔；盈利单回吐率中位数 __%、回吐率 >50% 的盈利单占 __%；全样本回吐金额 ¥__，其中来自持有 ≥11 日的 __%、来自「亏损且持有 ≤10 日」的 __%。
> H1（移动止损价值大）**成立/不成立**；H2（出场不是出血口）**成立/不成立**。
> 「移动止损能赚多少」**本实验不回答**，只能由 P2-6 的 B 类回测回答。

禁止出现的写法：`回吐说明该止盈`、`移动止损能多赚 X 元`、`持有越久越好`、`证明短持止损是错的`。

## §2 实验假设（可证伪形式）

| 编号 | 假设 | 判据（三/二条同时满足才算成立） | 证伪条件 |
|---|---|---|---|
| **H1** | **移动止损潜在价值大**：回吐主体在长持赢家身上 | ① 可检验**盈利单**中 `回吐率 > 50%` 的占比 **≥ 50%**；② 全样本回吐金额中，来自 `hold_bars ≥ 11` 的占比 **≥ 50%**；③ `hold_bars ≥ 21` 两带的每单位净利为正，且跨年过滤后正号比 `ratio_f ≥ 0.50`（`Mf ≥ 8`） | ①或②任一条不满足 → **不成立**；③不满足 → 记「不成立（长持并非赢家，回吐无利润可保护）」 |
| **H2** | **出场不是出血口**：回吐集中在「本来就没浮盈」的短持亏损单 | ① 全样本回吐金额中，来自「`pnl < 0` 且 `hold_bars ≤ 10`」的占比 **≥ 50%**；② 同一批样本的 MFE 金额占全样本 MFE 金额 **< 20%** | ①或②任一条不满足 → **不成立** |
| **H3** | **方法论对照**：按持有天数分带能复现「持有时间 = 唯一赚钱因子」 | L1 五带的每单位净利，5 个相邻对中 **≥ 4 个**随持有天数递增（严格大于） | 递增对 < 4 → 登记「未复现」，并写明与 `docs/05` M10.5 的口径差异（14 年 vs 5 年、1328 笔 vs 570 笔） |

**H1 与 H2 不是互补关系。** 两者可以同时不成立（回吐分散在长短两端），也可以同时成立（长持赢家吐得多、短持单本来就没浮盈——两句话都对）。裁定允许输出「H1 成立 / H2 成立」「H1 不成立 / H2 不成立」等四种组合，**禁止**为了叙事漂亮把混合结果压成二选一。这个双判据设计是本次框架最重要的防线：它允许实验得出「两个方向都不值得做」的结论。

**判据阈值（50% / 20% / ≥4 个递增对）在跑数之前写死**，不得看结果调整。

## §3 数据准备过程

### 3.1 只读纪律

- 一律用 `sqlite3.connect("file:<db>?mode=ro", uri=True)`。
- 不写回测库、不碰生产库 `darvas.db`（`docs/06` §6.2 库隔离）。
- 不重跑任何回测、不改任何参数、不重建任何索引。

### 3.2 取数口径

单库两条 SQL（持仓 + 行情），不跨库 JOIN：

```
-- ① 持仓样本
SELECT p.id, p.code, p.opened_date, p.closed_date, p.avg_cost, p.realized_pnl,
       p.close_reason, o.reason_json,
       (SELECT SUM(qty)         FROM position_leg WHERE position_id=p.id) AS qty,
       (SELECT SUM(qty*price)   FROM position_leg WHERE position_id=p.id) AS cost_basis
FROM position p
JOIN position_leg l ON l.position_id=p.id AND l.leg_no=1
LEFT JOIN plan_order o ON o.id=l.plan_order_id
WHERE p.status='closed'

-- ② 持仓窗口行情（逐笔按 code + 日期区间取）
SELECT date, high, close FROM daily_bar
WHERE code=? AND date>=? AND date<=?
```

提取字段：

| 字段 | 来源 | 用途 |
|---|---|---|
| `year` | 库文件名 `bt_e17_<year>.db` | 逐年分组 |
| `opened_date` / `closed_date` | `position` | 持仓窗口（含两端） |
| `avg_cost` | `position` | MFE 分母（成本） |
| `qty` / `cost_basis` | `position_leg` 求和 | **实际收益率分母**（见 §3.3 陷阱） |
| `realized_pnl` | `position` | 实际盈亏（净额，含双边费用） |
| `units` | `reason_json.units` | 每单位净利分母 |
| `newhigh_distance_pct` | `reason_json` | t1 甜区切片（≤15%） |
| `box_top` / `box_bottom` | `reason_json` | 记录用，不分带（OFAT） |
| `close_reason` | `position` | 附录切片（退出方式），不作判据 |
| `high[]` / `close[]` | `daily_bar` | **MFE 的唯一原料** |

### 3.3 样本漏斗与一个必须绕开的陷阱

**陷阱：`position.qty` 在平仓后被清零。** 实测 2014 库 100 笔已平仓头寸 `qty` 全为 0，若照 `docs/29` 原文公式 `实际收益率 = realized_pnl / (avg_cost × qty)` 直接算，分母为 0，全部样本作废。
**绕开方式**：数量与成本一律从 `position_leg` 求和（`qty = Σleg.qty`、`cost_basis = Σleg.qty×leg.price`）。已实测 `avg_cost × qty == Σ(qty×price)` 在 1328 笔上**逐笔完全相等**（容差 1e-3 相对误差，0 笔不符），故两路成本口径等价，登进附 A。

| 步 | 说明 | 剩余 |
|---|---|---|
| 1 | 14 个回测库（2005–2018） | 14 库 |
| 2 | `leg_no = 1` 首次建仓 | 1405 笔 |
| 3 | `status='closed'` 且 `realized_pnl` 非空 | **1328 笔** |
| 4 | `cost_basis` / `units` / `newhigh_distance_pct` 缺失 | 0 笔被剔除（实测齐备） |
| 5 | 持仓窗口内 `daily_bar` 为 0 行（无行情无法算 MFE） | 0 笔被剔除（实测齐备） |
| 6 | **有效样本** | **1328 笔** |

第 3 步排除的 77 笔为未平仓头寸（未实现盈亏与已实现盈亏不可比）。**这是唯一的剔除动作**：MFE 算不出来或为负的样本**不剔除**，进「不可检验」登记行（§5.5）。

### 3.4 清洗规则

**只做结构清洗，不做数值清洗。**

- **不剔除极端回吐率**：极端值靠「回吐率直方图的尾部箱」与「利润集中度」暴露，不删。
- **不剔除大赢家**：设为独立切片（§5.6），并从主表提供「剔除前三赢家」列。
- **不按 `close_reason` 过滤**：退出方式本身是本实验的观察对象之一（附录），过滤它会循环论证。
- **不按牛熊分段取舍**：regime 归因属 P0-3，本轮不做。
- **不改权重**：每笔等权计入，不按 `units` 加权聚合胜率。

### 3.5 已知数据偏差（结论必须携带）

- **未复权（`adj_factor` 恒 1.0）**：持仓期间除权 → MFE 虚高、回吐率虚假偏大。
  **诊断口径（跑前写死）**：持仓窗口内存在**收盘价单日跌幅 < −20%** 的样本，记为「疑似除权污染」。
  理由：A 股主板涨跌停 ±10%（ST ±5%），单日真实跌幅超 20% 在日线层面基本只能是除权/送转或数据错误。
  **稳健性切片**：剔除疑似污染样本后重算 H1 的三条判据与回吐率中位数，若结论翻转则必须在报告首屏标注「结论受数据偏差支配」。
- **幸存者偏差**：只用当前仍存在的股票，退市股不在样本内；退市前的暴跌不在 MFE 里（此项会**低估**回吐）。
- **日频上界**：MFE 是日高，不是可成交价（§1.2 第 6 条）。
- **口径差**：本实验的「持有交易日」用该股自身 bar 计数，回测引擎的「持有天数」用市场日历。两者在停牌股上会不同（§4.4 有强制一致性校验）。
- **无基线对照不构成缺口**：本实验只统计 E17 自身，不需要 p05 基线，2005–2013 缺 `bt_p05_<year>.db` 不影响本实验。

## §4 口径定义

### 4.1 核心三式（全部相对成本）

```
cost_basis = Σ_legs (qty × price)              # 总成本（元）
MFE        = max(high[t]) / avg_cost − 1       # 最大浮盈幅度，t ∈ [opened_date, closed_date]（含两端）
ret        = realized_pnl / cost_basis         # 实际收益率
giveback   = (MFE − ret) / MFE                 # 回吐率，仅在 MFE > 0 时有定义
```

`avg_cost = cost_basis / qty`（§3.3 已证等价于 `position.avg_cost`）。

### 4.2 为什么分母用 `avg_cost` 而不用「窗口最低价」

MFE 是**相对建仓成本**的浮盈，不是相对持仓期低点的涨幅。用成本做分母，`giveback` 才能被读成「这轮浮盈最后留下多少」——这是移动止损唯一关心的问题。若用窗口最低价做分母，亏损单会得到荒谬的巨幅 MFE。

### 4.3 回吐金额（元，跨带可加）

```
MFE_amount      = MFE × cost_basis             # 理论最大浮盈金额（日频上界）
giveback_amount = MFE_amount − realized_pnl    # 回吐金额（元）
```

`giveback_amount` 的用途：**它是任何「完美出场规则」能回收金额的上界**（连卖在最高点都只能拿回这么多）。
报告必须同时给「回吐率（%）」与「回吐金额（元）」：前者回答「吐得狠不狠」，后者回答「值多少钱」。**只看百分比会在小仓位上夸大问题，只看金额会在小样本上夸大问题。**

### 4.4 持有天数（分带驱动变量）

```
hold_bars = 该股 daily_bar 在 [opened_date, closed_date] 的行数（含两端）  ← 主口径
hold_cal  = 市场交易日历（sh000001 的 bar）在同区间的行数                  ← 对照口径
```

主口径取「该股自身 bar 数」，理由：与 MFE 同源（同一批 bar），停牌日不构成观察窗口。
**强制一致性校验（HARD）**：`hold_bars` 与 `hold_cal` 落在同一 L1 带的比例必须 **≥ 95%**；若低于 95%，主表改用 `hold_cal` 并在 §10 登记。此项防止「停牌股把长持误判成短持」。

### 4.5 统计口径（每带必须齐备）

| 口径 | 公式 | 备注 |
|---|---|---|
| 胜率 | `wins / closed` | 已平仓头寸中盈利占比 |
| 每单位净利 | `Σpnl / Σunits` | `units` 取自 `reason_json.units`，实测集合 ⊆ {0.5, 1, 2, 3} |
| 保本胜率 | `1 / (1 + 平均盈利/|平均亏损|)` | 即 `|avgLoss| / (avgWin + |avgLoss|)` |
| 利润集中度 | 前三赢家合计 / 毛盈利 | 无毛盈利或前三合计为负时记 `—` |
| 附加 A | 利润因子 PF = 毛盈利 / |毛亏损| | |
| 附加 B | **缺口** = 实际胜率 − 保本胜率（pp） | `docs/29` §八.2 判定用 |
| 附加 C | **剔除前三赢家净利** | 识破「假 edge」的关键列 |
| 附加 D | 剔除前三赢家每单位净利 | 同上 |
| **附加 E（本实验专属）** | **回吐率中位数 / 均值 / P25 / P75** | 分布形态 |
| **附加 F（本实验专属）** | **回吐金额（元）** | 跨带可加，见 §4.3 |
| **附加 G（本实验专属）** | **MFE 金额（元）** | 分母，用于判断「本来有没有浮盈」 |

### 4.6 回吐率的三个技术性边界

1. **可检验集**：`MFE > 0`。`MFE ≤ 0` 的样本（整段持仓最高价都没超过成本）登记为「不可检验（从未浮盈）」，**不进分布**，但**必须在表里占一行**（§5.5）。
2. **回吐率 < 0**：`ret > MFE` 在数学上不可能（实际收益不可能超过窗口最高价相对成本的涨幅）。若出现，一律记为**数据异常**，单列清单，不静默修正。允许的例外只有浮点误差级（`|giveback| < 1e-6`）。
3. **回吐率 > 100%**：`ret < 0` 时的正常结果（浮盈转亏损），**不是异常**，是「浮盈全部回吐并倒亏」的实质。单独设箱（§5.4）。

## §5 分带设计

### 5.1 分带一：持有天数（主表，预设 5 带）

```
[1,6)  [6,11)  [11,21)  [21,61)  [61,+∞)
```

区间左闭右开，对应「1–5 日 / 6–10 日 / 11–20 日 / 21–60 日 / >60 日」。**切法直接照抄任务书的预设，不按结果调整**——它存在的唯一目的是与 `docs/05` M10.5 的「短持 6–10 日 = 最大出血口 −164,781」对照。

### 5.2 分带二：回吐率直方图（分布本体，预设 6 箱）

```
<0（异常）  0–25%  25–50%  50–75%  75–100%  100–150%  ≥150%
```

`<0` 箱只应含数据异常（§4.6.2），报告须印出笔数：**非零即说明成本或行情口径有错**，这是本实验的自检表。
`100–150%` / `≥150%` 两箱是「浮盈全部吐出并倒亏」的量化，**不合并进 75–100%**——合并会掩盖出场端最严重的那批。

### 5.3 分带三：两个专项切片（预设，非事后挑）

| 切片 | 定义 | 为什么单切 |
|---|---|---|
| **t1 甜区** | `newhigh_distance_pct ≤ 15` | M9.0 已证「≤15% 是唯一稳定正贡献」，出场规则若在甜区失灵会比别处更贵（`docs/29` §四第 1 条） |
| **大赢家** | `MFE > 50%` | 移动止损的最大受益者与最大受害者都在这里：保护浮盈 vs 切碎主升浪 |

### 5.4 加密规则（逐级二分，规则预设）

**先 L1 五带；命中触发条件的带，按「该带宽度二分」降一级，等距、不找拐点。**

L2（对命中的 L1 带二分）：

```
[1,6)  → [1,3) [3,6)
[6,11) → [6,8) [8,11)
[11,21)→ [11,16) [16,21)
[21,61)→ [21,41) [41,61)
[61,∞) → 保持不动（样本天然稀少，二分会产生空箱）
```

L3（对命中的 L2 段再二分一次，即 1–2 日粒度）：默认不启用；若启用须在报告附录写明触发段号与理由。

**触发条件（事先写死）**：该带同时满足

- `n ≥ 30`，且
- 出现以下任一信号：**符号反转**（与相邻带每单位净利一正一负）、或 **利润集中度 > 50%**、或 **剔除前三赢家后净利符号翻转**。

未命中的带**保持不动**（不得为了「看起来对称」而全表加密）。

**P0-1 的教训必须继承**：任何「总账最优」的带，必须再降一级粒度复核是否成片。本实验的对应做法——若某带的回吐率中位数显著低于相邻带（看起来「吐得少、值得加仓」），该带强制降 L3 复核。

### 5.5 空带与不可检验样本的呈现规则（**加总恒等式：带内包含 + 子集标记**）

**设计决定（跑前定稿，见 §10 差异 9）**：`MFE ≤ 0` 的样本**留在它本来所属的持有天数带里**，不剥离成独立带。

理由：这批样本「整段持仓最高价都没超过成本」，绝大多数是亏损单。若把它们从带内剥离，各带的胜率与每单位净利会被**系统性抬高**，H3（持有天数 → 每单位净利符号）会被口径污染，正是本实验最不能承受的错误。

呈现方式三条：

1. **L1 五带的四项口径包含全部样本**（可加总 = 1328），带内另设一列 `可检验/不可检验`（如 `58 / 6`）；
2. **另设「不可检验（MFE ≤ 0）」汇总行**，标注**「子集标记，非加总行」**，印出它自己的笔数、胜率、每单位净利（这批的性质本身就是结论的一部分：从未浮盈的单子长什么样）；
3. **回吐统计列（中位/均值/回吐金额/MFE 金额）只在带内可检验子集上计算**，分母写在该列标题里（「可检验 n」）。

加总恒等式（HARD② 据此断言）：

```
Σ(L1 五带 n) = 1328
Σ(各带 n_untestable) = 不可检验汇总行 n        ← 子集一致，不参与加总
```

- **L1 任一带 0 笔**（理论可能，如无 >60 日持仓）：保留空行，状态列写「**无样本**」，不省略。
- `[61,∞)` 带因宽度开放，**不得与其他带合并**；若 `n < 30` 按 §5.6 单列并标「样本不足」。

### 5.6 小样本带的处理规则

- `n < 30` 的带**单列成行**，笔数旁加 `⚠ 样本不足` 角标，结论列写「样本不足，仅供参考」。
- **不把小样本并进大带以凑显著性。**
- 附录细表（L2/L3）一律标注「探索性，多带多重比较，不得据此提新阈值」。

### 5.7 逐年矩阵

14 年 × 5 带，每格印「净利（笔数）」。缺失年份登记原因，**不得留空**（HARD 校验 §7.5）。
另出「逐年回吐率中位数」矩阵：识别「某一年全市场普遍大回吐」（如 2015 股灾）与「长期结构性回吐」的区别——这是 P2-6 立项前必须看的一张表。

## §7 判定标准

### 7.1 三条硬门槛（缺一不得下结论）

1. **样本量**：`n ≥ 30`；不足则标「样本不足，仅供参考」。
2. **有样本年数**：`M ≥ 8`（`pos_ratio` 判定需 `Mf ≥ 8`）；不足则标「出现年数不足，不作跨年裁定」。
3. **完整性**：四项固定口径 + PF + 缺口 + 剔除前三 + 回吐率分布 + 回吐金额，缺一项即不得下结论。

### 7.2 跨年一致性记账规则

- `M` = 该带 `n > 0` 的年数；`P` = 该带年度净利 > 0 的年数。
- **过滤后符号统计**：只把「该年该带 `n ≥ 3`」的年计入 `P'` / `M'`，**判定用过滤后那一组**。
- 记分卡必须**同时印出** `P/M` 与 `P'/M'`。
- `longest_run` = 最长连续同号年数（对应 `docs/29` §八.3「连续 ≥2 年同符号」）。
- `pos_years_pnl_share` = 正号年净利合计 / 该带净利合计（识别「靠两年暴赚、其余年亏」）。

### 7.3 逐带裁定矩阵（与 P0-1 同构，便于横向对比）

| 条件 | 裁定标签 |
|---|---|
| `n < 30` | **样本不足** |
| `n ≥ 30` 且 `Mf < 8` | **出现年数不足** |
| `n ≥ 30`、`Mf ≥ 8`、`pos_ratio' ≥ 0.70`、缺口 ≥ +2pp、剔除前三仍为正 | **edge** |
| 同上但剔除前三为负 | **假 edge（少数交易撑起）** |
| `pos_ratio'` 在 0.30–0.70 | **不稳定（不得下 edge 结论）** |
| `pos_ratio' ≤ 0.30`、缺口 ≤ −2pp | **负 edge** |
| `MFE ≤ 0` 登记行 | **不可检验（从未浮盈）** |

判定顺序：**先查剔除前三是否翻负（假 edge）→ 再查跨年稳定性**（P0-1 附 A 方法论修正 1，本实验继承）。
补充：缺口在 ±2pp 之间一律记「无 edge」。

### 7.4 H1 / H2 / H3 的裁定输出

三条假设**各自独立裁定**，输出格式固定为：

```
H1 [成立/不成立]  判据①__%（需≥50%）  判据②__%（需≥50%）  判据③ ratio_f=__（需≥0.50 且 Mf≥8）
H2 [成立/不成立]  判据①__%（需≥50%）  判据②__%（需<20%）
H3 [复现/未复现]  递增相邻对 __/5（需≥4）
```

**若 H1 与 H2 同时成立**，必须在判定章写一句解释为什么两者不矛盾（长持赢家吐得多 + 短持单本来没浮盈），并给出「P2-6 是否仍值得立项」的明确建议。

## §9 风险与局限

| 风险 | 表现 | 缓解 |
|---|---|---|
| **未复权污染**（本实验最大威胁） | 除权日前的价格把 MFE 抬高，回吐率虚增；若污染集中在长持样本，会直接把 H1 推向「成立」 | ① §3.5 单日 −20% 诊断，打印污染笔数；② 稳健性切片剔除后重算 H1 三条判据；③ 结论章必须写明污染面 |
| **「回吐」被读成「该止盈」** | 看到中位回吐 60% 就宣布移动止损是答案 | §1.3 强制句式 + §1.2 第 1 条：本实验不给收益预测 |
| **短持单的机械偏误** | 持有 3 天的单子 MFE 天然小，回吐率分布形状与长持不可比 | 回吐率只在「可检验集」内比；同时印 MFE 金额（附加 G），防「百分比幻觉」 |
| **分母敏感** | `giveback` 在 MFE 很小（如 1%）时数值爆炸（ret=−0.5% → 回吐率 150%） | 报告须同时给 P25/中位/P75 与直方图；禁止只报均值 |
| **多重比较** | 5 带 × 14 年 ≈ 70 格 | 结论只下在 `n≥30` 且 `Mf≥8` 的带 |
| **与 P0-1 误比** | 拿 P0-1 的每单位净利与本实验的每单位净利横向比较 | 两者样本相同（1328）但分组变量不同（box 高度 vs 持有天数），**只能定性参照**，报告须标注 |
| **持有天数的口径差** | 停牌股 `hold_bars` 偏小，可能把长持判成短持 | HARD④ 两口径一致率 ≥95%，低于则切 `hold_cal` |
| **`close_reason` 语义不明** | 引擎的 `stop` 可能同时包含初始止损与移动止损 | 只作附录切片，**不作任何判据**；语义核实登记在附 A |

## §10 与 `docs/29` 原设计 / 任务书的差异登记

| # | 原文 | 本文做法 | 理由 |
|---|---|---|---|
| 1 | `实际收益率 = realized_pnl / (avg_cost × qty)` | `ret = realized_pnl / cost_basis`，其中 `cost_basis = Σleg.qty×leg.price` | `position.qty` 平仓后清零（实测 100% 为 0），原式分母为 0、样本全废（§3.3） |
| 2 | 行情源写 `var/bt/full_hist_10pct.db` | 用**各年回测库自带的 `daily_bar`** | 两者行数（29,371,270）与代码数（11,940）完全一致，日期范围同为 1990-12-19~2026-10-16；用回测库自带的 bar 保证「MFE 与引擎当时看到的是同一批行情」，避免跨库口径漂移。附 A 登记一致性核对结果 |
| 3 | `MFE = max(持仓期间 highest − 成本)`（绝对价差） | `MFE = max(high)/avg_cost − 1`（相对幅度） | 绝对价差不可跨股票聚合（10 元股与 100 元股不可比）；相对幅度才能做分布统计。回吐率公式要求 MFE 与 ret 同量纲 |
| 4 | 判定只给 H1/H2（二选一语气） | 加 **H3 方法论对照** + 明确允许「两者同时成立/同时不成立」 | 原设计把 H1/H2 写成互斥，但「长持赢家吐得多」与「短持单没浮盈」在数据上可同时为真；强行二选一会制造假结论 |
| 5 | 分带只写「1-5/6-10/11-20/21-60/>60」 | 补 **L2/L3 二分加密规则 + 触发条件** | P0-1 教训：单一粒度会把「峰」和「窄缝」混淆；加密规则必须跑前写死 |
| 6 | 未要求「回吐金额（元）」 | 新增附加 F/G（MFE 金额、回吐金额） | 百分比无法回答「值多少钱」；`giveback_amount` 是任何完美出场规则的收益**上界**，是 P2-6 立项决策的直接输入 |
| 7 | 未提 `close_reason` | 新增附录切片 | 退出方式是出场端实验的天然分组维度，免费可得；但语义未核实，不升级为判据 |
| 8 | 未提未复权风险 | §3.5 诊断 + 强制稳健性切片 | 任务书已登记「诚实边界」，本文把它变成可执行的断言与复核表 |
| 9 | 任务书「分带合计 = 样本总数（含『不可检验』登记行）」 | **子集标记方案**：不可检验样本留在本带内参与四项口径，另设子集汇总行 | 若把 MFE≤0 剥离成独立带，各带胜率/每单位被系统性抬高（这批几乎全是亏损单），H3 判定被口径污染。加总恒等式改为「Σ五带 = 1328 + Σn_untestable = 子集行 n」 |
| 10 | 未规定持有天数的行情源 | `hold_bars` 用该股自身 bar、`hold_cal` 用 sh000001，HARD④ 一致率 ≥95% 否则切 `hold_cal` | 停牌股会把「持有 30 个交易日」记成 12 天，直接改变分带归属 |

5. **`close_reason` 语义核实结果**：取值仅 `stop`(1193) / `manual`(135)。`stop` 混合了初始止损与时间止损，
   无法单靠它区分；正文因此改用 `reason_json.signal` 精确识别 `time_stop_noprofit`，
   `close_reason` 只保留在 §9.2 附录作粗切片（不作判据，符合 §9 的风险约定）。
