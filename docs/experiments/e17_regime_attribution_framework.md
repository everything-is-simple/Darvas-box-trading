## §1 实验目的与边界声明

### 1.1 本轮的出发点

系统的现状是「固定单位头寸」（1 单位 = 2% 权益；A M1 升势日首买 2 单位、其余 1 单位），**没有任何 regime 闸门**。

用户提出的痛点是：**固定单位在大盘趋势不适合时回吐太多**（`docs/29` 立项理由点名 2011 / 2010 / 2008 三个年份）。

本轮要回答三个问句：

1. 把 14 年 1328 笔平仓交易按**交易时点的大盘状态**分桶，哪些桶的每单位净利为负、且这个负值不是「两三笔亏损撑出来的」？
2. 这个负值是**「在大盘不好时买入」造成的，还是「持有期内大盘转坏而没跑」造成的**？
3. 三个不同的 regime 判据（MA20 / MA60 / A 判据）是不是在讲**同一件事**？如果口径不同结论就翻转，那结论只能挂在口径上，不能当普适事实。

### 1.2 本轮明确回答不了的四件事

| # | 回答不了 | 原因 |
|---|---|---|
| 1 | **闸门阈值应该是多少** | 本轮是**描述性归因**，不是规则验证。任何阈值只能由 B 类「改 planner 后同参数重跑 14 年」得出。此外 `docs/23` §9 P5 已把「熊市闸门」列为硬结论否决（C 判据六轮证伪），**本报告不因此复活闸门**，只产出待验假设。 |
| 2 | **因果** | 分桶不改变信号、成交、仓位路径。regime 与大势、与个股波动率、与箱体质量高度共线，桶间差异含大量混杂。这是后验切分，不是随机对照。 |
| 3 | **样本外有效性** | 2005–2018 是全部参数被选定所用的同一段历史（`docs/29` §八.6）。结论只用于提假设，不得直接改参数上线。 |
| 4 | **与其他维度的交互** | 单因子轮换纪律（`docs/29` §2.3）：本文只动「大盘状态」一个因子。大盘状态 × box 高度、× 距新高、× 持有时间的交互不在本轮范围（另立项）。 |

### 1.3 结论句式模板（强制措辞）

跑完写结论时，必须按以下句式组织，不得省略括号内的限定项：

> 在 2005–2018 的 1328 笔平仓交易中，按 **C2（上证 vs MA60）× 建仓日** 分桶，**MA60 下方**桶的每单位净利为 __、剔除前三赢家后为 __、14 年中有 __ 年为正、覆盖 __ 个 regime 段（记账规则见 §7.2）；该桶**具备 / 不具备**初步负 edge。
> 该负 edge 是否可转化为闸门，**本实验不回答**；须由 B 类同参数重跑验证。

禁止出现的写法：`熊市不该开仓`、`跌破 MA60 就该停手`、`回撤超过 X% 必须降仓`、`可以据此调参`、`证明择时有效`。

## §2 实验假设（可证伪形式）

框架阶段只登记判据，不写任何预期数字。

| 编号 | 假设 | 成立判据（全部满足） | 证伪条件 | 对应表 |
|---|---|---|---|---|
| **H1** | 「降势有害」在 14 年全样本上成立 | C3@建仓日 · 降势桶：每单位净利 `pu < 0`、剔除前三 `pnl_ex_top3 < 0`、出现年数 `M ≥ 8` | 降势桶 `pu ≥ 0`，或剔除前三后转正（说明负值由少数亏损笔造成） | **T3**，以 T6（平仓时点）复核 |
| **H2** | 「MA60 下方」是负 edge（不只是方向为负） | C2@建仓日 · 下方桶：`n ≥ 30`、`m ≥ 20`、`pu < 0`、`pnl_ex_top3 < 0`、段级 `ratio_seg ≤ 0.30`、笔级 `ratio_f ≤ 0.30`、缺口 `gap ≤ −2pp` | 任一门槛不达 → 只能记「方向为负但未达负 edge」；若 `pu < 0` 但 `ratio_f > 0.30` → 记「不稳定」 | **T1** |
| **H3** | 「MA60 上方」是**利润主体而非 edge** | 上方桶 `pu > 0`，但满足任一：集中度 `conc > 50%`、`pu_ex_top3 / pu < 0.5`、`ratio_f < 0.70` | 三项全不满足（剔除前三仍留大部分、跨年 ≥70%、集中度不高）→ 可称 edge，须进 B 类列 | **T1**，T2 辅助 |
| **H4** | 三口径在方向上是同一件事（口径稳健） | ① 三口径「看空桶」`pu` 同号；② 两两 Jaccard ≥ 0.50；③ C2×C3 交叉表中「MA60 下方 ∧ 非降势」与「MA60 下方 ∧ 降势」`pu` 同号 | 任一不满足 → 结论必须降级为「MA60 口径专属」，不得写成普适事实 | §2 并排表 + §6.2 交叉表 |
| **H5** | 「卖晚」比「买错」更贵 | 2×2 转移矩阵中（上方→下方）桶：`pu < 0`、`|pnl| > |(下方→下方) 桶 pnl|`、`n ≥ 30` | （下方→下方）更负，或（上方→下方）为正 | §6.1 |
| **H6** | 「按账户回撤停手」不可检验；「按指数深度回撤降仓」可检验 | 账户回撤 `>10%` 桶 `n = 0`（结构性），且**距 52 周高点回撤** `≥20%` 桶 `n ≥ 30` 且 `pu < 0` | 账户 `>10%` 桶出现样本（说明回测期有更深回撤，相关结论须重写）；或距 52 周高点回撤 `≥20%` 桶 `n < 30` | §7.2 + §7.3 |

**登记为「不可检验」的项（不得写成「已证伪」或「无效应」）**：

| 项 | 登记理由 |
|---|---|
| 账户权益回撤 `>10%` 档 | 回测每年权益从 1,000,000 重置，14 年最深回撤仅 −9.08%，该档**恒为 0 天**。不得据此得出「深度回撤时表现未知/回撤闸门无效」任一结论。 |
| 「低账户回撤段更优」 | 账户回撤是**内生**变量（由此前交易盈亏决定），低回撤段与「刚赚完钱」高度重合，无法与 regime 分离。只作描述。 |

## §3 数据准备过程

### 3.1 只读纪律

- 一律用 `sqlite3.connect("file:<db>?mode=ro", uri=True)`。
- 不写回测库、不碰源库 `full_hist_10pct.db` 与生产库 `darvas.db`（`docs/06` §6.2 库隔离）。
- 不重跑任何回测、不改任何参数、不重建任何索引。

### 3.2 取数口径

单库单条 SQL（14 库循环）：

```
SELECT p.opened_date, p.closed_date, p.status, p.realized_pnl, p.code,
       o.reason_json, t.plan_date
FROM position_leg l
JOIN position p        ON p.id = l.position_id
LEFT JOIN plan_order o ON o.id = l.plan_order_id
LEFT JOIN trade_plan t ON t.id = o.trade_plan_id
WHERE l.leg_no = 1
```

提取字段：

| 字段 | 来源 | 用途 |
|---|---|---|
| `year` | 库文件名 `bt_e17_<year>.db` | 逐年分组 |
| `opened_date` | `position` | **主时点 O**：建仓日归因 |
| `closed_date` | `position` | 对照时点 C：平仓日归因 |
| `plan_date` | `trade_plan` | 审计时点 P：与 `reason_json.regime` 对齐 |
| `status` | `position` | 只统计 `closed` |
| `realized_pnl` | `position` | 净利（唯一盈亏口径，含费） |
| `units` | `reason_json` | 每单位净利的分母，实测 ⊆ {0.5, 1, 2, 3} |
| `regime` | `reason_json` | **C3 在 P 时点的落库值**（仅审计轨，见 §4.3） |
| `sizing_basis` | `reason_json` | 记录用，**不用于分桶** |

指数序列（只需从 `bt_e17_2005.db` 读一份，14 库指数指纹实测一致）：

```
SELECT date, close, low FROM daily_bar
WHERE code = 'sh000001' ORDER BY date
```

### 3.3 样本漏斗

| 步 | 说明 | 剩余 |
|---|---|---|
| 1 | 14 个回测库（2005–2018） | 14 库 |
| 2 | `leg_no = 1` 首次建仓 | 1405 笔 |
| 3 | `status = 'closed'` 且 `realized_pnl` 非空 | 1328 笔 |
| 4 | `units` 缺失或 ≤ 0 | 0 笔被剔除 |
| 5 | 6 个 regime 标签任一无法定位（§4.4） | 0 笔被剔除 |
| 6 | **有效样本** | **1328 笔** |

第 3 步排除的 77 笔为未平仓头寸：未实现盈亏与已实现盈亏不可比，故剔除（这是唯一的剔除动作）。

### 3.4 清洗规则

**只做结构清洗，不做数值清洗。**

- **不剔除极端盈亏**：极端值靠「利润集中度」与「剔除前三赢家」两列暴露，而不是删掉。
- **不剔除单年**：牛市年、熊市年一视同仁，不按年筛选。
- **不按 `sizing_basis` / `units` 过滤**：regime 与距新高档位、仓位档位是不同维度，混用会重复归因（`docs/29` §2.3 OFAT）。
- **不改权重**：每笔交易等权计入胜率；每单位净利按 `units` 求和做分母。**不做按段加权**——段级结果单独成表（§8.1），不混入笔级表。

### 3.5 已知数据偏差（结论必须携带）

- **幸存者偏差**：只用当前仍存在的股票，退市股不在样本内；2005–2008 段偏乐观（`docs/01` §10.1 已披露）。
- **前复权失真**：指数不受影响（指数不做复权），但个股盈绝对额受影响，每单位净利口径相对稳健。
- **2008 已并入**：2008 原为样本外验证年，现与其余年份合并统计，不再具备样本外属性。
- **regime 段高度自相关**：同一段大盘状态内的多笔交易**不是独立观测**（详见 §4.5），这是本实验最重要的偏差，必须在每张表上标注。
- **账户回撤内生**：见 §2 登记项。

## §4 口径定义（三判据 × 三时点）

### 4.1 三套判据

| 代号 | 判据 | 定义 | 状态数 | 出处 / 授权 |
|---|---|---|---|---|
| **C1** | MA20 | `d20 = (close − MA20) / MA20 × 100`；`d20 ≥ 0` 上方，`< 0` 下方 | 2 | `docs/29` §五 P0-3 |
| **C2** | MA60 | `d60 = (close − MA60) / MA60 × 100`；同上。**主表用它** | 2 | 同上 |
| **C3** | A 判据 | 60 日低点相邻日比：`cur = min(近 60 根 low)`、`prev = min(前 60 根 low)`；`cur > prev×1.002` 升势 / `cur < prev×0.998` 降势 / 其余震荡 | 3 | `internal/regime/regime.go:181-236`（`ClassifyDateA`）、`scripts/e17_newhigh_distance_report.py:135-158` |

**授权边界（重要）**：MA20/MA60 **只允许用于 regime 分桶**，不得作为入场信号（`docs/00` §3.6 红线、`docs/29` §八.1）。本实验只用它们给「当天大盘在均线上还是均线下」打标签，不产生任何买卖规则。

MA 计算规则：`MA_N(T) = mean(close[T−N+1 … T])`，**含当日**，只用 `≤ T` 的 K 线（零未来信息，§9 风险 2）。

### 4.2 三个时点

| 代号 | 时点 | 字段 | 角色 |
|---|---|---|---|
| **P** | 信号日 | `trade_plan.plan_date` | **仅审计轨**（`reason_json.regime` 就是这一天的 C3） |
| **O** | 建仓日 | `position.opened_date` | **主**（= T+1 实际买入日） |
| **C** | 平仓日 | `position.closed_date` | **对照** |

### 4.3 表号映射（6 张主表 + 1 张审计表）

| 表 | 规则 × 时点 | 角色 | 桶数 |
|---|---|---|---|
| **T1** | **C2 × O** | **主表**（L1 二元 + L2 八带 + L3 边界加密 + 裁定） | 2 + 8 + 8 |
| T2 | C1 × O | 对照 | 2 + 8 |
| T3 | C3 × O | 对照（与 M9.0 报告同口径） | 3 |
| T4 | C2 × C | 对照（平仓时点） | 2 |
| T5 | C1 × C | 简表 | 2 |
| T6 | C3 × C | 简表 | 3 |
| **T7** | C3 × P（+ `reason_json.regime`） | **审计轨，不进主表** | 3 × 2 |

**关键判断：`reason_json.regime` 不是第四个口径**，它是 **C3 在 P 时点的落库值**。因为「T 日判定 → T+1 买入」存在 1 日错位，用它归因等于把「判据在 T 日怎么说」当成「买入时市场什么样」。它只能用来对账，不进主表。

### 4.4 标签定位规则

给定一个交易日 `T`，取其**在 sh000001 交易日历中 `≤ T` 的最后一个交易日**的标签。

- 若 `T` 早于该库指数序列起点或晚于终点 → 记 `None`，**不填 0、不填默认桶**，并计入缺失计数（HARD 断言缺失 = 0）。
- `d == 0` 归「上方」（写死）。

### 4.5 有效样本 m（本实验的核心方法论）

大盘状态是**高度自相关**的：一段持续 8 个月的「MA60 上方」会包含上百笔交易，但它们共享同一个大盘状态，**不是上百个独立观测**。把 723 笔当 723 个独立样本做显著性检验，会得到虚假的显著性。`docs/18` R1 已记录过同类教训（「20 日窗口重叠，独立样本≈14 个」）。

定义：

```
交易日历 D = sh000001 在 [2005-01-04, 2018-12-31] 的全部交易日
runs      = 把 D 切成「连续同标签」的区间段
m_total   = len(runs)                       # 全期独立性上限
m_trade   = #{ run : 该段内至少 1 笔已平仓交易 }
seg_density = n / m_trade                   # 平均每段被重复计数几次
```

报告每桶必须同时印 `n`（笔数）与 `m`（段数），格式 `723 / 147`，并在表下固定小字说明二者区别。**`m < 20` 一律不下结论**（裁定矩阵第 3 级）。

段级聚合（抗伪重复）单独成表：每个 regime 段视为 1 个观测，段内 `pnl` 求和，算 `M_seg / P_seg / ratio_seg` 与前三盈利段集中度。**段级符号与笔级符号不一致时，笔级结论必须降级**（裁定矩阵第 6 级）。

### 4.6 回撤双口径

| 口径 | 定义 | 性质 | 角色 |
|---|---|---|---|
| **指数累计回撤（审计对照）** | `peak = close(2005-01-04)`；逐日 `peak = max(peak, close(d))`；`dd(d) = close(d)/peak − 1` | 外生、跨年不重置 | 保留作审计；**执行中发现退化**（见 §10 #8） |
| **距 52 周高点回撤（操作口径）** | 滚动 250 交易日最高收盘为峰：`dd250(d) = close(d)/max(close[d−249…d]) − 1` | 外生、跨年不重置、零未来信息 | **实际裁定依据**；与系统既有「52 周新高距离」同尺 |
| **账户权益回撤（描述性）** | `equity_snapshot.drawdown`（= `(peak_total − total)/peak_total`） | **内生、逐年重置**（每年起点 1,000,000） | 仅描述，不给裁定标签 |

指数回撤分带（预设）：

```
累计回撤：[0,5) [5,10) [10,20) [20,30) [30,40) [40, +∞)
距 52 周高点回撤：[0,5) [5,10) [10,20) [20,30) [30, +∞)
```

账户回撤分带（沿用 `docs/29` 原设）：

```
[0,5) [5,10) [10, +∞)
```

**为什么保留两个指数回撤口径**：累计回撤用 2005 起点作基准峰，会被 2007 年 10 月泡沫高点永久锚死——此后所有交易都记在深回撤档，分桶失去判别力（执行实测：单档独占 78% 样本）。故新增滚动的「距 52 周高点回撤」作操作口径，两版并存，累计口径降为审计对照。此为执行中的口径修正，登记在 §10 #8。

### 4.7 统计口径（每桶必须齐备）

| 口径 | 公式 | 备注 |
|---|---|---|
| 胜率 | `wins / closed` | 已平仓头寸中盈利占比 |
| 每单位净利 | `Σpnl / Σunits` | `units` 取自 `reason_json.units` |
| 保本胜率 | `|avgLoss| / (avgWin + |avgLoss|)` | 即 `1 / (1 + 平均盈利/|平均亏损|)` |
| 利润集中度 | 前三赢家合计 / 毛盈利 | 毛盈利 ≤ 0 或前三和为负时记 `—`（无经济含义） |
| 附加 A | 利润因子 PF = 毛盈利 / |毛亏损| | |
| 附加 B | **缺口** = 实际胜率 − 保本胜率（pp） | `docs/29` §六.2 判定用 |
| 附加 C | **剔除前三赢家净利** = 净利 − 前三赢家合计 | 识破「假 edge」的关键列 |
| 附加 D | 剔除前三赢家每单位净利 | 同上 |

## §5 分桶与加密设计

### 5.1 核心原则：规则预设，不按结果切

- 所有分带**等距**，不是「找拐点」。
- 加密触发条件**事先写死**（§5.3），不是看着结果挑。
- 任何桶**不得因结果好坏合并或拆分**。若事后确需新增切法，必须登记到 §10 差异表，并在报告附录公开完整「探索日志」（本次跑过的全部切法）。

### 5.2 MA 距离三层

| 层 | 分带 | 触发规则 |
|---|---|---|
| **L1** 二元 | `d < 0` 下方 / `d ≥ 0` 上方 | 永远启用，是主表第一段 |
| **L2** 对称八带 | `≤−10 / −10~−5 / −5~−2 / −2~0 / 0~+2 / +2~+5 / +5~+10 / ≥+10`（单位 %，左闭右开） | **永远启用**（不是条件触发）。`±2%` ≈ 上证一个 ATR；`±5/±10` 覆盖尾部；对称是为让上下两侧同尺度可比 |
| **L3** 边界加密 | 0 轴两侧 `±4%` 按 1% 切 8 带：`−4~−3 … −1~0 / 0~+1 … +3~+4` | **规则触发**：跨 0 的两相邻带（`−2~0` 与 `0~+2`）**同时** `n ≥ 30`，且二者 `pu` 符号相反或集中度差 > 30pp → 启用。另：任一 L2 带若 `n ≥ 30 且 conc > 50%`，该带再按 0.5% 复核（只复核该带，不扩大范围） |

**L3 存在的理由**：P0-1 的教训（`e17_box_height_framework.md` 附 A 第 3 条）——`/top 20–25%` 在 5% 网格上是全表峰值（每单位 +1,228），降到 1% 后碎成 21–22%、24–25% 两条窄缝，紧邻的 20–21% 直接变成 −21,709。所以 MA 距离必须保留一个边界加密层，用来回答：**MA60 的符号翻转是「0 轴这条结构性分界线」，还是「某 1 个百分点内的抽样波动」**。

L3 结果一律标「**探索性，不据此提任何阈值**」。

### 5.3 空桶与不可检验项的呈现规则

- 空桶**必须保留行**，灰底斜体，写明「不可检验（结构性无样本）」及**原因**。
- 不得删行，不得并入相邻桶，不得写成「无效应」。
- 尾部分桶的合并只允许发生在尾部（`40%+` / `≥+10`），且行内须注明合并了哪几段。

### 5.4 报告组织的五条硬规则（防看晕）

1. 每张表标题写成 `T3 ｜ C3 A判据 × O 建仓日 ｜ 3 桶`——表号 + 口径 + 时点，缺一不可。
2. 所有表**行序固定**：看空档在前（下方 / 降势），看多档在后。**不按盈利高低排序**（那是「按结果挑」）。
3. 所有表**列序固定**：`桶 | n | m | 胜率 | 每单位 | 保本胜率 | 缺口 | PF | 集中度 | 前三赢家 | 剔除前三净利 | 净利 | 裁定`。
4. 主表（T1）之外的桶表**不展开成完整长表**：只保留二元/三元行；距离加密只进 T1。
5. 页首「一页结论」最多 5 条，每条必须带表号；写不出表号的结论删掉。

## §7 判定标准

### 7.1 四条硬门槛（任一不满足即不给裁定）

| 门槛 | 阈值 | 理由 |
|---|---|---|
| 样本量 | `n ≥ 30` | `docs/29` §六.1 |
| **有效样本** | `m ≥ 20` | 段数不足时，笔级显著性可能是伪重复 |
| 出现年数 | `Mf ≥ 8`（该桶有交易的年份数） | 防止单年主导 |
| 口径齐备 | 四项固定口径 + PF + 缺口 + 剔除前三 全部可算 | `docs/29` §2.5 |

### 7.2 跨年与段级记账规则

- 年份符号：该桶该年 `n ≥ 3` 才计入分母（`M`），`pnl > 0` 计为 `P`，`ratio_f = P / M`。
- 段级：该段有交易才计入 `M_seg`，段内 `Σpnl > 0` 计为 `P_seg`，`ratio_seg = P_seg / M_seg`。
- **跨年 ≥ 70% 才叫「稳定」**；≤ 30% 才叫「跨年一致为负」。
- **笔级与段级符号不一致 → 降级**，不允许只报对自己有利的那一个。

### 7.3 裁定矩阵（10 级，顺序不可调）

判定顺序是方法的一部分，先查什么后查什么会直接改变标签。顺序如下：

| 级 | 条件 | 标签 |
|---|---|---|
| 1 | 空桶 | `不可检验（结构性无样本）` |
| 2 | `n < 30` | `样本不足` |
| 3 | `m < 20` | `有效样本不足（段数 <20）` |
| 4 | `Mf < 8` | `出现年数不足` |
| 5 | `pu > 0` 且 `pu_ex_top3 ≤ 0` | `假 edge（前三撑起）` |
| 6 | `pu > 0` 但 `ratio_seg < 0.50` | `笔级为正但多数段为负` |
| 6′ | `pu < 0` 但 `ratio_seg ≥ 0.50` | `笔级为负但多数段为正` |
| 7 | `ratio_f ≥ 0.70` 且 `gap ≥ +2pp` | `edge` |
| 8 | `ratio_f ≤ 0.30` 且 `gap ≤ −2pp` | `负 edge` |
| 9 | `ratio_f ≤ 0.30` 但缺口未达 −2pp | `跨年偏负（缺口未达 −2pp）` |
| 10 | 其余 | `不稳定（正/负但非跨年）` |

**第 6 级为什么比的是「多数段是否为正」而不是「段级中位数 vs 笔级均值」**：两者是不同统计量（均值 vs 中位数），一个桶完全可以「均值为正、中位数为负」而毫无矛盾——那是分布右偏的正常表现。用它们比大小会把每个右偏的桶都标成「段级不支持」，属于错误比较。故第 6 级改为比例对比例的判断：`ratio_seg`（正段数/总段数）与笔级符号是否同向。段级中位数仍作为诊断列印在报告 §8.4，但**不作裁定依据**。此为执行中的方法修正，登记在 §10 #9。

**为什么第 5 级必须排在稳定性之前**：P0-1 的实际教训——初版把「跨年稳定性」放在前面，导致 `5–10%`（跨年 5/14）与 `15–20%`（7/14）被标成「不稳定」，掩盖了它们「剔除前三即翻负」（−8,451 / −692）的实质。假 edge 必须优先暴露。

**补充降级**：上方桶即使跨年达标，若 `conc > 50%` 或 `pu_ex_top3 / pu < 0.5`，降级为 `利润主体（非 edge）`——这是 H3 的裁定语言。

### 7.4 校准锚点与非盲测声明

本框架的 HARD 断言中含若干「已知结果」锚点（样本量、C3 分布、MA 分布、段数、回撤天数），分两类：

| 类别 | 用途 |
|---|---|
| **跨报告一致性锚** | 与 P0-1（1405/1328/842,799.7）、M9.0（C3@O = 91/51/1186、净利 +265,532/−27,292/+604,560）对齐。**这些数字在写框架前已从既有报告读到**，用于保证本实验与既有报告是同一批样本。 |
| **实现正确性锚** | C1/C2 分布、段数、回撤天数由只读预检实测得到，用于发现口径实现错误。 |

**诚实声明**：上述锚点是在**看到既有报告之后**登记的，因此本文在「样本是否一致」这一点上**不是盲测**。但 §2 的 H1–H6 判据与 §7.3 的裁定矩阵**在看到本轮分桶结果之前**已定稿，这一点是可审计的（见附 A 时间戳）。
