核心结论

  • 2005–2018 共 1481 笔已平仓交易，其中可复算谱系深度 1481 笔、不可复算 0 笔。
  • 谱系深度四带每单位净利：+154（1–5 级） / +1,078（6–12 级） / +720（13–20 级） / +749（21 级+）。
  • 谱系深度四带胜率：24.5% / 18.7% / 23.5% / 24.3%。
  • H1（谱系深度与突破质量单调相关）不成立（递减相邻对 1/3）；H2（深层箱体突破质量差）不成立。

读法：谱系深度是「这是这只票第几级箱体」（沿 prev_box_id 链回溯的步数），不是寿命（box 自身存续）、 也不是阶梯速度（相邻两级隔多久）。与 LB-2「爬多快」是一对正交维度：LB-2 测速度、LB-5 测位置。本实验只报相关性分布，不下因果结论（框架 §1.2）。
