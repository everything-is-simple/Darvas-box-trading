## §1 实验目的与边界声明

### 1.1 本轮要回答的一个问句

箱体是"活的生命体"（突破当日开新箱、阶梯往上叠），但 `raiseStops`（planner.go:448）把「箱体 → 止损」映射用的是**带两条限制的跟随规则**：

1. 新箱下轨必须**已 3 日确认**（`BottomConfirmed != ""`）；
2. **入场箱体自身不参与上移**（`lb.ID == pos.EntryBoxID` 则跳过）。

结果可能是：**票涨得越快，新箱确认越慢，止损越追不上**——大赢家冲到数倍时，止损仍钉在入场老位置。

**本轮问句**：持仓期内，止损**实际有没有及时跟着新箱下轨往上挪**？"没跟上"的那批持仓，是不是就是大赢家回吐（或小亏变大亏）的出血口？

### 1.2 与 P2-5 的界限（防自相矛盾，必读）

- **P2-5 否掉的是 trail%（百分比驱动的移动止损）**——「盈利回吐超 X% 就走」，无证据。
- **本项是箱体驱动的止损上移**——「新 box 的下轨才是止损位」，与价格百分比无关，是原书 L2618/L2719 原文规则。
- **两者不是同一件事，P2-5 的否决不适用于本项。** 本项验的是「上移**来得及来不及**」，不是「该不该上移」。

### 1.3 本轮明确回答不了的

| # | 回答不了 | 原因 |
|---|---|---|
| 1 | **因果** | 止损跟随性高度混杂市况/箱体节奏/个股动量。本实验只报**相关性分布**，不下因果。 |
| 2 | **"该改成几天下轨确认 / 入场箱是否参与"** | 本实验是 A 类统计。若发现 edge，须另立 B 类改规则 + 回测，不在本范围。 |
| 3 | **每次上移的精确时间序列** | 见 §2 硬约束——事件不落库，只读库拿不到「每次何时、幅度」。 |
| 4 | **样本外有效性** | 2005–2018 是全部参数被选定的同一段历史。 |
| 5 | **2019+ 样本** | 规则定稿前禁碰。 |

### 1.4 结论句式模板（强制措辞）

> 在 2005–2018 的 __ 笔已平仓交易中，可复算「入场止损→最终止损」总上移幅度的 __ 笔、上移 >0 的 __ 笔、从未上移的 __ 笔；
> 按上移幅度分带（0 / (0,5%] / (5%,15%] / >15%）的每单位净利分别为 __ / __ / __ / __，回吐率 __ / __ / __ / __。
> H1（上移幅度与交易质量相关）**成立/不成立**；H2（从未上移的大赢家回吐最重）**成立/不成立**。
> 「该不该改 raiseStops 的确认日/入场箱参与」**本实验不回答**，只能由后续 B 类回测回答。

禁止出现的写法：`止损应该跟着箱体走`、`上移及时就能多赚`、`该缩短确认日`。

## §2 硬约束：止损上移事件不落库（本文最重要的口径声明）

**事实**：`TradeRepo.UpdateStop` 只执行 `UPDATE position SET stop_price=?`，**不留任何历史痕**。持久层没有 stop_move 表，`plan_order.reason_json` 也没有 raise 事件键（实测：只有 signal/position_id/qty/stop_price/box_bottom 等，`stop_price` 是卖单那一刻的值，非事件账）。

**后果**：只读库**拿不到**「止损实际上移了几次、每次何时、每次幅度多少」。docs/29 原写「从 reason_json 的 raiseStops 记录」——**该记录实际不存在**，这是原设计的偏差，登记在 §10。

**本框架采用的可行口径（A 类降级版）**：

- **"实际上移"** 用两个可得的端点近似：**入场初始止损**（= 入场箱体下轨 × sell.discount，见 §4.1）与 **最终 stop_price**（`position.stop_price` 收盘时的终值）的差值。
- **"总上移幅度"** = (最终 stop_price − 入场初始止损) / 入场初始止损。
- **"理论上可上移"** 用 `box` 表的**后续箱体下轨**（入场日之后、清仓日之前，`BottomConfirmed != ""` 的 LatestNonFormingBox 序列）估算——但受 A0 使用须知约束（见下），**不把它当"当日真值"**。

**A0 使用须知两条内化**（`e17_a0_determinism_report` §七）：

1. 只读**持仓票**（必在 watch 池内、每日重扫）⇒ 不受 p50=17 交易日滞后影响。
2. **不查生产 box 表推生死**；涉及「本可上移日」只作**上界估算**，结论句明确标注"这是状态投影下的上界，非事件账"。

**两条可行路径（本框架默认走 A，B 留作后续工程项）**：

| 路径 | 成本 | 能拿到什么 | 拿不到什么 |
|---|---|---|---|
| **A 降级版（本框架）** | 零成本只读 | 总上移幅度、是否上移过、入场止损→终值 | 每次上移的精确时点/次数/滞后天数 |
| **B 补 stop_move 事件账** | 改代码+重跑回测 | 每次 raiseStops 的完整事件（时点/幅度/滞后） | — |

> **判定**：先用 A 降级版看"总上移幅度 vs 交易质量"有没有梯度。**只有** A 版发现"上移不足与大赢家回吐有明确关系"，才值得做 B（补事件账 + 精确滞后 + 改规则回测）。A 版无梯度 → 本项关闭，不做 B。

## §3 实验假设（可证伪形式）

**口径前置**：本框架的「上移幅度」= (最终 stop_price − 入场初始止损) / 入场初始止损，是**持仓全周期的净结果**，不是"每次上移"的微观事件。

| 编号 | 假设 | 判据（同时满足才算成立） | 证伪条件 |
|---|---|---|---|
| **H1** | **上移幅度与交易质量单调相关**：止损上移得越多的持仓，交易质量越好（每单位净利越高、回吐率越低） | 按上移幅度四带，每单位净利在相邻对中 **≥ 3 个**随幅度递增而递增（严格大于），且回吐率随幅度递增而**非增** | 递增对 < 3 → 不成立 |
| **H2** | **从未上移的大赢家回吐最重**：上移幅度 = 0 的带里，大赢家（MFE>50%）的回吐率显著高于其他带 | 上移=0 带的大赢家回吐率 > 其他三带合并回吐率，且差异超噪声门槛（相对 > 3pp） | 差异 ≤ 3pp → 不成立 |

**H1 与 H2 不互补。** H1 关心全谱梯度，H2 关心"没上移"这个极端带。可都成立/都不成立/一成一败。

**方向约定在跑数前写死**：假设"上移越多质量越好"（每单位净利随幅度递增）。不得看结果调整。

## §4 取数口径

### 4.1 入场初始止损（2026-11-03 修正：源码 B2 校订口径，非 bottom）

- **源码事实**（planner.go:buyOrder，B2 校订 2026-10-22）：初始止损 = 被突破箱体 **`top × sell.discount`**（0.97），
  **不是** `bottom × 0.97`。原书 §3.4「新箱体下轨 ≈ 前一箱体上轨（±3% 容差）」→「新箱下轨下方」≈「被突破旧箱上轨下方」。
- **§0 框架原写的 `bottom × 0.97` 是错的**，已在此修正（登记 §10 #4）。
- `entry_box_id` 历史库**全 NULL**（LB-1 已确立），无法直接关联入场 box 的 top。
- **本框架改用「成本归一化比值」口径，绕开反推**（见 4.2b）：
  `买入触发价 = top × buy.premium(1.03)`，`avg_cost ≈ 触发价`，`初始止损 = top × 0.97 ≈ avg_cost × 0.97/1.03 = avg_cost × 0.9417`。

### 4.2 最终止损

- `position.stop_price`（closed 状态下的终值）。

### 4.2b 总上移幅度（成本归一化比值，正式口径）

- **`ratchet = stop_price / avg_cost`**，直接替代「(最终止损 − 初始止损)/初始止损」。
- **物理含义**：`ratchet ≈ 0.9417` = 止损仍钉在入场初始位（从未上移）；`ratchet > 1.0` = 止损已抬到成本之上（确已上移）。
- **优点**：绕开 `entry_box_id` 全 NULL、绕开 bottom/top 反推误差，`avg_cost` 是库内直接字段（实测稳定）。
- **与框架 §2 降级口径的关系**：`ratchet` 是「初始止损→终值」的单调变换（`初始止损 = avg_cost×0.9417` 固定比例），
  两者排序等价，故分带结论一致；`ratchet` 只是把「上移 0」锚定在 `0.9417` 而非 `0`。

### 4.3 上移幅度分带（成本归一化）

- **`≤0.94`（未上移）** / **`(0.94, 1.0]`（微弱）** / **`(1.0, 1.3]`（已上移）** / **`>1.3`（大幅上移）**，四档。
- 档界在跑数前写死（以 `ratchet=0.9417` 为「未上移」锚点），禁止按结果合并/拆分/挪界。

### 4.4 交易质量口径（与 P2-5 同源，可直接横向对照）

- 每单位净利、胜率、保本胜率、利润集中度、PF、剔除前三赢家净利、**MFE、回吐金额、回吐率**。
- 成本口径：`Σ(position_leg.qty×price)`（不可用 `avg_cost×qty`）。

### 4.5 每带必报

| 必报项 | 说明 |
|---|---|
| 胜率 / 每单位净利 / 保本胜率 | 固定三口径 |
| 利润集中度 + PF | 固定三口径 |
| 剔除前三赢家净利 | 识破假 edge 的关键列 |
| 回吐金额 / 回吐率 | 与 P2-5 同源，直接对照 |

## §5 关键判据（转 B 类的门槛）

A 类发现 edge 的充分条件（**同时满足**才立项 B 类补事件账 + 改规则回测）：

1. 「上移幅度低」的带 **剔除前三后净利显著更低**（差异超噪声门槛）；
2. 且「上移幅度低」的带 **回吐率显著更高**；
3. 且该带 **n ≥ 30**，结论**跨年份**成立（非单年）。

否则 → 「追不上」不是问题，维持现状，本项关闭，登记为观察结果。

## §7 判定纪律（继承研究宪法）

- 单年不结论、跨年才下结论。
- 均值与中位数不可比；段级一致性比「正段占比」。
- 有效样本 m（regime 段数）与 n 并列；硬门槛 m≥20。
- 不能跨库比「带」（改档位改资金分配内生性）。
- 分带逐级加密（5% → 2% → 1%），切点是预设规则，禁按结果合并/拆分/挪界。
