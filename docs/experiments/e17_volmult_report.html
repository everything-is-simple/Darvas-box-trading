核心结论

2× 量比门槛不是一个固定值最优，而是「牛松熊紧」：牛市/结构市/震荡 → 1.5（抓机会）；熊市 → 2.0 甚至更紧（躲烂单）；1.0 任何市况都别用。
四年总账（已实现）：1.5 档 +518,093（最优）｜ 2.0 基线 +224,446 ｜ 1.0 仅 +134,526（淘汰）。
但 1.5 的优势由 2015 牛市一年扛起（相对基线 +269,715），2018 熊市里 2.0 反而最优。

一、实验设计

  • 单变量 OFAT：只动 box.volmult（1.0 / 1.5 / 2.0 基线），buy.premium 钉 1.03，其余参数全冻结。
  • 12 库：3 档 × 4 年（2012 震荡 / 2015 牛市 / 2017 结构市 / 2018 熊市），总回测 18h31m。
  • 观测分带（带界固定）：0–1× / 1–2× / 2–5× / 5×+。
  • 验收口径：以已实现为主（讨论入场规则必须用已实现）；账户净利（权益变动，含年末浮盈）仅作对照。
  • 硬校验：volmult=2.0 档与账本基线逐年零差异（HARD①，四年全部复现）。

为什么只能靠 B 类：A 类已证量比 2× 之上无梯度，但 0–2× 带在基线下结构性无样本（被 2× 闸门拦在信号阶段）——「2× 准入值本身对不对」只能改参数重跑。

三、三条硬结论

① 「1.5 四年全最优」不成立——熊市必须收紧。2018 里 2.0 亏得最少（−49,698），1.5 反而多亏 2 万。熊市里「少交易」比「抓机会」重要。
② 四年总账 1.5 最优（+51.8 万，比基线多 29.4 万）。但它是 2015 一年扛起来的（相对基线 +27 万），并非每年都赢。
③ 1.0（完全放开）淘汰。四年 +13.5 万，三档最低；2015/2017/2018 三年都劣于基线。缩量突破放太松，稀释资金、拉低质量。

4.2 警示 2：不能跨库比「带」（本轮最重要的方法论教训）

同一量比区间在不同档位库里表现可能相反，因为档位改变了资金分配（系统持仓上限 14 只，单子之间争预算）：

2015 量比区间1.0 档库1.5 档库
1.0–1.5×+4,541（最肥）无样本（被门槛挡住）
1.5–2.0×+1,122+5,665

1.5 档的「1-2× 带」实际是纯 1.5–2.0× 区间，它每单位 +5,665；而 1.0 档混入 1.0–1.5× 后均值掉到 +2,801。但这不是「1.0–1.5× 单子本身坏」——用 1.0 档库内部切，1.0–1.5× 反而是 2015 最肥的一段（+4,541）。

真相：1.5 门槛挡掉缩量单后，腾出的资金集中到更好的单子上，整体多赚。门槛的最优值是「资金集中度」的最优，不是「某量比区间单子本身的好坏」。

纪律：分带只能同库内部看，或比端到端（账户净利/已实现）；禁止跨库横比同一带的每单位净利。

  • 结构市：中量相对好（2.0–3.0× +118，唯一正）；

这坐实 docs/35 那句「量重要与否必须与所处位置关联」——位置就是市况，量比门槛该跟着市况走。

六、结论与后续

  1. 2× 门槛该动，但不是改成一个固定值，而是按市况切换：牛/结构/震荡 → 1.5，熊市 → 2.0 或更紧。
  2. 1.0 淘汰（四年总账最低，3/4 年份劣于基线）。
  3. 1.5 是「四年总账最优 + 牛市放大器 + 弱市减损器」，不是弱市翻正药。
