## §1 实验目的与边界声明

### 1.1 本轮要回答的一个问句

box 的**谱系深度**（这只股票从样本内第一次箱体突破算起，已经突破了第几级箱体）与**突破后这笔交易的质量**是什么关系？

- 具体化：把每一笔已平仓交易的「入场 Box 的谱系深度」（沿 `prev_box_id` 链回溯到链头所需的步数）分带，看各带的**胜率 / 每单位净利 / 保本胜率 / 利润集中度 + PF + 剔除前三赢家净利**有没有梯度。
- 这是「Box 生命体征」六体征（出生/成长/阶梯/寿命/死亡/谱系）里的**谱系**体征，是达瓦斯「箱体像金字塔层层叠加」（L1405）的**层级位置**量化，不引入任何新理论（`docs/00` §3.6 唯一理论约束）。
- **与 LB-2 的区分**：LB-2 测「爬一级台阶花多久」（速度，时间量），LB-5 测「爬到第几级了」（位置，层级量）。两者是一对正交维度。

### 1.2 本轮明确回答不了的五件事

| # | 回答不了 | 原因 |
|---|---|---|
| 1 | **因果** | 「第几级箱体」与「突破质量」高度混杂：更深的谱系往往对应更长久的升势、更接近泡沫顶部（第 5 维距新高）、更老的主力盘等。本实验只报**相关性分布**，不下因果结论。 |
| 2 | **谱系深度该定多少才算「好」** | 本实验是 A 类分带统计，**不改回测器**。若发现某带有 edge，须另立 B 类，不在本实验范围。 |
| 3 | **样本外有效性** | 2005–2018 是全部参数被选定的同一段历史（`docs/29` §八.6），结论只用于提假设。 |
| 4 | **其他五体征** | LB-1（寿命）/ LB-2（阶梯速度）已收官；LB-4（成长速度）/ LB-3（出生方式）/ LB-6（死亡模式）不在本实验，LB-5 只做谱系深度。 |
| 5 | **2019+ 样本** | 规则定稿前禁碰（`docs/29` §八.6）。 |

### 1.3 结论句式模板（强制措辞）

> 在 2005–2018 的 __ 笔已平仓交易中，可复算谱系深度 __ 笔、首级箱体（链头）__ 笔、不可复算 __ 笔；谱系深度四带（1–5 / 6–12 / 13–20 / 21+ 级）的每单位净利分别为 __ / __ / __ / __，胜率 __ / __ / __ / __。
> H1（谱系深度与突破质量单调相关）**成立/不成立**；H2（深层箱体突破质量差）**成立/不成立**。
> 「谱系深度该定多少阈值」**本实验不回答**，只能由后续 B 类回测回答。

禁止出现的写法：`越深越好`、`该在早期箱体买`、`等到第 N 级箱体再进`。

## §2 实验假设（可证伪形式）

> **口径前置说明**：本实验的「谱系深度」是**入场 Box 沿 `prev_box_id` 链回溯到链头（`prev_box_id` 为 NULL）的步数**，即「这是这只票样本内第几级箱体」。
> 它与 LB-1 的「寿命」（一个 box 自己活了多久）、LB-2 的「阶梯速度」（相邻两级隔了多久）、「持仓天数」（买入到卖出隔多久）是**四个不同概念**。
> 本实验只研究「谱系深度」与「这笔买入的质量」的关系。

| 编号 | 假设 | 判据（同时满足才算成立） | 证伪条件 |
|---|---|---|---|
| **H1** | **谱系深度与突破质量单调相关**：更深的箱体（谱系层级更高），突破后交易质量越低 | 四带的每单位净利，4 个相邻对中 **≥ 3 个**随深度递增而递减（即层级越深每单位净利越低，严格小于） | 递减对 < 3 → **不成立**（记为「无单调梯度」） |
| **H2** | **深层箱体突破质量差**：谱系深度 ≥21 级（「金字塔最上层」）的 box，突破后是负 edge | `≥21 级` 带的每单位净利 **< 0**，且该带 `n ≥ 30`，且剔除前三赢家后净利仍 **< 0** | `≥21 级` 带每单位净利 ≥ 0，或剔除前三翻正 → **不成立** |

**H1 与 H2 不是互补关系。** H1 关心「全谱有没有单调梯度」，H2 关心「最右端那一带（最深）是不是坑」。可以 H1 不成立但 H2 成立，也可以都成立/都不成立。裁定允许四种组合，**禁止**为叙事漂亮压成二选一。

**方向约定（H1 的「递减」方向）**：本实验假设方向是**层级越深（谱系越老）质量越低**，即每单位净利随深度**递减**。这是达瓦斯原书「箱体金字塔越高，越接近行情末端」的直觉延伸——越晚的箱体越可能买在行情尾部。但**判据方向在跑数前写死**，不得看结果调整。

**判据阈值（≥3 递减对 / ≥21 级每单位 <0 / n≥30）在跑数之前写死**，不得看结果调整。

## §3 数据准备过程

### 3.1 只读纪律

- 一律用 `sqlite3.connect("file:<db>?mode=ro", uri=True)`。
- 不写回测库、不碰生产库 `darvas.db`（`docs/06` §6.2 库隔离）。
- 不重跑任何回测、不改任何参数、不重建任何索引。

### 3.2 取数口径

**关联链**（`entry_box_id` 在新基线库全为 NULL，须反向匹配，见 §3.3；沿用 LB-1/LB-2 已验证的关联键）：

```
position ──leg_no=1──▶ position_leg ──plan_order_id──▶ plan_order
   │                                                      │
   │ status='closed'                                      │ reason_json.box_top / box_bottom
   │ realized_pnl                                         │ signal='breakout'
   ▼                                                      ▼
  交易样本                                      code + box_top + box_bottom
                                                        │ 精确匹配
                                                        ▼
                                                    box 表（入场 Box）
                                                        │ prev_box_id（前驱）
                                                        ▼
                                       沿 prev_box_id 链回溯到链头（prev=NULL）
                                                        │ 步数累计
                                                        ▼
                                       谱系深度 = 从入场 Box 走到链头的步数
```

单库两条 SQL：

```sql
-- ① 交易样本（复用 LB-1/LB-2/P2-5 的成本口径：cost_basis 从 legs 求和，position.qty 平仓后清零）
SELECT p.id, p.code, p.realized_pnl, p.close_reason,
       tp.execute_date AS ex_date, o.reason_json,
       (SELECT SUM(qty)       FROM position_leg WHERE position_id=p.id) AS qty,
       (SELECT SUM(qty*price) FROM position_leg WHERE position_id=p.id) AS cost_basis
FROM position p
JOIN position_leg l ON l.position_id=p.id AND l.leg_no=1
JOIN plan_order o ON o.id=l.plan_order_id
JOIN trade_plan tp ON tp.id=o.trade_plan_id
WHERE p.status='closed'

-- ② 入场 Box 匹配（用 reason_json 里的 box_top/box_bottom 精确匹配，含 prev_box_id）
SELECT id, prev_box_id, bottom_confirmed, broken_date, top, bottom, status
FROM box WHERE code=? AND ABS(top-?)<1e-6 AND ABS(bottom-?)<1e-6 AND status='broken_up'

-- ③ 沿链回溯（反复取 prev_box_id，直到 NULL 或循环或断链）
SELECT prev_box_id FROM box WHERE id=?
```

提取字段：

| 字段 | 来源 | 用途 |
|---|---|---|
| `year` | 库文件名 `bt_baseA_<year>.db` | 逐年分组 |
| `realized_pnl` | `position` | 实际盈亏（净额，含双边费用） |
| `qty` / `cost_basis` | `position_leg` 求和 | 成本口径（§3.3 陷阱） |
| `units` | `reason_json.units` | 每单位净利分母 |
| `box_top` / `box_bottom` | `reason_json` | **反向匹配 box 的键** |
| `prev_box_id` | `box` | 链回溯的锚点 |
| `lineage_depth` | ③ 链回溯 | 谱系深度 = 走到链头的步数（链头本身 = 1 级） |
| `newhigh_distance_pct` | `reason_json` | 附录切片（与第 5 维交叉） |

### 3.3 两个必须绕开的陷阱

**陷阱一：`entry_box_id` 在新基线库全为 NULL。** 与 LB-1/LB-2 同因（`ledger.go:405 reasonBoxID` 读的 `box_id` 字段在现行新基线二进制里是死代码路径，planner 没写）。
**绕开方式**：用 `reason_json` 里的 `box_top` / `box_bottom` + `code` 三元组反向精确匹配 box 表（LB-1 已证唯一命中率 100%）。

**陷阱二：`position.qty` 在平仓后被清零。** 成本一律从 `position_leg` 求和（`cost_basis = Σleg.qty×leg.price`），与 LB-1/LB-2/P2-5 同口径。

### 3.4 反向匹配与链回溯的唯一性验证（HARD 前置）

- `(code, box_top, box_bottom)` 三元组在 box 表里的命中必须是唯一的。多命中取 `broken_date` 最新（与 LB-1/LB-2 同规则），仍不唯一则标「匹配失败」。
- **链回溯完整性**：沿 `prev_box_id` 回溯时必须能走到链头（`prev_box_id` 为 NULL）。断链（前驱被删除，`docs/36` 缺口 L5）或**循环**（`prev_box_id` 链成环）则标「不可复算」。
- 实测（§3.2 前）1481 笔全部可回溯、环断 0、链完整（LB-2 已证 19363 个 prev 非 NULL 的 broken_up box 前驱全部存在）。

### 3.5 谱系深度的口径边界（`docs/36` 第六法）

- **链头** = 沿 `prev_box_id` 回溯遇到的第一个 `prev_box_id IS NULL` 的 box。
- **谱系深度** = 从入场 Box 走到链头的**步数**（入场 Box 自己算第 1 级，每沿 `prev_box_id` 走一步 +1）。
  含义 = 「这是这只票样本内第几级箱体」。
- **首级箱体** = 入场 Box 本身 `prev_box_id IS NULL`（深度 = 1）。
- **循环断链**：`prev_box_id` 链成环（理论上不应发生，但引擎重建/删除可能制造），标「不可复算」。
- **800 根窗口左截断**：`docs/36` 缺口 L4——若链头 box 落在窗口左边界之外被删除，回溯会在半路断链（链长被**低估**）。这是本实验的已知系统性偏差，登记在 §9，结论章必须携带。

### 3.6 样本漏斗（跑前登记，结构锚点）

| 步 | 说明 | 预期 |
|---|---|---|
| 1 | 14 个回测库（2005–2018） | 14 库 |
| 2 | `status='closed'` 且有 leg1 | **1481 笔**（LB-1 §0 实测锚点） |
| 3 | reason_json 缺 `box_top`/`box_bottom`（非 breakout 信号） | 登记，不进谱系深度分带 |
| 4 | 反向匹配 box 失败（无唯一命中） | 登记「不可复算」，不进谱系深度分带 |
| 5 | 链回溯循环断链 | 登记「不可复算」，不进谱系深度分带 |
| 6 | **可复算谱系深度样本** | 待跑数，见报告 |

### 3.7 已知数据偏差（结论必须携带）

- **未复权（`adj_factor` 恒 1.0）**：box 的 top/bottom 是未复权价，匹配不受影响；但跨除权日的 box 边界本身可能有语义噪声。
- **800 根窗口左截断**（§3.5）：谱系链被系统性低估长度，深层箱体可能被误判为浅层。
- **幸存者偏差**：只用当前仍存在的股票，退市股不在样本内。
- **无基线对照不构成缺口**：本实验只统计新基线自身，与账本基线（1328 笔）是不同仓位语义，不横比（`docs/29` §〇）。

## §4 口径定义

### 4.1 核心两式

```
lineage_depth = 从入场 Box 沿 prev_box_id 回溯到链头（prev=NULL）的步数，入场 Box 自己 = 1
pu            = realized_pnl / units          # 每单位净利（units 取自 reason_json.units）
```

### 4.2 为什么谱系深度用「链回溯步数」而不用「前驱数量相减」

谱系深度的本质是「层级位置」，必须沿 `prev_box_id` 链**实际走一遍**才能确定，不能靠任何单一字段直接读出（box 表没有「层级」列）。链回溯是唯一正确口径，且与引擎的阶梯语义一致（`engine.go` 的 `lastConfirmed` 链）。

### 4.3 统计口径（每带必须齐备，与 LB-1 / LB-2 / P0-1 / P2-5 同构）

| 口径 | 公式 | 备注 |
|---|---|---|
| 胜率 | `wins / closed` | 已平仓头寸中盈利占比 |
| 每单位净利 | `Σpnl / Σunits` | `units` 集合 ⊆ {0.5, 1, 2, 3} |
| 保本胜率 | `1 / (1 + 平均盈利/|平均亏损|)` | 即 `|avgLoss| / (avgWin + |avgLoss|)` |
| 利润集中度 | 前三赢家合计 / 毛盈利 | 无毛盈利或前三合计为负时记 `—` |
| 附加 A | 利润因子 PF = 毛盈利 / |毛亏损| | |
| 附加 B | **缺口** = 实际胜率 − 保本胜率（pp） | `docs/29` §八.2 判定用 |
| 附加 C | **剔除前三赢家净利** | 识破「假 edge」的关键列 |
| 附加 D | 剔除前三赢家每单位净利 | 同上 |

### 4.4 分带驱动变量（谱系深度）

`lineage_depth` 分四带（§5.1）。本实验**不做**「谱系深度 vs 寿命」「谱系深度 vs 阶梯速度」的交叉（那是 LB 系列内部交叉验证，留待 LB 系列 A 类全收官后联验），只报谱系深度这一个分组变量（OFAT，`docs/29` §2.3）。

## §5 分带设计

### 5.1 主带：谱系深度四带（预设规则，禁止按结果合并）

```
[1,6)  [6,13)  [13,21)  [21,+∞)
```

即 **1–5 级 / 6–12 级 / 13–20 级 / 21 级+**。

**切法说明**：谱系深度是「箱体金字塔层级」，用 5/12/20 三个界切出「早期 / 中期 / 中后期 / 后期」四段金字塔。**这些边界是预设的固定值，不是拟合拐点。**
（数据可行性探测仅用于确认「四带不会出现空箱」，实测 1–5 级 102 笔、6–12 级 155 笔、13–20 级 586 笔、21+ 级 638 笔，全部 ≥30 笔，非空。）

### 5.2 样本不足的加密规则

- 若某带 `n < 30`，按 §7.1 标「样本不足」，**不合并**（`docs/29` §2.5.1 第 4 条）。
- **浅层带（1–5、6–12）不再加密**（浅层每级仅 9–34 笔，逐级太稀，加密只会产生大量空箱）。若结果出现「某带每单位净利异常高、集中度 >50%、剔除前三翻负」，按 §7.3 直接裁定为「假 edge」，不再降粒度。

### 5.3 空带与不可复算样本的呈现规则

- **不可复算样本**（reason_json 缺 box 字段 / box 匹配失败 / 链回溯循环断链）**不进四带**，单设「不可复算」子集行，标注「子集标记，非加总行」。
- 加总恒等式：`Σ(谱系深度四带 n) + 不可复算 n = 1481`。
- **注意**：本实验的「首级箱体」（深度=1）**属于四带中的 1–5 级带**（与 LB-2 把首级箱体单列不同——因为谱系深度的 1 级本身就是一个有意义的层级值，不是「无前驱不可算」）。深度=1 的箱体数量极少（实测 9 笔），不单列。

### 5.4 逐年矩阵

14 年 × 4 带，每格印「净利（笔数）」。缺失年份登记原因，**不得留空**（HARD 校验 §7.5）。

## §7 判定标准

### 7.1 三条硬门槛（缺一不得下结论）

1. **样本量**：`n ≥ 30`；不足则标「样本不足，仅供参考」。
2. **有样本年数**：`Mf ≥ 8`（过滤后「该年该带 n≥3」的年数）；不足则标「出现年数不足，不作跨年裁定」。
3. **完整性**：四项固定口径 + PF + 缺口 + 剔除前三，缺一项即不得下结论。

### 7.2 跨年一致性记账规则

- `M` = 该带 `n > 0` 的年数；`P` = 该带年度净利 > 0 的年数。
- **过滤后符号统计**：只把「该年该带 `n ≥ 3`」的年计入 `P'` / `M'`，**判定用过滤后那一组**。
- 记分卡必须**同时印出** `P/M` 与 `P'/M'`。
- `longest_run` = 最长连续同号年数（对应 `docs/29` §八.3「连续 ≥2 年同符号」）。

### 7.3 逐带裁定矩阵（与 LB-1 / LB-2 / P0-1 同构，便于横向对比）

| 条件 | 裁定标签 |
|---|---|
| `n < 30` | **样本不足** |
| `n ≥ 30` 且 `Mf < 8` | **出现年数不足** |
| `n ≥ 30`、`Mf ≥ 8`、`pos_ratio' ≥ 0.70`、缺口 ≥ +2pp、剔除前三仍为正 | **edge** |
| 同上但剔除前三为负 | **假 edge（少数交易撑起）** |
| `pos_ratio'` 在 0.30–0.70 | **不稳定（不得下 edge 结论）** |
| `pos_ratio' ≤ 0.30`、缺口 ≤ −2pp | **负 edge** |

判定顺序：**先查剔除前三是否翻负（假 edge）→ 再查跨年稳定性**（P0-1 附 A 方法论修正 1，本实验继承）。
补充：缺口在 ±2pp 之间一律记「无 edge」。

### 7.4 H1 / H2 的裁定输出

两条假设**各自独立裁定**，输出格式固定为：

```
H1 [成立/不成立]  递减相邻对 __/4（需≥3）  四带每单位净利 __ / __ / __ / __
H2 [成立/不成立]  ≥21 级带每单位净利 __（需<0）  n=__（需≥30）  剔除前三 __（需<0）
```

### 7.5 HARD 校验（生成器必须断言，失败即中止）

| # | 校验 | 判据 |
|---|---|---|
| HARD① | **样本总对账**：Σ 各库 closed 笔数 = 1481 | 严格相等 |
| HARD② | **加总恒等式**：Σ(四带 n) + 不可复算 n = 1481 | 严格相等，不静默丢弃 |
| HARD③ | **逐年符号表齐备**：2005–2018 每年都在矩阵里 | 14 行齐全 |
| HARD④ | **反向匹配唯一性**：每笔可复算样本的 box 匹配命中 = 1（多命中按 §3.4 规则取最近） | 失败 0 笔 |
| HARD⑤ | **链回溯无循环**：沿 prev_box_id 回溯不得成环 | 循环 0 笔 |
| HARD⑥ | **谱系深度为正**：`lineage_depth ≥ 1` | 0 笔 <1 |
| HARD⑦ | **成本两路一致**：`avg_cost×qty` vs `Σ(qty×price)` | 相对误差 < 1e-3 |
| HARD⑧ | **逐年净利对账**：Σ 各年 `realized_pnl` = +1,461,228.2（容差 1.0） | 见 §7.6 锚点 2 |

WARN 级（不中止，但必须出现在报告附 A）：谱系深度各带笔数分布是否极端不均、800 根窗口左截断影响的首级/断链 box 数量。

### 7.6 校准锚点（生成器每次必须断言）

> **诚实声明**：本框架登记时只做过**结构级**可行性探测（样本 1481 / 谱系深度可算 1481 / 链回溯无循环 /
> 分带非空），**未看过任何谱系深度分带的盈亏结果**。以下锚点全部是结构性的：

1. 已平仓样本 = **1481**
2. `Σrealized_pnl = +1,461,228.2`（容差 1.0）
3. 单腿头寸占比 = **100%**（`legs_per_position` 全为 1）
4. `units` / `box_top` / `box_bottom` 缺失笔数 = **0**（实测齐备）
5. 链回溯循环断链笔数 ≈ **0**（结构性锚点）
6. 谱系深度范围 ≈ **1–36**（结构性锚点，p50 ≈ 19）

**执行中的方法论修正与结构性发现**：

1. **链回溯完整 100%**：1481 笔全部沿 `prev_box_id` 链回溯成功，0 循环、0 断链。谱系深度范围 1–36 级，中位 19 级（p25=15 / p75=23），分布集中在 8–26 级。`prev_box_id` 链（局部 ID 0 → DB 存 NULL）作为谱系锚点完全可靠。

2. **结果与 LB-1/LB-2 形成三角关系**：LB-1 证「寿命越短越好」、LB-2 证「阶梯越快越好（一半）」，而 LB-5 证**「谱系越浅越差」**——早期箱体（1–5 级、6–12 级）才是坑。三者不矛盾：寿命短 ≠ 阶梯快 ≠ 谱系浅。一个「第 20 级的箱体」可以寿命很短（刚确认就突破）、阶梯很快（爬得快），这三个体征是**独立正交**的。

3. **两个浅层带都是「假 edge」**：1–5 级每单位 +154（PF 1.15 最低、剔除前三 −43,025）、6–12 级每单位 +1,078（PF 2.62 最高但集中度 64.7%、剔除前三 −8,906），剔除前三双双翻负——浅层箱体的表面盈利靠少数赢家撑起。只有 13–20 级（剔除前三 +290,916）与 21 级+（+292,721）剔除前三仍为较大正值。

4. **「第 6–12 级」这一带是陷阱**：PF 2.62 全表最高、缺口 +10.6pp，但胜率仅 18.7%（最低）、集中度 64.7%（最高）——典型的「低胜率 + 高赔率 + 少数赢家」结构，剔除前三即翻负。这正是 P0-1 附 A「剔除前三识破假 edge」教训的第四次复现。
