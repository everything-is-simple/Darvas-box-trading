> 生成器：`scripts/base_snowball.py`（只读 `var/bt/base/bt_baseA_<year>.db` 的 `equity_snapshot`，逐日链式复利）
> 参数：`newhigh_ladder=on lookback=252 cutoff=40 units=3/2/1/0.5 pool.max_hold=14 pos.equity_gate=off gate.ma60=stop@sh000001 staledays=2`
> 数据：14 年齐全（2005–2018 全段）
> 算法：`level_d = level_{d-1} × (total_d / total_{d-1})`；跨年直接衔接（每年首日权益恒 = 1,000,000）

## 五、诚实边界

1. **这是「按年收益率的复利推演」，不是连续交易路径的重跑**：真连续跑时下单金额基于复利后权益，整手取整、持仓上限、黑名单冷启动的边界行为都会变。
2. **跨年强制衔接**：年末未平仓头寸按市价结算带入下一年起点（`equity_snapshot` 已含浮盈）。
3. **容量未计**：14 年复利到数百万仍属小资金，冲击成本未建模。
4. **无风险利率取 0**：夏普仅作相对指标。
5. **历史锚不可重算**：账本基线与擂主的逐笔库在老机、未随包带来，表中数值只能引用，本机无法复现其曲线。
