核心结论

  • 「距新高越近越好」不是单调规律。2% 细粒度下，edge 呈「甜点区—陷阱区」交替：0–2% 与 2–4% 都正贡献，但 2–4% 才是真正引擎（+640,260，胜率 39.3%，PF 4.02）；紧接着的 4–6% 直接转负（-17,273，PF 0.89）。
  • 甜点区就藏在 t1 内部，断裂点恰在 5% 边界。t1（0–5%）合计 +827,309，但它的利润几乎全来自 2–4% 这一小段（+640,260）；一旦越过 5%（进入 t2 头部的 5–6%），edge 立刻转负。这说明「距新高」的价值集中在 2–4% 这一窄带，而非「越近越好」的宽泛单调。
  • 远档（20%+）无稳定正期望。20–25% 明确亏损，25–40% 三个分段虽微正但 PF 徘徊在 1 附近、利润集中度低，属于「高风险观察区」而非 edge。
阅读方式：本报告把达瓦斯「距 52 周新高」从四档粗分细化到 2% 粒度，用四项固定口径（胜率 / 每单位净利 / 保本胜率 / 利润集中度）逐段验证。红线向右为盈利、绿线向左为亏损。所有数据只读自回测库，未重算、未改回测器。
