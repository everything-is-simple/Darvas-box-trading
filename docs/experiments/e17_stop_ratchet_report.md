## 核心结论

- 2005–2018 共 **1481** 笔已平仓交易，其中止损从未上移（ratchet=1.0）**995** 笔（67%），上移过 **486** 笔。
- 四带每单位净利：未上移（=1.0） **-331** / 1.00–1.10 **+179** / 1.10–1.50 **+2,581** / 大幅上移（>1.5） **+5,767**，递增相邻对 3/3。
- **内生性警示**：止损上移本身就是「股价大涨」的结果。总净利梯度再漂亮也可能是同义反复，不能据此说「上移导致多赚」。
- **决定性拆解（受害者计数）**：未上移的 995 笔里，曾浮盈 &gt;30% 的仅 **33** 笔，其中最终亏损的 **1** 笔（涨过 30% 却亏 = 真正的「止损没跟上」受害者）。
- **结论：raiseStops 没有「追不上」的问题。**未上移的票 97% 从未涨过 30%（本来就没涨、本来就该亏），真正「涨了很多却因止损钉在低位而倒亏」的受害者仅 **1** 笔（995 笔里涨过 30% 却亏的），体量可忽略。「上移幅度 vs 净利」的梯度是内生性，不是可干预缺陷。维持现状，不做 B 类。

## 口径

**内生性**：止损上移是「涨得多」的结果，不能只看总净利梯度，必须看剔除前三 + 回吐率。
