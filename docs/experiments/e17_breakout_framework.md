## §1 实验目的与边界声明

### 1.1 本轮要回答的问句

1. **在已通过 3% 突破门槛的 1560 笔样本内部**，突破强度（收盘价高于箱顶的百分比）**还有没有区分度**？分 6 个 1% 带后，每单位净利是否单调、是否跨年一致、剔除前三赢家后是否仍为正？
2. **在已通过 2× 量比门槛的样本内部**，量比倍数**还有没有区分度**？分 6 个带后同上。
3. **被 `max_entry_gap=1.05` 弃掉的 118 笔**，如果买了会怎样？——这是本轮唯一可能产出「该改参数」证据的臂。

### 1.2 本轮明确回答不了的六件事

| # | 回答不了 | 原因 |
|---|---|---|
| 1 | **3% 这个门槛该定在哪** | 0–3% 强度带**结构性无样本**：所有低于门槛的突破在 `isBreakout`（`engine.go:203`）就被拦掉，根本不产生买入单。要回答「降到 1% 会怎样」**必须 B 类**。 |
| 2 | **2× 这个门槛该定在哪** | 同上：0–2× 量比带结构性无样本。 |
| 3 | **因果** | 强度与市况（牛市突破更强）、流动性、股本高度混杂；每单位净利与年份不可分离。 |
| 4 | **强度上限是不是市场规律** | 上限 8.15% = `buy.premium(1.03) × match.max_entry_gap(1.05)`，是**参数乘积**。要观测真实的强度分布必须放开两个参数（B 类）。 |
| 5 | **样本外有效性** | 2005–2018 是参数被选定的同一段历史（`docs/29` §八.6）；结论只用于提假设。 |
| 6 | **日内路径** | 只有日线。强度按收盘价算，无法知道盘中最高突破多少。 |

### 1.3 结论句式模板（强制措辞）

> 在 2005–2018 的 1560 笔已成交买入中，可计盈亏 __ 笔（__ 笔年末未平仓无已实现，不计入）。强度分 6 带后，每单位净利为 __ / __ / … ，跨年正贡献 __/14 年，剔除前三赢家后 __；量比 6 带同理。
> H1（强度有单调梯度）/ H2（量比有单调梯度）**成立或不成立**；H4（门槛已充分）**成立或不成立**。
> 被 `max_entry_gap` 弃掉的 118 笔，N 日远期收益中位 __%，同口径 filled 对照 __%，差 __pp → `max_entry_gap` 该收紧 / 该放宽 / 无法判断。
> **「3%/2× 该定在哪」本实验不回答**，只能由 B 类单变量扫描回答。

禁止出现的写法：`3% 门槛太松/太紧`、`强度越高越好`、`放量突破更可靠`、`证明门槛应该改成 X%`。

## §2 口径定义（唯一事实源，禁止临场改）

### 2.1 强度与量比的复算公式

| 指标 | 公式 | 说明 |
|---|---|---|
| **强度** `strength` | `daily_bar.close(plan_date) / reason_json.box_top − 1` | 突破信号日收盘相对箱顶上轨的涨幅 |
| **量比** `volratio` | `daily_bar.volume(plan_date) / avg(volume, plan_date 之前 50 个交易日)` | **不含 plan_date 当日**，与 `avgVolumeBefore(bars,i,50)`（`engine.go:227`）同语义；近上市端用 `min(50, i)` 短窗 |
| **进场跳空** `entry_gap` | `trade_fill.price / plan_order.trigger_price − 1` | 上限由 `max_entry_gap=1.05` 硬性截断 |
| **触发价** | `trigger ≡ box_top × buy.premium(1.03)` | 容差 1e-6，HARD③ 校验 |

### 2.2 分母口径

- **信号分母**：`plan_order(side='buy', status='filled')` 计数 = 1560；实测 ≡ `position` 行数（HARD①）。
- **盈亏分母**：`position.realized_pnl IS NOT NULL` 的已平仓 = 1481（79 笔年末未平仓，五个年份各有一批；**无已实现，不进盈亏口径**）。每带必须同时报 `n_signal` 与 `n_closed`，禁止只报一个。
- **禁止**用 `status != 'cancelled'` 当分母（会多算 77 笔 expired）。

### 2.3 四项固定口径 + 三项附加（每带必报，缺一不可）

沿用 `scripts/base_year_summary.py::load_year()` 的实现（口径统一是铁律，不重写）：

| 指标 | 定义 |
|---|---|
| 胜率 | `realized_pnl > 0` 占 `n_closed` |
| 每单位净利 | `Σrealized_pnl / Σunits`，`units = 建仓成本 / (建仓日权益 × 2%)`；**已实现口径** |
| 保本胜率 | `avg_loss / (avg_win + avg_loss)`（`avg_*` 按该带的盈亏笔均值） |
| 缺口 | `胜率 − 保本胜率`（符号是牛熊判别器） |
| 利润集中度 | `top3 / gross_win`（**不是 /净利**，亏损年避免 NaN） |
| PF | `gross_win / gross_loss` |
| 剔除前三赢家净利 | `Σrealized_pnl − top3`（识破假 edge 的关键列） |
| 持中位（交易日） | `opened_date → closed_date` 之间的 `daily_bar` 根数，**不用自然日** |

### 2.4 建仓成本口径（P2-5 血泪坑）

`position.qty` 平仓后清零、`avg_cost` 保留但**不可作为分母**。成本必须取
`Σ(position_leg.qty × position_leg.price)`。本库实测全部 1560 笔 `leg_no = 1`（单腿，无加仓），
`avg_cost × qty ≡ Σ(qty × price)` 应逐笔相等（HARD④ 抽查）。

## §3 分带设计（预设，禁止按结果合并/拆分/挪界）

### 3.1 臂 A · 突破强度（1% 粒度）

`3–4% / 4–5% / 5–6% / 6–7% / 7–8% / 8%+`

**为什么必须 1% 而不是 5% 等距**：有效跨度只有 3.00%–8.14%（约 5pp），5% 等距会碎成「3–5%」与「5–10%」两个带，样本失衡且无法定位。

### 3.2 臂 B · 突破量比（后段加密）

`2–2.5× / 2.5–3× / 3–4× / 4–5× / 5–8× / 8×+`

**为什么后段加密**：长尾到 22.7×，等距切会让前 4 带挤满 90% 样本、尾部每带 <10 笔。

### 3.3 臂 C · 被弃样本（反事实，独立口径，见 §4）

### 3.4 附加维度 · 进场跳空

`0–1% / 1–2% / 2–3% / 3–5%`（由 `max_entry_gap` 截断在 5%）。看「买得越贵是否越差」，与臂 C 互为验证。

### 3.5 样本不足规则

任一档 `n_closed < 30` → 标 **「样本不足」**，**不合并、不解释、不参与裁定**，只登记数值。

### 3.6 异常集中归因（P2-5 教训）

若某带中位强度/量比异常堆在闸门值附近（如强度 p50 ≈ 3.0%），**先回引擎查是哪条规则把它们归进这一带**，写进报告，**不许当市场规律**。

## §4 臂 C · 被弃样本反事实（本轮最值钱，口径必须钉死）

### 4.1 样本

`plan_order(side='buy', status='cancelled')` = 118 笔。语义：`matchOrder` 命中、但
`slip(px)/trigger > max_entry_gap(1.05)` → 判「跳空追高」弃单（`match.go:112-123`）。

### 4.2 反事实入场价的复算规则（照抄引擎，禁止自创）

对 `execute_date` 的日线 bar：

1. `open ≥ trigger` → 入场价 `px = open`（跳空高开，引擎即按开盘价成交）；
2. 否则 `high ≥ trigger` 且 `open < trigger` → `px = limit_price`（盘中上穿）；
3. 再叠滑点：`px = px × (1 + match.slippage)`，`match.slippage = 0.002`（`slip()`，`match.go:197`）。
4. 若 `matchOrder` 判不中（`!hit`）→ 该单本不该被弃，**单独登记为异常**，不进统计。

### 4.3 收益测量（三档并列，全部固定口径）

| 口径 | 定义 |
|---|---|
| **裸持有 N 日** | `close(entry_date + N 个交易日) / px − 1`，N = 5 / 10 / 20 |
| **止损版 N 日** | 逐日检查 `low ≤ reason_json.stop`，先触发则按 `min(open, stop)` 出场；否则按 N 日收盘 |
| 费用 | 买卖双边佣金+印花+过户（`fee.*` 参数），仅在报告附录给一次量级，主表用未扣费收益 |

### 4.4 对照组（必须同口径，禁止与「全体 1560 笔的 realized_pnl」直接比）

1. **filled 全体**：同一 N 日裸持有口径，入场价用 `trade_fill.price`、入场日 `trade_fill.date`；
2. **filled 高跳空带**（`entry_gap 3–5%`）；
3. **filled 高强度带**（`strength 7–8%` 与 `8%+`）。

三组都要报，因为 118 笔本身是被「跳空 >5%」选出来的强度尾部，只和全体比会混淆「跳空大」与「强度高」。

### 4.5 裁定标准（预注册，臂 C 专用）

- 主判据：合并口径的 N=5/10/20 三个时点的收益差方向是否一致 + 剔除前三后仍同向；
- **强制报 2015 占比**；若 2015 > 40%，结论降级为「2015 年声明」，不当作 14 年结论；
- 方向一致性优先于显著性（118 笔，逐年一致性无统计力，不设跨年门槛）。

## §5 预注册假设与裁定规则

| # | 假设 | 成立条件（三条同时满足） |
|---|---|---|
| **H1** | 强度有单调梯度（越高越好或越差） | ① 6 带每单位净利**单调**（反序 ≤1 且 **\|ρ\| ≥ 0.8**）；② 最带差异 **> 600 元/单位**（= 3% × 单位值 20,000）；③ 剔除前三后符号与主方向一致；跨年辅助：带-年 `n≥10` 的年里方向一致 ≥ 8/14 |
| **H2** | 量比有单调梯度 | 同 H1 |
| **H3** | 门槛是瓶颈（低强度/低量比带明显更差 → 该加严） | 最低带每单位净利显著低于最高带（>600 元）且剔除前三仍成立 → 值得 B 类加严 |
| **H4** | **门槛已充分**（默认结论） | 所有带差异 < 600 元/单位，或剔除前三后全负 → 关闭两个维度，不立 B 类 |

> **判据修订（2026-10-30，执行中收紧，登记于 §10-#7）**：①「反序 ≤1」单独用会把**峰值形态**
> 判成梯度（实测跳空臂 372→1000→1266→644，只有 1 处反序）。补 **Spearman \|ρ\| ≥ 0.8** 作主判据，
> 对三臂同时生效。这是**收紧**，只会让更多臂被判「无稳定结论」，不会制造假阳性。

**裁定顺序**：先查 H1/H2；不成立则看 H3 是否成立（加严有价值）；都不成立 → 判 H4。

**跨年一致性的定位（写死）**：`8%+` 强度带、`8×+` 量比带样本极小（信号 n 分别 22 / 21），
摊到逐年必然 n<5，**逐年一致性对这些带不可算**。主判据 = 合并梯度 + 超噪声 + 剔除前三；
跨年只做辅助，**带-年 n≥10 才算数**，否则该带不参与跨年判定。

## §6 混淆控制

1. **强度 × 量比相关性**：报 Spearman ρ。实测 **ρ = 0.066**（|ρ| < 0.3）→ 按规则**不做**二维交叉表；若复算结果 |ρ| > 0.3 则必须补做 3×3 交叉表。
2. **年份**：每带报「正贡献年份数 / 可算年份数」，并单独报 2015（牛）与 2018（熊）。
3. **仓位/资金约束**：不同带的建仓数不同（强信号更容易抢到仓位），**一律比每单位净利，不比总净利**。
4. **regime**：`reason_json.gate_ma60.below` 记录建仓日 MA60 上下，作为分层校验（只做稳健性切片，不做主判据——P0-3 已证 MA60 下方为负 edge）。

## §7 HARD 校验（全过才算完成）

| # | 校验 | 判据 |
|---|---|---|
| ① | 分母闭合 | 逐年 `plan_order(buy, filled)` 计数 ≡ `position` 行数；14 年和 = **1560** |
| ② | 分带并集 | 各带 `n_signal` 之和 + 缺行情数 = 1560；缺行情必须为 **0** |
| ③ | 强度复算一致性 | 抽 30 笔手工核对 `close(plan_date)/box_top − 1`；同时验 `trigger ≡ box_top × 1.03`（容差 1e-6） |
| ④ | 盈亏对账 | 抽 30 笔 + 逐年合计，与 `base_year_summary.load_year()` 的 `realized` 对齐（同库同年） |
| ⑤ | 异常归因 | 若某带中位强度异常集中在 3.0% 附近，回查规则来源并写入报告 |
| ⑥ | 门槛语义下界 | 1560 笔复算后 **量比全部 ≥ 2.0 且强度全部 ≥ 3.0**（口径一错就会现出低于闸门的值） |

## §9 B 类规格（本轮不立，A 类出信号才启动）

**铁律：一次只动一个变量**。扫幅度时量比门槛钉 2.0，扫量比时幅度门槛钉 1.03，其余参数全冻结。

**分带口径：统一按「突破当日观测值」，门槛档位只负责把各带填满。**

| 观测带（幅度） | 门槛 `buy.premium` |
|---|---|
| 0–1% | 1.00 |
| 1–3% | 1.00 / 1.01 |
| 3–5%（基线区） | 1.03 / 1.04 |
| >5% | 1.05（受 `max_entry_gap` 截断） |

| 观测带（量比） | 门槛 `box.volmult` |
|---|---|
| 0–1× | 1.0 |
| 1–2× | 1.0 / 1.5 |
| 2–5×（基线区） | 2.0 / 2.5 |
| 5–8× | 3.0 |
| >8× | 3.0+（观测尾部） |

- 代表年：2012 / 2015 / 2017 / 2018（沿用 P2-6a 四年代理）。
- 结构约束：① 观测带 ≠ 门槛档，同带可跨多档归并；② `>5%` 幅度带受 `premium × max_entry_gap` 乘积截断，须报「实际入场/理论应入」缺口；③ `>8×` 量比带是观测尾部。
- 带界固定（0/1/3/5/8），禁止按结果挪界；`n<30` 标样本不足。
