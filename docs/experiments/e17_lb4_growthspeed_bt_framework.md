## §1 实验目的与边界声明

### 1.1 本轮要回答的问句

**唯一命题**：把「只买快成型箱体（轨确认延迟短）」做成引擎里的**买入准入门槛**（成长速度 ≤ 阈值才允许买入，
超过阈值不产生买单），是否提升系统收益？最优门槛在哪？

- LB-4 A 类后验已证：成长速度与突破质量**单调相关**（4-5 日每单位 +1,015 → 11 日+ +320），
  4–5 日带是 LB 系列唯一「剔除前三仍成片为正」的强带。
- 本 B 类验证：这个相关性**能不能转成可执行的准入规则**（真金白银改准入、对比基线）。

### 1.2 本轮明确回答不了的

| # | 回答不了 | 原因 |
|---|---|---|
| 1 | **成长速度低端（<4 日）** | 结构性无样本——受「上/下轨各需 3 日确认」规则刚性钳制，最小 4 日 |
| 2 | **样本外有效性** | 代表年仍是参数被选定的同一段历史；结论只用于提假设 |
| 3 | **因果** | 成长速度快可能与「强势股快速成型」内生相关，不推断因果 |

### 1.3 方向声明（准入，不是放宽）

本实验是**收紧**准入——门槛越紧（阈值越小），样本（笔数）越少。这与 P1-4 量比（放宽 2.0→1.0）方向相反，
是**砍掉慢成型箱体**而非**放行缩量突破**。故判定时**必须并列「每单位净利」与「笔数/总盘子」**：
「每单位变好」但「总盘子缩水」未必是净收益——空出来的资金可能没有更好的去处（机会成本），
也可能正好避开了坏交易。两者分开看，不混为一谈。

## §2 口径定义（唯一事实源，禁止临场改）

### 2.1 成长速度定义（与 A 类、与引擎完全一致）

| 指标 | 公式 | 说明 |
|---|---|---|
| **成长速度** `growth_speed` | `daily_bar` 在闭区间 `[top_confirmed, bottom_confirmed]` 的交易日计数（含两端） | `top_confirmed`=上轨 3 日确认日、`bottom_confirmed`=下轨 3 日确认日；与 `e17_lb4_growthspeed.py` A 类口径一字不差 |

引擎侧实现：`planner.buyOrder` 读 `box.TopConfirmed`/`box.BottomConfirmed`（`LatestNonFormingBox` 已填充），
用 `BarRepo.BarCountClosed(code, TopConfirmed, BottomConfirmed)` 计数；`gs > max_growth_days` → 拒买。

### 2.2 分母口径

- **笔数分母**：`position.status='closed' AND realized_pnl IS NOT NULL` 的已平仓笔数（逐库）。
- **权益口径**：`equity_snapshot` 首末差 = 权益变动（含年末浮盈），仅作对账；
  **评价口径**用已实现 `realized_pnl`（docs/29 §2.5.2）。

### 2.3 四项固定口径 + 附加（每档必报）

| 指标 | 定义 |
|---|---|
| 胜率 | `realized_pnl > 0` 占已平仓笔数 |
| 每单位净利 | `Σrealized_pnl / Σunits`；已实现口径 |
| 保本胜率 | `avg_loss / (avg_win + avg_loss)` |
| 缺口 | 胜率 − 保本胜率 |
| 利润集中度 | 前三赢家 / gross_win |
| PF | gross_win / gross_loss |
| 剔除前三赢家净利 | `Σrealized_pnl − 前三赢家`（识破假 edge 的关键列） |
| **已实现净利总额** | `Σrealized_pnl`（区分「总盘子缩水」的关键列，B 类准入必报） |

### 2.4 单位口径

`units = Σ(position_leg.qty × price) / (开仓日权益 × 0.02)`——成本取 `Σ(leg.qty×price)`，
**不可用** `avg_cost × qty`（P2-5 血泪坑：`position.qty` 平仓后清零）。

## §3 分档设计（预设，禁止按结果合并/拆分/挪界）

| 档位 | 阈值 | 语义 |
|---|---|---|
| off | — | 基线（不注入参数，吃默认 0=关闭），复现历史基线 |
| 5 | ≤5 日 | 只买成长速度 ≤5 日的快成型箱体 |
| 6 | ≤6 日 | |
| 7 | ≤7 日 | |
| 8 | ≤8 日 | |
| 10 | ≤10 日 | 接近不筛（A 类分布中位 6 日，≤10 基本全放行） |

- 档位固定，**禁止按结果挪界或并档**；`n<30` 标「样本不足」，不合并不解释。
- 若某档样本太少导致跨年判断不可靠，再往下加密（≤4 日等逐日加密），切点必须是预设规则。
- **档位间不可比「带」**：每档是独立回测、独立资金轨迹，只能比端到端结果（每单位净利 + 总盘子），
  不能把「某档成交的某笔」直接与「另一档的某笔」对齐（资金分配有内生性，P1-4 量比教训）。

## §5 预注册假设与裁定规则

| # | 假设 | 成立条件 |
|---|---|---|
| **H1** | 收紧门槛提升收益（快成型箱体有可执行 edge） | 某档（非 off）每单位净利**显著高于** off 基线（差 > 600 元/单位），且剔除前三后符号不变，且跨年方向一致 |
| **H2** | 收紧门槛无价值（默认结论） | 所有档每单位净利与 off 基线差 < 600 元/单位（噪声内），或剔除前三后翻负 |

- **噪声门槛**：每单位净利差 > **600 元**（= 3% × 单位值 20,000）。
- **三条同时满足才算有结论**：① 幅度超噪声；② 剔除前三仍成立；③ 跨年方向一致（档-年 n≥10 才算）。
- **总盘子并列**：即使每单位变好，也要看「已实现净利总额」是否大幅缩水（门槛收紧砍掉笔数是必然，
  关键是砍掉的是不是坏交易——看「被砍掉的单」是否本就在亏钱）。
- 不挑单点最优；总账最优的档必须再降一级粒度复核是否成片（P0-1 教训）。

## §6 混淆控制

1. **样本量衰减**：门槛每收紧一档，笔数必然下降。报告的每个数字旁必须带 n，
   n<30 不下结论。
2. **年份**：每档报逐年每单位净利；2015（牛）与 2018（熊）单独列。
3. **仓位/资金约束**：不同档建仓数不同，一律比**每单位净利**，不比总净利绝对值。
4. **成长速度 × 距新高**：成长速度（维 11）与距 52 周新高（维 5）是独立维度，不交叉下因果。

## §7 HARD 校验（全过才算完成）

| # | 校验 | 判据 |
|---|---|---|
| ① | **零差异复现** | off 档重跑后，与历史基线库 `base/bt_baseA_<year>.db` 逐年已实现/权益变动**零差异**——证明默认 off 不污染基线、只改了这一个参数 |
| ② | **门槛语义下界** | 某档（如 ≤5）filled 单成长速度应全 ≤5；off 档成长速度应含 >5 的值（口径一错立刻现形） |
| ③ | **拦截正确性** | 收紧档的笔数 ≤ off 档笔数，且被砍掉的单成长速度 > 该档阈值 |
| ④ | **异常归因** | 若某档指标异常，回查规则来源（是准入规则本身还是样本量效应），写进报告，不当规律 |

## §8 报告结构（固定四段）

1. **档位总表**：6 档 × 四项口径 + PF + 剔除前三 + 笔数 + 已实现净利总额；
2. **跨年稳定性**：逐年每单位净利矩阵；
3. **总盘子 vs 每单位**：明确写「每单位变好」与「总盘子缩水」两个维度；
4. **裁定**：H1/H2 判定 + 是否补全 14 年 + 明确写「本实验只回答成长速度准入，不回答其他体征」。
