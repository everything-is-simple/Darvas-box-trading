## 一、要回答的问题

系统的 regime 闸门需要一个「镜子」——**判断今天这个市场处于牛/熊/猴的那个指数**。
现行镜子 `sh000001` 上证指数在 2013 年系统性误伤（B-2 闸门 −67,174，docs/31 §一），
病灶是镜子错，不是尺子错（docs/31 §3.1）。

本实验只回答一件事：**哪个（或哪一对）指数最能代表「我们要交易的那个 A 股市场」**。

不回答：① regime 判定的有效性（那是 docs/31 A 类后验）；② 因果解释；③ 未来预测；
④ 任何入场信号（docs/00 §9 违宪红线）。

## 二、基准定义（唯一的「真实市场」代理）

### 2.1 定义

```
a_t = median{ r_i,t }        r_i,t = close_i,t / close_i,t-1 − 1
```

即**当日全市场个股日涨跌幅的等权中位数**。

### 2.2 与原文口径的差异（必须登记）

| | 原文（公众号 02） | 本实验 | 影响 |
|---|---|---|---|
| 基准 | 全市场**市值**中位数股票的涨跌幅 | 全市场个股涨跌幅的**等权中位数** | 等权中位数对「个股涨跌分布的中心」更敏感，对「市值重心」不敏感；两者反操纵机制同源 |
| 为什么改 | 原文需总股本数据 | `daily_bar` 只有 OHLCV + 成交额，无股本字段 | 无法计算市值加权，**任何市值加权构造都会造成循环论证**（拿加权指数当基准去评判加权指数） |

**这不是妥协，是收紧**：原文的市值中位数在「一只权重股暴涨」时不动，在「大量小票暴跌」时也不动；
等权中位数同样对单只股票免疫（一只股票最多 1/N 的票权），但能完整反映「多数股票今天往哪走」。

### 2.3 样本过滤（逐日执行，缺一不可）

| 过滤 | 规则 | 理由 |
|---|---|---|
| 停牌 | 当日无 K 线 | 无交易即无价格信号 |
| 一字无量 | `high == low` 或 `volume == 0` | 涨跌停锁死，价格不代表可成交价 |
| 次新 | `date − list_date < 30 天` | 新股炒作期波动与市场脱节 |
| ST | 名称含 `ST` / `退` | 与原文一致 |
| 长期停牌复牌跳空 | 与上一根 K 线间隔 > 30 自然日则剔除该日收益 | 复牌跳空非当日市场行为 |
| 除权除息残差 | 个股收益 winsorize 到 ±11% | 库内 `adj_factor` 恒为 1.0（**未复权**），送转会造成伪 −20% 收益；截尾而非剔除，保留样本 |

> **诚实边界**：ST 状态取自 `security.name` 的**当前快照**，无法回溯历史 ST 身份（库中无此字段）。
> 这是已知偏倚，方向不定，量级小（当前 ST 仅 205 只），第 3 层相关性检验不受影响。

### 2.4 基准的合法性自检（HARD）

- 每日覆盖：`N_used / N_bars ≥ 95%`（全期间中位数），且 `< 90%` 的天数必须报出
- 基准序列**不含任何指数代码**，全程只用个股 K 线

## 四、四层评估（全部跑前写死）

### 第 1 层 · 贴合度排名

```
d = Σ_t | b_t − a_t |         b_t = 候选指数日收益
```
输出：全历史 d、有效天数 n、年均日误差 `d/n`、逐年误差表。
排名以 **年均日误差**为准（各候选有效天数不同，直接比 d 不公平）。

### 第 2 层 · 操纵抗性（权重不低于第 1 层）

1. **剪刀差天数**：指数涨 > +0.5% 但基准中位数 < 0（「指数红、多数票绿」）的天数占比；反向亦然。
2. **误差 top 20 归因**：列日期、`a_t`、`b_t`、上涨家数占比、**成交额加权涨幅 − 中位数涨幅**之差。
   后者 > 0 且显著即「资金抱团大票拉指数」的量化证据（无股本数据，用成交额作权重的代理）。
3. **抗性得分**：`1 − 剪刀差天数占比`，与第 1 层并列。

### 第 3 层 · 与交易池相关（终极检验）

数据：14 个 `bt_e17_<year>.db` 的 `equity_snapshot`（**3402 个交易日**，HARD 校验固定）。

被检验的是「我们的票所处的市场」，不是「全市场平均」：
1. **相关系数**：组合日收益 `r_p,t`（`total_t/total_t−1 − 1`）× 候选指数 `b_t`；
   主口径用**有持仓日**（`market_value > 0`，共 3159 日），全样本作为对照（现金日会把相关稀释向 0）。
2. **领先/滞后**：`corr(r_p,t , b_t+k)`，k ∈ [−5, +5]，报最优 k 与增益（指数是否领先组合）。
3. **regime 重叠**：A 判据（60 日低点，1.002/0.998）分别作用于
   ①基准构造的等权累积曲线（代理「我们的市场」）②候选指数，算三态 Jaccard 与一致率。
   > 代理曲线只有收盘价，故本层 A 判据统一用**收盘价滚动 60 日最低**（收盘口径），
   > 生产用的盘中 low 口径另在第 4 层使用。两种口径不可混比，报告中分列。

### 第 4 层 · 道氏组合（配对 / 投票）

用生产口径（60 日 **low**）对候选指数跑 A 判据，构造：
- **单指数**：第 1+2+3 层综合最优者
- **双指数**：大盘镜 + 中小盘镜配对，四态确认矩阵（双升 / 单升背离 / 双降 / 其余震荡）
- **三指数投票**：仅 2010+ 可含创业板指，2005-2009 降级为双票

每案必须给出 **2013 与 2017 的逐格推演**：四态各占多少天、双降桶吃了当年多少建仓日。

## 八、回答不了的事

1. **因果**：误差小 ≠ 因果驱动，本文只做贴合度排序，不做归因证明
2. **样本外**：2019 以后不进主判据（结构变了：注册制、涨跌幅 20%、北交所），只作旁注
3. **regime 判定的有效性**：镜子选对 ≠ 闸门有用，那是 docs/31 A 类后验的活
4. **权重数据的缺失**：没有股本/成分股权重，第 2 层只能用成交额代理，无法直接验证「某权重股拉了指数」
5. **未来不变性**：指数编制方案会改（国证A指 2023 起纳入北交所），历史贴合度不能保证未来贴合
