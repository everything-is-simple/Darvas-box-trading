核心结论

  • 2005–2018 共 1481 笔已平仓交易，其中可复算寿命 1481 笔、不可复算 0 笔。
  • 寿命四带每单位净利：+2,127（1–2 日） / +1,060（3–10 日） / +605（11–30 日） / +488（30 日+）。
  • 寿命四带胜率：33.3% / 24.4% / 23.8% / 21.6%。
  • H1（寿命与突破质量单调相关）不成立（递增相邻对 0/3）；H2（短寿命 box 突破质量差）不成立。

读法：寿命是「box 从下轨确认到突破的存续交易日」，不是持仓持有天数。 本实验只报相关性分布，不下因果结论（框架 §1.2）。
