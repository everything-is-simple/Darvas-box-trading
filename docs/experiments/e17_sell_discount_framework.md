## §1 要回答的一个问句 + 回答不了的六件事

### 1.1 问句

**把 `sell.discount` 从 0.97 挪到 0.95 或 0.99，端到端是变好还是变坏；如果变，变化来自「初始止损」还是「移动止损」？**

### 1.2 明确回答不了

| # | 回答不了 | 原因 |
|---|---|---|
| 1 | 0.97 是否「最优」 | 只测三点，中间可能有峰；三点之间只能判「可分辨 / 不可分辨」，不能反推最优解 |
| 2 | 与 `staledays` / 量比门槛的交互 | 本实验固定其余参数，单变量语义；交互性须另立实验 |
| 3 | 因果 | 档位改变会**内生改变资金分配**（更紧止损→更早释放仓位→不同标的被买入），端到端差异不是纯「止损价」效应 |
| 4 | 个股差异化止损 | 原书个体化止损（按个股波动）与统一折价是两回事，本实验只测统一折价 |
| 5 | 样本外有效性 | 2005–2018 是全部参数被选定的同一段历史，结论只提假设 |
| 6 | 2019+ 表现 | 数据冻结（`docs/00` §9），不碰 |

## §2 参数语义：一个参数，两个作用点（本实验的核心难点）

`docs/01` FR-403 / `docs/36` 法定事实 5.1 / `planner.go:56`：

```
sellDisc := p.st.ParamRepo.GetFloat("sell.discount", 0.97)

① 初始止损（腿 1 建仓）：stop = entry_box.top × sellDisc
② 移动止损（raiseStops）：   stop = 新箱 bottom × sellDisc，且只升不降
```

**同一个参数同时控制「建仓止损有多宽」和「跟踪止损有多宽」**，所以端到端差异必须再做分解，否则无法说清是哪一处改了行为。§5 给出分解方案。

> 纪律：本实验**不得**改 `docs/36` 的法定公式，只测参数取值。

## §5 出口分解方案（预注册，跑前定死）

每一笔已平仓交易打三个正交标签：

### 5.1 标签 A：出口来源（优先按**成交来源**判定，其次按 `plan_order.reason_json.signal`）

> **2026-11-02 08:24 口径修正（跑完首库 097/2018 后发现并立即固定，非跑后调参）**
>
> 原定义「一律按 `plan_order.reason.signal` 归类」会把**复权跳空日强制清仓**混进策略出口，原因是双层错配：
> ① 该清仓由 `internal/match/match.go` §3.8 直接调 `ledger.ApplyFill`，无计划单 → `close_reason='manual'`（首库 7 笔）；
> ② 若当日恰有在途卖单，`ApplyFill` 的订单匹配会把这笔清仓「配」给该计划单 → `close_reason='stop'` 并沿用该单 signal（首库 4 笔）。
> 结果 11 笔复权清仓被拆进 `manual`/`stop`/`initial_stop` 三类，稀释档位差异，且它们按构造偏正
> （清仓价 = 昨收×(1−滑点)，刻意避开跳空损失），会系统性抬高所有档位的胜率。
>
> **修正后的判定优先级**（唯一依据是成交的 `raw_text`，客观可复核）：
>
> | 优先级 | 条件 | 标签 |
> |---|---|---|
> | 1 | 平仓日存在 `trade_fill.side='sell' AND raw_text='sim:dividend'` | `dividend_clear` |
> | 2 | 匹配到计划单且 `reason.signal` 非空 | 该 signal 值 |
> | 3 | `close_reason='manual'` 且无计划单 | `manual`（真·计划外） |
> | 4 | 其余 | `(未知)` |
>
> `dividend_clear` **不参与档位归因**，并在报告 §2.0 单列「剔除复权清仓」的可比口径表
> （三档之间的差异只能来自受 `sell.discount` 影响的出场）。这是分类口径的**修正**，
> 不改变任何假设、档位、年集或判定门槛。

| 值 | 含义 |
|---|---|
| `initial_stop` | 持仓保护单触发（止损价，可能是初始位也可能是已上移位——见标签 B） |
| `stop` | 信号驱动卖单（箱体下轨跌破等） |
| `time_stop_noprofit` | 时间止损不获利离场（`staledays=2`） |
| `failed_breakout` | 突破失败 |
| `manual` | 计划外（`close_reason='manual'` 且无对应订单） |
| `dividend_clear` | **复权跳空日强制清仓（撮合层规则，非策略出口，不参与归因）** |

### 5.2 标签 B：止损位是否已上移（仅 `initial_stop` 笔）

用**新库自带的 `position.entry_box_id` → `box.top`** 判定：

```
若 |exit_px / (entry_box.top × disc) − 1| ≤ 0.5%   → B = 初始位未上移（真·初始止损）
否则                                              → B = 已上移（移动止损生效后触发）
```

容差 0.5% 预注册固定（覆盖 T+1 撮合的价格漂移），**跑完不许调容差**。

### 5.3 标签 C：结构指标（按档汇总，不逐笔）

- 平均/中位持仓天数（初始止损→短；移动止损→长）
- 每笔 `initial_stop` 订单的 `trigger_price` 在持仓期内被更新次数（止损上移频次）
- 单位数、笔数、未成交率（`plan_order.status != 'filled'` 的卖单占比）

### 5.4 为什么这样分解能回答 §1.1

- 若三档差异集中在 **B=初始位未上移** 的笔数/亏损上 → 差异来自「建仓止损宽度」
- 若集中在 **B=已上移** 或标签 A 的 `stop` → 差异来自「跟踪止损宽度」
- 若集中在 `time_stop_noprofit` 或笔数/未成交率 → 差异来自**仓位释放节奏**（内生性），须显式声明为「非纯止损效应」

## §6 判定规则（预注册，跑前定死）

### 6.1 主判定（阈值来自 `docs/29` §六 第 6 条与 §七第 480 行）

四档合并（四年同集）后，对每一档与基线 0.97 比：

| # | 条件 | 门槛 |
|---|---|---|
| ① | **每单位净利差** | > **600 元**（`docs/29` 沿用） |
| ② | **跨年方向一致** | ≥ **3/4 年**同向改善，且唯一反向年的幅度落在噪声内 |
| ③ | **单年复利终值差** | < 3% 视为噪声（`docs/29` §六 第 6 条） |
| ④ | **成片性** | 剔除前三赢家后净利不得翻负 |

**①+② 同时满足 = 该档「可采纳」；仅 ① 满足 = 「有信号但不稳」，不足以改默认值。**

### 6.2 负面结论的预先规定（重要：防止事后找理由）

| 情形 | 预注册结论 |
|---|---|
| 三档全部落入噪声（①不满足） | **`sell.discount` 是钝参数** → 维持 0.97，**出场端价格止损停止调参**（与 P2-6a 收官方式一致） |
| 只有某一年显著、其余打平 | 判「市况依赖」，**不采纳**，登记为后续「市况自适应」候选 |
| 紧档（0.95）改善但剔除前三翻负 | 判「靠少数大赢家」，**不采纳** |
| 宽档（0.99）改善但 MDD/水下天数显著恶化 | 判「以风险换收益」，**不采纳**（达瓦斯体系以保本为先，`docs/00` §5） |

### 6.3 必报表（缺一即视为报告不合格）

已实现净利 / 权益变动 / 胜率 / PF / MDD / 水下天数 / 出口数 / 未成交率 / 最差年 / **剔除前三赢家净利** / 每单位净利 / 平均持仓天数，且全部按 §5 的三个标签分组。

> 口径纪律：账户层用**权益变动**（含年末浮盈），讨论出场/止损/每单位净利必须用**已实现**（`docs/29` §2.5.2）。
