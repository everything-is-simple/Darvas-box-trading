LB-4 B 类 · 成长速度买入准入门槛

把「只买快成型箱体（成长速度 ≤ 阈值）」做成引擎买入准入门槛，逐档回测对比基线（off 档）。 研究问题：收紧成长速度门槛是否提升收益？最优门槛在哪？只读对应年份的回测库（baseline + 5/6/7/8/10 六档）。

一句话结论：≤6 日是最优门槛——四年合并每单位净利 1,134 元 （基线 508，改善 +626，超 600 噪声门槛），剔除前三 +163,718（基线 +34,814，成片变好）， 已实现净利 381,640（基线 224,446，总盘子反而增大），笔数仅砍 24%。H1 成立、H2 不成立。 但它是「提升器」不是「翻正药」：四个代表年里三个年份本身在亏，≤6 只是少亏。

五、裁定

H1（收紧门槛提升收益）成立：≤6 日档四年合并每单位 +626 元（超 600 噪声门槛）、 剔除前三 +163,718 仍大幅为正、改善年数 3/4（唯一负值在噪声内）——三条同时满足。

H2（无价值）不成立。

最优门槛 = ≤6 日。它不是「总账最高」的孤峰（≤5 在 2012 更高、≤6 在 2015/2017 更高）， 而是唯一在四个年份里都不掉链子的档位。

结论边界：① 单年不结论、跨年才下结论；② 本实验只回答「成长速度准入」，不回答其他体征； ③ 成长速度低端（<4 日）结构性无样本（上/下轨各需 3 日确认刚性钳制）；④ 样本外（2019+）未参与； ⑤ 不推断因果——成长速度快可能与「强势股快速成型」内生相关。 单因子轮换：只动 box.max_growth_days，其余十维固定。
