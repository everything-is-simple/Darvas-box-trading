## §10 诚实标注

- 不是因果：分桶不改变交易路径，regime 与波动率、箱体质量高度共线。
- 不是样本外：2005–2018 是参数选定所用的同一段历史。
- 不是盲测：校准锚点在看既有报告后登记，但 H1–H6 判据与裁定矩阵在看到本轮结果前定稿。
- 口径偏差已登记：2005 基准峰回撤退化（框架 §10 差异 #8），改用距 52 周高点回撤；两种口径并存，前者保留作审计对照。
- 账户回撤 `>10%` 档结构性无样本，不得据此判断回撤闸门。
- 幸存者偏差：退市股不在样本内；2008 已并入，不再具样本外属性。
