## §1 实验目的与边界声明

### 1.1 本轮要回答的三个问句

1. 在**已通过 5% 闸门**的箱体中，哪一档高度（`/top` 口径）同时满足三个条件：每单位净利符号稳定、实际胜率高于保本胜率、跨年符号一致？
2. 这一档的正收益是**广泛优势**还是**少数大赢家撑起**？（判据：剔除前三赢家后是否仍为正）
3. 同一批交易换个分母（`/bottom`）重算，结论会不会翻转？翻了多少笔、多少钱？

### 1.2 本轮明确回答不了的四件事

| # | 回答不了 | 原因 |
|---|---|---|
| 1 | **5% 阈值是否过严/过松** | 样本全部来自「已过闸门」的交易。0–5% 带在两种口径下都是 0 笔，没有任何窄箱对照组。窄箱从未被测过。要回答必须走 **B 类**：参数化 `box.min_width` 重跑 14 年（≈14h），不属本轮。 |
| 2 | **因果** | 分带不改变信号、成交、仓位路径；带间差异含市场环境混杂（牛市高箱多、熊市窄箱多）。这是后验切分，不是随机对照。 |
| 3 | **样本外有效性** | 2005–2018 是全部参数被选定所用的同一段历史（`docs/29` §八.6）。结论只用于提假设，不得直接改参数上线。 |
| 4 | **与其他维度的交互** | 单因子轮换纪律（`docs/29` §2.3）：本文只动「box 高度」一个因子，高度与其他九维的交互不在本轮范围。 |

### 1.3 结论句式模板（强制措辞）

跑完写结论时，必须按以下句式组织，不得省略括号内的限定项：

> 在 2005–2018 已过 5% 闸门的 1328 笔平仓交易中，`/top` 口径 **X–Y%** 档的每单位净利为 __、剔除前三赢家后为 __、14 年中有 __ 年为正（记账规则见 §7.2）；该档**具备 / 不具备**初步 edge。
> 5% 阈值本身是否合理，**本实验不回答**。

禁止出现的写法：`窄箱表现更好`、`5% 阈值过严`、`证明箱体越高越差`、`可以据此调参`。

## §2 实验假设（可证伪形式）

| 编号 | 假设 | 判据 | 证伪条件 |
|---|---|---|---|
| **H1** | 高箱有害：`/top ≥ 25%` 的每单位净利为负，且跨年符号一致为负 | 合并带每单位 < 0；`pos_ratio ≤ 0.30` 且 `M ≥ 8` | 出现 n≥30 且每单位为正，或正号年数占一半以上 |
| **H2** | 中箱优于窄箱：`/top 10–25%` 的每单位净利高于 `5–10%` | 两带每单位之差 > 0 且不含前三赢家时仍成立 | `5–10%` 每单位更高，或差值在剔除前三后反转 |
| **H3** | 「<5% 更优」**不可检验** | —— | **不适用**。本条只做登记，不得写成「已证伪」，也不得写成「窄箱无 edge」 |
| **H4** | 分母敏感：高箱端的符号/幅度对分母选择敏感 | `40%+` 带在两口径下的 n 与每单位差异显著 | 两口径在同一经济区间给出同向、同量级结论 |

**H3 是本实验诚实性的核心。** `docs/29:106` 原判据（「若 0–5% 窄箱中位为正则阈值假设被证伪」）在数学上永远无法触发——该带恒为 0 笔，中位数不存在。本文把它降级为「登记为不可检验」，并在 §10 登记改写理由。

## §3 数据准备过程

### 3.1 只读纪律

- 一律用 `sqlite3.connect("file:<db>?mode=ro", uri=True)`。
- 不写回测库、不碰源库 `full_hist_10pct.db` 与生产库 `darvas.db`（`docs/06` §6.2 库隔离）。
- 不重跑任何回测、不改任何参数、不重建任何索引。

### 3.2 取数口径

单库单条 SQL：

```
SELECT p.opened_date, p.closed_date, p.status, p.realized_pnl, o.reason_json
FROM position_leg l
JOIN position p ON p.id = l.position_id
LEFT JOIN plan_order o ON o.id = l.plan_order_id
WHERE l.leg_no = 1
```

提取字段：

| 字段 | 来源 | 用途 |
|---|---|---|
| `year` | 库文件名 `bt_e17_<year>.db` | 逐年分组 |
| `opened_date` / `closed_date` | `position` | 持有期、时序核对 |
| `status` | `position` | 只统计 `closed` |
| `realized_pnl` | `position` | 净利 |
| `box_bottom` / `box_top` | `reason_json` | **高度计算的两个原料** |
| `units` | `reason_json` | 每单位净利的分母 |
| `sizing_basis` | `reason_json` | 记录用（**不用于分带**，见 §3.4） |

### 3.3 样本漏斗

| 步 | 说明 | 剩余 |
|---|---|---|
| 1 | 14 个回测库（2005–2018） | 14 库 |
| 2 | `leg_no = 1` 首次建仓 | 1405 笔 |
| 3 | `status = 'closed'` 且 `realized_pnl` 非空 | 1328 笔 |
| 4 | `box_top` / `box_bottom` 缺失 | 0 笔被剔除 |
| 5 | `box_top <= box_bottom` 脏数据 | 0 笔被剔除 |
| 6 | **有效样本** | **1328 笔** |

第 3 步排除的 77 笔为未平仓头寸：未实现盈亏与已实现盈亏不可比，故剔除（这是唯一的剔除动作）。

### 3.4 清洗规则

**只做结构清洗，不做数值清洗。**

- **不剔除极端盈亏**：极端值靠「利润集中度」与「剔除前三赢家」两列暴露，而不是删掉。
- **不做时间切片**：不按牛熊分段取舍（regime 归因属 P0-3，本轮不做）。
- **不按 `sizing_basis` 过滤**：高度与距新高档位是两个独立维度，混用会重复归因（`docs/29` §2.3 OFAT）。
- **不改权重**：每笔交易等权计入，不按 units 加权聚合胜率。

### 3.5 已知数据偏差（结论必须携带）

- **幸存者偏差**：只用当前仍存在的股票，退市股不在样本内。
- **前复权失真**：低价股箱体绝对价差小，可能放大 `/bottom` 口径的尾部。
- **2008 已并入**：2008 原为样本外验证年，现与其余年份合并统计，不再具备样本外属性。
- **无基线对照不构成缺口**：本实验只统计 E17 自身分带，不需要 p05 基线；故 2005–2013 缺 `bt_p05_<year>.db` 不影响本实验（与「距新高」报告不同，那边需要基线差额）。

## §4 口径定义（双口径）

### 4.1 主口径 `/top`（与闸门同尺）

```
H_top = (box_top − box_bottom) / box_top × 100
```

出处：`internal/box/engine.go:127` —— `if cur.top > cur.bottom && (cur.top-cur.bottom)/cur.top >= s.params.MinBoxWidth`，`box.min_width` 默认 `0.05`（migration 0015）。

**这是准入闸门唯一使用的尺子。** 只有用这把尺子分带，结论才能翻译成「要不要调 `box.min_width`」的语言。

### 4.2 对照口径 `/bottom`（历史观测轨）

```
H_bottom = (box_top − box_bottom) / box_bottom × 100
```

出处：`docs/29:102`、`scripts/e17_annual_tier_report.py:186`（`_pct(box_bottom, box_top)`）、历史 E8 报告 `var/bt/box_height_analysis.py:50`。

保留它的唯一理由是**审计轨**：与文档原口径、历史 E8 结论对齐。

### 4.3 换算关系

设 `/top = t`、`/bottom = b`（均为百分数），则

```
b = t / (1 − t/100) × 100        t = b / (1 + b/100) × 100
```

| `/top` | 5% | 10% | 15% | 20% | 25% | 30% | 35% | 40% |
|---|---|---|---|---|---|---|---|---|
| `/bottom` | 5.26% | 11.11% | 17.65% | 25.00% | 33.33% | 42.86% | 53.85% | 66.67% |

两条必须写进报告的推论：

1. `/top 5%` 闸门 ⟺ `/bottom 5.26%`。所以 `/bottom` 的 0–5% 同样是空带——**两个口径都有空带，只是空带宽度不同**。
2. 高箱端差得远：`/bottom 40%+` 实际覆盖 `/top 28.6%+`，而 `/top 40%+` 才是真正的高箱尾部。这是 H4「分母敏感」的算术根源。

### 4.4 主辅裁定

| 项 | 裁定 |
|---|---|
| 主表 | `/top` |
| 对照表 | `/bottom` |

理由三条：

1. 与闸门同尺，结论可直接对话调参；
2. `/bottom` 的分母是箱底，箱底越低数值越膨胀，同一经济事实在高低价股之间不可比；
3. `/bottom` 保留是为了与文档原口径和历史 E8 对齐，属审计轨，不用于下结论。

### 4.5 统计口径（每带必须齐备）

| 口径 | 公式 | 备注 |
|---|---|---|
| 胜率 | `wins / closed` | 已平仓头寸中盈利占比 |
| 每单位净利 | `Σpnl / Σunits` | `units` 取自 `reason_json.units`，实测集合 ⊆ {0.5, 1, 2, 3} |
| 保本胜率 | `1 / (1 + 平均盈利/|平均亏损|)` | 即 `|avgLoss| / (avgWin + |avgLoss|)` |
| 利润集中度 | 前三赢家合计 / 毛盈利 | 无毛盈利时记 `—` |
| 附加 A | 利润因子 PF = 毛盈利 / |毛亏损| | |
| 附加 B | **缺口** = 实际胜率 − 保本胜率（pp） | `docs/29` §六.2 判定用 |
| 附加 C | **剔除前三赢家净利** = 净利 − 前三赢家合计 | 识破「假 edge」的关键列（`docs/01` §10.2 明文要求剩余分布单独报告） |
| 附加 D | 剔除前三赢家每单位净利 | 同上 |

## §5 分带设计（三级加密）

### 5.1 核心原则：逐级加密，规则预设

**先 5% 等距全切；若某区间仍不够细致，降 2%；再不够，降 1%。**

- 每一层的切分都是**等距**，不是「找拐点」。
- 降级触发条件**事先写死**（§5.3），不是看着结果挑。
- 任何带**不得因结果好坏合并或拆分**。若事后确需新增切法，必须登记到 §10 差异表，并在报告附录公开完整「探索日志」。

### 5.2 L1 第一层：5% 等距（主表，全区间）

`/top` 主表分带（区间左闭右开）：

```
[0,5) [5,10) [10,15) [15,20) [20,25) [25,30) [30,35) [35,40) [40, +∞)
```

`/bottom` 对照表分带：

```
[0,5) [5,10) [10,15) [15,20) [20,25) [25,30) [30,35) [35,40) [40,45) [45, +∞)
```

尾部处理规则（预设）：**当某 5% 带的样本数不足 30 时，允许把相邻尾部各带合并为「X%+」一行**，并在行内注明合并了哪几段。合并只允许发生在尾部，不允许在中间开口。

### 5.3 L2/L3 降级触发规则（事先写死）

**L2（降 2%）触发条件**：L1 中某带同时满足

- `n ≥ 30`，且
- 出现以下任一信号：**符号反转**（与前一带每单位净利一正一负）、或 **利润集中度 > 50%**、或 **剔除前三赢家后净利符号翻转**。

命中区间降 2% 等距加密；未命中区间**保持 5% 不动**（不得为了「看起来对称」而全表加密）。

**L3（降 1%）触发条件**：L2 中某 2% 段同时满足 `n ≥ 30` 且仍有上述信号。默认不启用；若启用，须在报告附录写明触发原因与段号。

### 5.4 0–5% 空带的呈现规则

**保留空行，不省略。** 渲染要求：

- 笔数写 `0`，其余数值列写 `—`；
- 状态列写「**结构性无样本（闸门所致）**」；
- 整行灰底 + 斜体。

表下固定注记：

> `0–5%（/top）` 与 `0–5%（/bottom）` 均为 0 笔，因为 `(top−bottom)/top ≥ 5%` 是准入条件，样本天然不含窄箱。这不是数据缺失，也不构成「窄箱差」的证据——**窄箱从未被测过**。

保留空行的三条理由：① 省略会让人以为忘了切；② 空行本身是「闸门裁掉了整段」的可视化证据；③ 它是 H3「不可检验」在表上的实体化。

### 5.5 小样本带的处理规则

- `n < 30` 的带**单列成行**，笔数旁加 `⚠ 样本不足` 角标，结论列一律写「样本不足，仅供参考」。
- **不把小样本并进大带以凑显著性**。若确需一个可下结论的合并行（如 H1 的裁定行），该合并行必须另起一行、显式标注合并了哪几段。
- 附录细表（更细切分）一律标注「探索性，多带多重比较，不得据此提新阈值」。

## §7 判定标准

### 7.1 三条硬门槛（缺一不得下结论）

1. **样本量**：`n ≥ 30`；不足则标「样本不足，仅供参考」。
2. **有样本年数**：`M ≥ 8`；不足则标「出现年数不足，不作跨年裁定」。
3. **完整性**：四项固定口径 + PF + 缺口 + 剔除前三，缺一项即不得下结论。

### 7.2 跨年一致性记账规则

- `M` = 该带 `n > 0` 的年数。
- `P` = 该带年度净利 > 0 的年数。
- **过滤后符号统计**：只把「该年该带 `n ≥ 3`」的年计入 `P'` / `M'`，避免「1 笔撞对」被算成一个正号年。
- 记分卡必须**同时印出**原始 `P/M` 与过滤后 `P'/M'`，**判定用过滤后那一组**。
- `longest_run` = 最长连续同号年数（对应 `docs/29` §六.3「连续 ≥2 年同符号」）。
- `pos_years_pnl_share` = 正号年净利合计 / 该带净利合计（识别「靠两年暴赚、其余年亏」）。

### 7.3 裁定矩阵

| 条件 | 裁定标签 |
|---|---|
| `n < 30` | **样本不足** |
| `n ≥ 30` 且 `M < 8` | **出现年数不足** |
| `n ≥ 30`、`M ≥ 8`、`pos_ratio' ≥ 0.70`、缺口 ≥ +2pp、剔除前三仍为正 | **edge** |
| 同上但剔除前三为负 | **假 edge（少数交易撑起）** |
| `pos_ratio'` 在 0.30–0.70 | **不稳定（不得下 edge 结论）** |
| `pos_ratio' ≤ 0.30`、缺口 ≤ −2pp | **负 edge** |
| 0–5% 带 | **不可检验（结构性无样本）** |

补充：缺口（实际胜率 − 保本胜率）在 +2pp ~ −2pp 之间的一律记「无 edge」。

### 7.4 五个校准锚点（生成器必须断言）

> **诚实声明**：这 5 个锚点是在基线统计已跑过一次之后登记的**防漂移快照**，因此本文在这一点上**不是盲测**（见 §9 已窥视数据）。但它们只锁「方向与量级」，不锁完整结论，也不参与裁定。

1. 已平仓样本数 = 1328
2. `Σrealized_pnl ≈ +842,799.7`（**不是 842,801**——那是 `e17_metrics.csv` 按年取整的和，差 1.3）
3. 两口径下 `0–5%` 带均 = 0 笔
4. `/top 10–15%` 带剔除前三赢家后净利 > 0
5. `/top 5–10%` 带剔除前三赢家后净利 < 0

锚点 4、5 是本实验最反直觉的两条，必须每次跑都断言，防止分带逻辑漂移。

## §10 与 docs/29 原设计的差异登记

| # | docs/29 原文 | 本文做法 | 理由 |
|---|---|---|---|
| 1 | 口径 `(box_top−box_bottom)/box_bottom`（单一） | **双口径**，`/top` 主 + `/bottom` 对照 | 代码闸门 `engine.go:127` 用 `/top`；单用 `/bottom` 会让观测口径与准入口径不同尺，无法对话调参 |
| 2 | 梯度 5 带（0-5/5-10/10-20/20-40/40+） | **5% 等距首层 + 2%/1% 逐级加密** | 5 带把 `20–40` 整段合并，会把峰与谷平均掉；5% 等距是规则预设，不是拟合 |
| 3 | 判据「若 0–5% 窄箱中位为正则阈值假设被证伪」 | **删除，改为 H3「不可检验」登记 + H1/H2 两条可触发判据** | 0–5% 带恒为 0 笔，原判据**永远无法触发**，属死判据 |
| 4 | 产出 `var/bt/e17_box_height_distribution.html` | `docs/experiments/e17_box_height_report.{html,md}` + `_data.json` | 与「实验报告唯一沉淀处 = docs/experiments/」的目录约定一致 |
| 5 | 未要求「剔除前三赢家」列 | **强制新增** | `docs/01` §10.2 明文要求剩余分布单独报告；本实验中该列直接决定了「真 edge / 假 edge」的区分 |
| 6 | 未说明 A 类的证伪能力边界 | **§1.2 显式声明四条回答不了的事** | 防止把「已过闸门的统计」误读成「阈值已被检验」 |

**执行中的两处方法论修正**（记录以备复核）：

1. **裁定顺序调整**：初版按「跨年稳定性」优先判定，导致 5–10%（跨年 5/14）与 15–20%（7/14）被判为「不稳定」，掩盖了它们「剔除前三即翻负」的实质。改为**先查剔除前三是否翻负 → 再查跨年稳定性**，两个带才被正确标为「假 edge（前三撑起）」。
