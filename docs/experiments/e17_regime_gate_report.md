## 三、机制层（钱从哪里省出来的）

1. **闸门动作 = 同一只票、同一止损价、只改仓位**：青岛双星（2008）基线 3 单位 −4,956 → half 0.5 单位 −831；安通控股 2 单位 −3,810 → 0.5 单位 −908。stop 则是这些单根本不生成。
2. **减亏端远大于让利端**：half 2010 让利实例 sh600701（+988 → +489，少赚 499），但同年减亏累计 +45,680。
3. **E17 阶梯与闸门的分工**：深熊年大量候选本就是 t4（0.5 单位），half 无再降空间（2008 仅 24/68 可降）——闸门的边际保护集中在 t1–t3 高位票；而 stop 对所有买单一视同仁地拦截，故深熊优势放大。
4. **路径效应**：stop 拦截改变后续持仓结构（2007 拦 34 笔 vs half 仅 8 笔 below 订单）——两种闸门连"触发次数"都不可直接比，只能比最终账。

## 五、诚实边界（结论携带项）

1. **只有 4/14 年**。代表年按「闸门活跃度」选择（牛/深熊/震荡/阴跌），**改善额 +159,815 存在选择偏倚**——8 个未测年（2005/2006/2009/2012–2017）多为中性市况，闸门触发率低，预期改善小但**代价未测**（尤其 stop 在中性年的拦截成本）。**这是必须跑全 14 年的第一理由。→ 已于 2026-10-27 补齐，见 §七。**
2. **年内起跑口径**：四年各自从 1,000,000 起跑，合计数不是连续复利路径。全 14 年连续跑才能给出真实资金曲线。
3. **2019+ 样本外未测**：2005–2018 是参数选定所用历史（docs/29 §八.6）；MA60 闸门参数（60/收盘对比）虽为 P0-3 后验发现，"采用与否"的判定仍需样本外确认。
4. **2007 未实现代价**：stop 在牛市年少了 24,351 浮盈——若未来连续牛市，闸门的机会成本会累积；全 14 年将量化这一点。
5. **单一指数单一参数**：MA60 用 sh000001 收盘，未测 MA20/其他指数/参数敏感性（P0-3 已示三口径方向一致但覆盖不重叠）。
6. **数据边界**：四年均为 A 类已验证的回测路径（off 等价 HARD 通过）；fees/滑点/黑名单与基线完全一致。

### 7.4 全 14 年新增的三个认知

1. **改善的构成不对称**：改善年 7 个合计 +219,856，受损年 6 个合计 −87,720。受损集中在两类——**脱钩年**（2013 −67,174 / 2017 −4,677：指数与中小盘方向相反）与**洗耳光年**（2018 −11,422：单边阴跌中的反弹让闸门反复开合，高位买、低位止损）；
2. **2018 是 MA60 的机制性失败样本**：345 笔拦截（14 年最多）却多亏 −11,422——崩盘段它确实挡住了，但每次反弹站回 MA60 它就开门放行，买入后市场续跌再止损。这正是斯波朗迪说的「挨耳光」（whipsawed），也是均线作为趋势判据的固有缺陷的最纯样本；
3. **2010 勘误**：此前误报 stop 2010 已实现 +3,012（把年末权益差当成已实现净利），权威数字 **−14,884**；half（−7,665）在 2010 已实现口径反超 stop——「震荡市保留参与度」有其价值，这直接支持 docs/31 草案的分级设计（震荡组合档 → half）。

### 7.5 对 docs/31 双指数草案的增量证据

- 脱钩两连击（2013/2017）+ 不对称性（指数弱/小盘强 伤害是反向的 14 倍）→ 双指数确认的「背离豁免」机制必要性成立；
- 2018 洗耳光 → 单纯换镜子解决不了均线固有的振荡缺陷 → 分级动作（确认→停手、模糊→half）比二值开关更必要；
- 2012 白干年 → 无 edge 年闸门无法识别，接受为该类工具的固有成本。
