## §1 实验目的与边界声明

### 1.1 本轮要回答的问句

**唯一命题**：把量比准入门槛 `box.volmult` 从 2.0 降到 1.0，让「突破当日不放量（量比 <2×）」的单子进场，
它们的后续收益是否**显著差于**基线区（2–5×）？

- 若 0–1× / 1–2× 带显著更差 → 2× 闸门是对的，维持。
- 若打平或更好 → 2× 在砍掉「缩量突破照涨」的利润，值得降门槛。

### 1.2 本轮明确回答不了的

| # | 回答不了 | 原因 |
|---|---|---|
| 1 | **幅度低端（0–3%）** | 需同时动 `buy.premium`，与量比混淆，本次冻结 1.03（另案） |
| 2 | **量比高端（>5×）** | A 类已证无梯度，本次仅作对照，不立「量比上限」假设 |
| 3 | **样本外有效性** | 代表年仍是参数被选定的同一段历史；结论只用于提假设 |
| 4 | **因果** | 低量比样本与次新股高度混杂（前 50 日均量小、突破日易显「缩量」） |

### 1.3 口径对齐（报告首页必写，防把结论往谚语上套）

1. 用户引谚语「**缩量涨，一直涨**」。原谚语指**上升趋势中回调/盘整缩量**（量的是过程、看抛压是否枯竭）；
   本实验的量比定义是**突破当日成交量 / 前 50 日均量**（量的是突破那一根 K 线）。两者不是同一概念。
2. 本实验验证的命题 = **「突破当天不放量，后续表现是否显著更差」**。
3. **措辞纪律**：结论**禁用「缩量涨」「缩量涨一直涨」字样**，只写「低量比突破 vs 高量比突破」的实证。

## §2 口径定义（唯一事实源，禁止临场改）

### 2.1 量比复算公式（与 A 类、与引擎完全一致）

| 指标 | 公式 | 说明 |
|---|---|---|
| **量比** `volratio` | `daily_bar.volume(plan_date) / avg(volume, plan_date 之前 50 个交易日)` | **不含 plan_date 当日**，与 `avgVolumeBefore(bars,i,50)`（`engine.go:227`）同语义；近上市端用 `min(50, i)` 短窗 |

### 2.2 分母口径

- **信号分母**：`plan_order(side='buy', status='filled')` 计数（逐库；≡ 该库 `position` 行数）。
- **盈亏分母**：`position.realized_pnl IS NOT NULL` 的已平仓。每带同时报 `n_signal` 与 `n_closed`。
- **禁止**用 `status != 'cancelled'` 当分母（会多算 expired）。

### 2.3 四项固定口径 + 附加（每带必报）

| 指标 | 定义 |
|---|---|
| 胜率 | `realized_pnl > 0` 占 `n_closed` |
| 每单位净利 | `Σrealized_pnl / Σunits`；**已实现口径**（勿混入年末浮盈，docs/29 §2.5.2） |
| 保本胜率 | `avg_loss / (avg_win + avg_loss)` |
| 缺口 | `胜率 − 保本胜率` |
| 利润集中度 | `top3 / gross_win` |
| PF | `gross_win / gross_loss` |
| 剔除前三赢家净利 | `Σrealized_pnl − top3`（识破假 edge 的关键列） |
| 持中位（交易日） | `opened_date → closed_date` 之间的 `daily_bar` 根数 |
| **次新占比** | `首次上市日 → plan_date` 交易日 < 60 的占比（§6 混淆控制，必拆） |

### 2.4 建仓成本口径（P2-5 血泪坑）

成本取 `Σ(position_leg.qty × position_leg.price)`，**不可用** `position.avg_cost × qty` 当分母
（`position.qty` 平仓后清零）。

## §3 分带设计（预设，禁止按结果合并/拆分/挪界）

| 观测带 | 量比范围 | 来源档位 |
|---|---|---|
| 0–1× | [0, 1) | volmult=1.0 |
| 1–2× | [1, 2) | volmult=1.0 / 1.5 |
| 2–5×（基线区） | [2, 5) | volmult=2.0(基线) / 2.5 |
| 5×+ | [5, ∞) | volmult=3.0（观测尾部，仅对照） |

- 带界固定（0/1/2/5），**禁止按结果挪带界或并带**；`n<30` 标「样本不足」，不合并不解释。
- **观测带 ≠ 门槛档**：同带可跨多档归并（如 1–2× 来自 volmult=1.0 与 1.5 两档的并集）。
- **结构约束**：0–1×、1–2× 两带在**基线库（volmult=2.0）里结构性无样本**——这正是本实验存在的意义；
  它们只出现在 volmult=1.0/1.5 的库里。

## §4 实验设计（单变量 OFAT）

### 4.1 变量与档位

| 变量 | 当前值 | 扫描档 | 其余参数 |
|---|---|---|---|
| `box.volmult` | 2.0 | **1.0 / 1.5 / 2.0(基线)** | 全冻结（§4.2） |

### 4.2 参数集（100% 复刻新基线，只改 box.volmult）

以 `var/bt/base/bt_baseA_<year>.db` 的 param 为黄金参照（38 键）。执行器显式 `--set` 以下键，
其余键由源库迁移种子 + 代码硬编码默认值兜底（两者值一致，已核对 `match.max_entry_gap=1.05` 等）：

pos.newhigh.units.t1=3, pos.newhigh.units.t2=2, pos.newhigh.units.t3=1, pos.newhigh.units.t4=0.5,

- 2012（震荡）/ 2015（牛）/ 2017（牛末）/ 2018（熊）。
- 先跑代表年。若 0–1×/1–2× 与基线区差异超噪声门槛（§5）且有稳定符号，再决定补全 14 年。

### 4.4 回放纪律

- 串行，失败即停；每档每年代建独立 scratch 库，不覆盖。
- 回放只用 scratch 库，勿污染实时库心跳；中间库用完归档，勿留 I 盘。

## §5 预注册假设与裁定规则

| # | 假设 | 成立条件 |
|---|---|---|
| **H** | 降门槛有价值（低量比突破不比基线差） | 0–1× 或 1–2× 带每单位净利**不显著差于** 2–5× 基线区（差 < 600 元/单位），或反而更好；且剔除前三后符号不变 |
| **H4** | **2× 闸门是对的**（默认结论） | 0–1×/1–2× 带**显著差于**基线区（差 > 600 元/单位），且剔除前三后仍为负贡献 → 维持 `box.volmult=2.0` |

- **噪声门槛**：每单位净利差 > **600 元**（= 3% × 单位值 20,000）。
- **三条同时满足才算有结论**：① 幅度超噪声；② 剔除前三仍成立；③ 跨年方向一致（带-年 n≥10 才算）。
- 不挑单点最优；总账最优的带必须再降一级粒度复核是否成片（P0-1 教训）。

## §6 混淆控制（次新拆分是硬要求）

1. **次新效应**：低量比样本里次新股占比会显著升高（前 50 日均量本身小、突破日易显「缩量」）。
   每带单独报「次新（上市 <60 交易日）占比」与「剔次新后每单位净利/胜率」，
   **否则会把次新效应误当缩量效应**。
2. **年份**：每带报正贡献年份数；2015（牛）与 2018（熊）单独列。
3. **仓位/资金约束**：不同档建仓数不同，一律比**每单位净利**，不比总净利。
4. **量比 × 强度**：若复算后 |ρ| > 0.3 须补二维交叉表（A 类实测 ρ=0.066，预期不用）。

## §7 HARD 校验（全过才算完成）

| # | 校验 | 判据 |
|---|---|---|
| ① | **零差异复现** | volmult=2.0 档重跑后，与历史基线库 `base/bt_baseA_<year>.db` 逐年已实现/权益变动**零差异**——证明只改了这一个参数、其余规则 100% 一致 |
| ② | **门槛语义下界** | volmult=1.0 档 filled 单量比应出现 <2× 的值；volmult=2.0 档量比全 ≥2.0（口径一错立刻现形） |
| ③ | **样本并集闭合** | 各观测带笔数之和 = 该档 filled 总数 |
| ④ | **异常归因** | 若某带指标异常，回查规则来源，写进报告，不当规律 |
| ⑤ | **次新拆分自洽** | 剔次新后笔数 + 次新笔数 = 带内笔数 |

## §9 与 `docs/29` 原设计的偏离登记

| # | 原设计（docs/29 §七 B 类） | 本轮实际 | 原因 |
|---|---|---|---|
| 1 | 幅度 + 量比两维都扫 | **只扫量比** | 用户 2026-10-30 拍板幅度 ≥3% 认可不动；幅度低端另案 |
| 2 | 量比 5 带（0-1/1-2/2-5/5-8/>8） | **4 带（0-1/1-2/2-5/5+）** | A 类已证 >5× 无梯度，5-8/>8 合并为 5×+ 仅作对照 |
| 3 | 无次新拆分要求 | **新增次新拆分（硬要求）** | 低量比样本与次新高度混杂，不拆会误判 |
