# 48 · 攻防转换：从「能不能买」到「该投多重」

> 立项：2026-11-03 · 用户原话：「darwas-box 的攻防转换缺少一种自动识别牛熊，也就无法调节牛市加满、熊市撤退。怎么办？」
> 前置证据：`docs/experiments/e17_regime_scale_a_report.md`（A 类零成本后验，同日完成）
> 状态：**设计定稿，B 类待跑**。本文是跑前宪法，§五判据不得事后改。

---

## 一、先纠一个错：不是缺识别器，是缺传导

系统**已经有**三个状态输入，且都在用：

| 输入 | 实现 | 用途 |
|---|---|---|
| 上证 vs MA60 | `gate.ma60.mode = stop/half/off`、`gate.ma60.index` | 只在**入场端**拦截，已投产 stop |
| 上证距 252 日高点 | `pos.newhigh.*`（个股级阶梯 t1=3/t2=2/t3=1/t4=0.5） | 决定**单票**买几单位 |
| A 判据升势 | `regime.a.*` | `newhigh_ladder=on` 时**失效**（走不到该分支） |

所以"没有自动识别牛熊"这个诊断不准确。真实病根是 **状态识别出来了，但没有一条线把它接到总仓位**：

- 升势日平均仓位 **18.9%**、震荡 **15.1%**、降势 **6.7%** —— 状态换了，仓位只动 3.8pp（`e17_position_profile_report`）
- 升势日只占 293/3402 = **8.6%**，其余 91% 被归为"震荡"
- 14 年平均仓位 **14.9%**、历史最高 **51.1%**，平均持仓 5.36 只

**打不满是算术问题，不是开关问题**：1 单位 = 2% 权益；升势平均 5.36 只 × 阶梯均值 ≈ 1.3 单位 ≈ **13% 暴露**；
即使每只都给满 3 单位，5.36 × 3 × 2% = **32%** —— 理论天花板就 32%。

> 结论：**要"牛市加满"，必须动「单位大小」或「只数上限」，加一个 if-else 状态开关是没用的。**

## 二、攻与守，证据强度完全不对等

| 方向 | 证据 | 裁定 |
|---|---|---|
| **守**（熊市撤退） | MA60 stop 全 14 年：Σ已实现 +842,801 → **+974,937**（+132,136）、亏损年减亏 66.2%、剔最佳年后仍 +63,486，三判据全过；已投产 `gate.ma60.mode=stop` | **成立，已落地** |
| **攻**（牛市加满） | A 类后验：按指数距高，每单位净利"看起来"单调（1,396 → −53），但 **≥−2% 带只有 4/8 年为正**；2017 样本最多（128 笔）反而 −271 | **单笔层面无稳定 edge，不可直接加满** |

而且 A 类里有个反直觉结果：**「只防不攻」的线性模拟只有 +0.3%** —— 说明现有 stop 已经吃掉了防守的钱，**再叠防守是冗余**。

**真正没被利用的是攻**。而攻的抓手，A 类指向了一个新变量：**市场宽度**。

## 三、为什么是「市场宽度」而不是别的指标

现有两个指数指标各自有明确失败样本（`e17_regime_gate_report` §7.4）：

| 指标 | 失败年 | 失效方式 |
|---|---|---|
| MA60 | 2018（−11,422） | **洗耳光**：反弹站回均线就开门，买完续跌 |
| MA60 | 2013（−67,174）/ 2017（−4,677） | **脱钩**：指数与中小盘方向相反 |
| 指数距高 | 2017 | 指数在近高点，但小盘在坏 → 128 笔每单位 −271 |
| 指数距高 | 2014 | 反向：远高点 +1,696、近高点 −4 |

这三类失败**都是同一个盲点**：指数只反映大市值，看不见"内部有多少票在涨"。

**市场宽度**（当日收盘在 MA50 上方的股票占比，全市场 2271~5549 只）直接测内部：

| 宽度 | n | 每单位净利 | 剔前三 | 胜率 |
|---|---:|---:|---:|---:|
| ≥ 70% | **919** | **983** | **+648** | 26.7% |
| 50~70% | 401 | 463 | −87 | 19.7% |
| 30~50% | 153 | 11 | −572 | 15.0% |
| < 30% | 8 | −1,321 | −1,289 | 0.0% |

样本量是距高带的两倍多，且**剔前三仍为正**——这是全项目迄今最干净的单一梯度。
序列已按史实校验（2008 年中位 10%、2015-06-12 = 92.7%、2018-10-19 = 6.4%）。

宽度的作用不是"预测牛熊"，而是**测内部健康度**：2013/2017 那种"指数涨、多数票跌"的假牛，
宽度会先掉下去。这正是现有指标的结构性盲点。

## 四、设计：三层结构（状态 → 目标暴露 → 传导）

### L1 状态机（把"能不能买"升级成"该多重"）

每日收盘后判定，输入两个（都只用 T 日及之前数据）：

```
宽度 b50 = 当日收盘 > MA50 的股票数 / 当日有行情股票数
距高 dd52 = 上证收盘 / 252 日最高 − 1

进攻 ATTACK : b50 ≥ 0.70  且  dd52 ≥ −5%
撤退 DEFEND : b50 < 0.50  或  dd52 < −20%
中性 NEUTRAL: 其余
```

**滞回（必须做，治 2018 洗耳光）**：状态升级须连续 `confirm_days` 日满足；降级立即生效（下跌快、上涨慢）。

### L2 目标暴露（不是硬控，是乘数量级）

| 态 | 目标暴露 | 依据 |
|---|---|---|
| 进攻 | 50~65% | 5.36 只 × 3 单位 × 2% × 2.0 ≈ 64% |
| 中性 | 20~30% | 现状 15% 略抬高 |
| 撤退 | 5~10% | 现状降势 6.7% |

### L3 传导（只动入场端，不动出场）

**硬纪律：只改「买多少」，不改「何时卖」。** P2-6a 已证出场端调参是噪声/实亏，不碰。

| 机制 | 说明 |
|---|---|
| `pos.regime_scale.mode` | `off`（默认，保基线等价）/ `on` |
| `pos.regime.attack_mult` | 进攻态单位乘数，建议 **2.0** |
| `pos.regime.defend_mult` | 撤退态单位乘数，建议 **0.5** |
| `pos.regime.breadth_min` | 进攻所需宽度下限，建议 **0.70** |
| `pos.regime.breadth_exit` | 撤退宽度上限，建议 **0.50** |
| `pos.regime.dd_max` | 进攻所需回撤下限，建议 **−0.05** |
| `pos.regime.dd_exit` | 撤退回撤上限，建议 **−0.20** |
| `pos.regime.confirm_days` | 升级确认天数，建议 **3**（滞回） |

乘数作用点：`planner.go` 计算 `units` 之后、`lotQty` 之前 —— **一处乘法**，不改任何出场逻辑。
与现有 `pos.equity_gate`（当前 off）的关系：若将来开启权益闸门，单票 8% 上限会截断 12% 的放大单位，
届时须同步上调 `pos.single_limit` 或改用「只数×单位」双控。

### 为什么不再走「大赢家加仓」

用户提到「确认赢家身份后加仓也可以」——**这条已经验过并否掉了**：
`e17_bigwinner_addon_a_report`（2026-11-03）：54 笔大赢家，MFE 随再突破次数单调升是幸存者偏差，
**落袋净利三带间 p=0.83~0.93 无任何差异**，每笔净利中位反而下降（14,939 → 12,248 → 11,500）。
「均等首买 + 不加码」已被坐实。

> 关键区别：**"赢家"不该定义在单票赚没赚，而该定义在市场内部健不健康。**
> 单票赢了再追 = 追高（已证无 edge）；市场宽度高时整体放大 = 顺势（本立项要验的东西）。

## 五、B 类预注册判据（跑前写死，不得事后改）

**变体**：`off`（基线，等价性验证用）/ `on`（乘数 2.0 / 1.0 / 0.5 + confirm 3 日）
**年份**：全 14 年 2005–2018（不是代表年——本参数直接改资金分配，代表年会引出内生性）

**判据（全部须过）**：

1. **净改善 > 0**：14 年 Σ已实现净利（`stop` 基线 974,937 起算）严格大于基线；
2. **剔除最佳一年后仍 > 0**（防单年独撑）；
3. **改善年数 ≥ 3 且唯一显著负值落在噪声门槛（±600 元/年）内** —— 沿用 LB-4 的 B 类裁判口径；
4. **机制确实生效**：进攻态平均仓位 ≥ **35%**（现状 18.9%）；若仓位没上去，说明乘数被别的约束吃掉了，实验无效；
5. **MDD 不更差**：14 年最大回撤 ≤ 基线 +1.0pp。

**任一不过 → 判"H2 不成立"登记，不进生产**（不得"挑个最优档"）。

**必须先解决的两个已知风险**（写进框架，不是免责声明）：

- **2014 −52,117**：线性模拟里唯一超门槛的负值。2014 是"上证暴涨 / 小盘震荡"的极端结构年。
  B 类前要先做一件事：把宽度改成**等权口径**（不看市值）与**双镜口径**（上证 + 中证500 各算一条）复比，
  看 2014 是否被修正。**若修不了，就在框架里把它登记为"结构分化年失效"，并要求该年不得为负超门槛。**
- **宽度是同步指标不是领先指标**：b50 高 = 今天多数票在涨，用它决定"明天买多少"存在**顺周期性**。
  T-1 取样已排除前视，但"跟着热度加仓"在转折点会最脆弱（2015-06 宽度 92.7% 后就是股灾）。
  → 必须叠加 **dd52 双确认**（指数也必须在近高点），单用宽度直接否决。

## 七、与既有结论的关系（不重复、不矛盾）

| 既有结论 | 本立项如何对待 |
|---|---|
| P0-3「买错才是出血口」 | **本设计的最大风险来源**：放大单位=放大买错。故进攻态必须双确认（宽度+距高），不是单条件 |

## 八、业界参照（2026-11-03 检索，仅作思路校准）
