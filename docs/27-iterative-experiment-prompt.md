## 0. 研究哲学

不是「书上说」，而是「实战说」。每一个系统要点都要被拆成可量化的统计分布，通过实验找到：
- **赚钱因子**（什么条件下利润集中）
- **赔钱因子**（什么条件下亏损集中）
- **拐点/甜蜜区**（参数多少时收益最优）
- **非线性关系**（是否单调、是否存在平台期或突变点）

实验流程：**提取系统要点 → 初步设计试验 → 分类实验结果 → 初步归纳结果 → 再次试验**。

## 3. 第二层：分类深挖试验（基于第一层结果交叉）

第一层发现某个维度有差异后，**用第二层实验回答：为什么？能不能组合出更好的规则？**

### 3.1 箱体维度 × 新高距离

- **假设**：低箱体 + 距新高近 的票，突破后上涨概率最高。
- **实验**：按 `箱体高度` × `距52周新高距离` 二维分桶，看净利热力图。
- **成功标准**：找到「低箱体 + 距新高 <20%」的组合是否显著优于其他组合。

### 3.2 大盘环境 × 新高距离

- **假设**：牛市里距新高远的票也可能涨；熊市里必须非常接近新高。
- **实验**：按 `年份/大盘区间` × `距52周新高距离` 二维分桶。
- **成功标准**：验证「动态 cutoff」假设——牛市 cutoff 放宽到 40-50%，熊市收紧到 10-15%。

### 3.3 升势标签 × 持有时间

- **假设**：升势入场的票，持有时间越长越赚钱；非升势入场的票，持有时间越长越危险。
- **实验**：按 `A_regime_up / 其他` × `持仓天数` 二维分桶。
- **成功标准**：确认升势入场是否应该延长 `staledays`，非升势是否应该更紧止损。

### 3.4 止损距离 × 箱体高度

- **假设**：高箱体应该用更远的止损，低箱体可以用更紧的止损。
- **实验**：按 `箱体高度` × `首腿止损距离` 二维分桶（需要模拟不同止损参数）。
- **成功标准**：找到「箱体高度 → 止损距离」的最优映射。

### 3.5 突破强度 × 放量程度

- **假设**：放量 + 强势突破（close 显著高于箱顶）的票质量更高。
- **实验**：按 `量比` × `close/箱顶 - 1` 二维分桶。
- **成功标准**：确认是否可以用「突破强度」替代或补充「新高距离」。

### 3.6 信号类型 × 新高距离

- **假设**：`breakout` 信号在非新高票上亏损最多；`failed_breakout` 或 `pyramid` 可能不同。
- **实验**：按 `signal_type` × `距52周新高距离` 二维分桶。
- **成功标准**：确认是否只对 `breakout` 信号应用新高校验，其他信号不应用。

### 3.7 黑名单冷却期深挖（E16）

- **假设**：单亏拉黑 12 个月可能过于严格——有些股票亏损后很快修复，重新走强。
- **实验设计**：
  1. 后验统计：找出所有曾亏损股票（409 只），统计它们在亏损后 6/12/24 个月内产生的 signal 数。
  2. 回测对照：分别跑 `无黑名单` / `6个月` / `12个月(当前)` / `24个月` / `永久` 五组五年回测。
  3. 关键指标：每组的总净利、胜率、被拦截股票数、被拦截 signal 的后续表现。
- **当前后验发现**：409 只曾亏损股票，12 个月拦截 197 个 signal，24 个月拦截 516 个，永久拦截 827 个。其中 379 只只亏 1 次，30 只多次亏损。
- **成功标准**：找到「冷却期 → 净利」的单调/非单调关系，确定最优冷却期。

### 3.8 新高距离仓位阶梯深挖（E17）

- **假设**：距52周新高 ≤40% 是甜蜜区，但内部质量不均匀——0-5% 是黄金区，20-40% 接近平庸。
- **实验设计**：
  1. 后验分档：把 ≤40% 区间细分为 0-5% / 5-10% / 10-20% / 20-40%。
  2. 后验仓位模拟：假设收益与仓位成正比，测试各档位 1x/2x/3x/4x/5x 仓位下的理论净利。
  3. 拐点分析：找出哪个区间的盈亏比/胜率开始显著下降。
  4. 真实回测：改 planner 的 buyOrder，把 A M1 的「升势 2 单位」改为「按距新高距离分档：0-5% 用 N1 单位、5-10% 用 N2 单位、10-20% 用 N3 单位、20-40% 用 N4 单位」，扫描 (N1,N2,N3,N4) 组合直到总仓位 ≤70%。
- **当前后验发现**：
  - 0-5%：75 笔，+63,804，胜率 30.7%，盈亏比 2.37（黄金区）
  - 5-10%：55 笔，+22,389，胜率 29.1%，盈亏比 1.69
  - 10-20%：80 笔，+33,472，胜率 18.8%，盈亏比 1.58
  - 20-40%：164 笔，+1,632，胜率 20.1%，盈亏比 1.01（平庸区）
- **拐点**：20-40% 区间盈亏比仅 1.01，几乎不赚钱。建议该区间仓位 ≤1 单位或拒绝。
- **成功标准**：找到各档位的最优单位数，使五年净利最大化且不超过 70% 总仓位硬上限。

## 4. 第三层：归纳与规则提炼（从深挖到可执行规则）

第二层实验完成后，把规律归纳成**可写入代码的规则**，并做**模拟回测**（不跑完整五年，只做参数敏感性或 A/B 测试）。

### 4.1 规则模板

| 规则 ID | 条件 | 动作 | 来源实验 | 验证方式 |
|---------|------|------|---------|---------|
| R1 | 距52周新高 ≤40% | 允许买入；>40% 拒绝 | E7 | 改 signal/screener 后跑五年 |
| R2 | 距52周新高 ≤15% | 仓位 2 单位；15-30% 仓位 1 单位；>30% 0.5 单位或拒绝 | E7+E3 | 改 planner 后跑五年 |
| R3 | 大盘一年新高股占比 <5% | 仓位减半或暂停 | E4+E7（待做） | 改 regime/planner 后跑五年 |
| R4 | 箱体高度 <8% 且距新高 <20% | 允许买入；否则拒绝 | E8+E7 | 改 box/screener 后跑五年 |
| R5 | A_regime_up = true | `staledays` 从 2 改为 8 | E4+E3 | 改 planner 后跑五年 |
| R6 | A_regime_up = false 且持仓 ≤10 日 | 收紧止损到买入价 -1% | E3 | 改 planner 后跑五年 |

### 4.2 模拟回测原则

- 每次只改一个规则（单变量），跑五年看净值变化。
- 若单变量有效，再组合做双变量/三变量。
- **任何规则改动后，必须重跑 2014-2018 五年，并对比基线 +112,707**。

## 5. 第四层：再试验与迭代（当规则失效或需要优化时）

如果第三层的规则在真实回测中表现不如后验，回到第一层重新切维度。

### 5.1 可能的原因

| 后验好但实盘差 | 排查方向 |
|---------------|---------|
| 过拟合 | 用 2019-2023 年数据做样本外验证 |
| 实现偏差 | 后验用 avg_cost，实盘用 signal close；重新用 signal 日 close 做 cutoff |
| 幸存者偏差 | 检查是否忽略了已退市股票（source_duckdb 有 348 只停止更新） |
| 交互效应 | 新高距离与箱体高度/大盘环境有非线性交互 |

### 5.2 再试验流程

1. **记录失效规则**：写入 `var/bt/failed_rules.md`。
2. **回切维度**：在第一层增加新维度（如「信号日 close 距新高」而非「avg_cost 距新高」）。
3. **重新深挖**：用新的二维/三维交叉实验定位问题。
4. **更新归纳**：修改规则或参数，再次回测。
