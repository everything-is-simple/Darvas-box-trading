## §1 语境：这条臂是什么

D3+D4 臂（`docs/65` 阶段 2「拆反向总成」）在新基线之上**只关两个反向部件**：

| 参数 | 值 | 含义 |
|---|---|---|
| `position.staledays` | 0 | **D3**：两日不获利强平（time_stop）彻底禁用 |
| `pool.blacklist_months` | 0 | **D4**：破位黑名单禁用 |
| `gate.ma60.mode` | stop | MA60 闸门开（stop 档：上证 < MA60 不开新仓） |
| `pool.max_hold` | 14 | 同时持仓上限 |
| `buy.premium` / `sell.discount` | 1.03 / 0.97 | 突破溢价 3% / 止损折扣 3% |
| `pos.unit` | 0.02 | 1 单位 = 权益 2% |

D3 是本笔能"活到"六月的关键：若 staledays=2（旧基线），01-19 收盘不高于成本即可能在第 3 日被强平，
根本等不到 2 月后的主升浪。**这笔交易的完整生命周期本身就是 D3 假设的证据**（详见 `docs/65` §阶段 2）。

## §4 买多少：仓位算法（单位制 × 新高档位）

逐步计算（`equity_base` = plan 生成时点最近权益快照 = 1,324,534.48）：

```
1 单位价值 = equity × pos.unit = 1,324,534.48 × 2% = 26,490.69 元
单位股数   = floor(26,490.69 / 触发价 4.32188 / 100) × 100 = 6,100 股
档位判定   = 距 52 周新高 4.497% < 40%（sizing_basis=newhigh_t1，档1）
单位数     = 档1 → 3 单位
买入数量   = 6,100 × 3 = 18,300 股 ≈ 79,812 元 ≈ 权益 6.0%
```

**逻辑**：离历史新高越近（突破即创新高区域），趋势确认越强，给的单位越多（`docs/44` §6.4 新高档位）。
单票风险由初始止损约束（§6）：止损距离 ≈ 6.6%，单笔最大亏损 ≈ 18,300 × (4.3613 − 4.07012) ≈ 5,329 元
≈ 权益 0.4%——**仓位大 ≠ 风险大，止损距离决定了真实风险敞口**。

## §6 初始止损在哪、为什么

**初始止损 = 入场箱体上轨 × 0.97 = 4.196 × 0.97 = 4.07012**（写在订单 reason_json 的 `stop` 字段）。

依据（B1 修正，2026-10-18）：首腿紧止损 = **被突破箱体上轨/突破点下方**，对应原书 §4.1——
突破后若跌回箱体内，说明突破失败，立即认错。旧实现误挂箱体下轨下方（风险放大 4 倍），已修正。
止损价随买入成交写入 position（`ledger.CreatePosition`），此后**只升不降**（DB 触发器保证）。

## §7 持仓监控：常驻止损单 + 箱体跟随上移

### 7.1 常驻止损单机制（ST1）

持仓期间，planner 每隔 2–3 个交易日为持仓挂一张 `stop_sell`（trigger = 当前 position.stop_price）：
挂单 → 执行日未触发 → expired → 下次 plan 重挂。**持仓每一天都处于止损单保护之下，先到先触发。**
本笔全程共 41 张订单，全部 side=sell、qty=18,300（一次全出）：

| 止损档 | 触发价 | 挂单区间 | 订单数 | 来源 |
|---|---|---|---|---|
| 1 初始 | 4.07012 | 01-19 → 02-16 | 9 | 入场箱顶 × 0.97 |
| 2 | 4.277991 | 02-27 → 03-26 | 10 | 新箱下轨 × 0.97 |
| 3 | 7.606158 | 03-27 → 05-14 | 13 | 新箱下轨 × 0.97 |
| 4 | 10.357078 | 05-16 → 06-12 | 7 | 新箱下轨 × 0.97 |
| 5 末档 | 12.777325 | 06-14 → **06-25 成交** | 3 | 箱 388326 下轨 × 0.97 |

### 7.2 上移规则（M4.4，`docs/00` §5.2）

新箱体**底确认**（3 日确认）当晚 → `raiseStops` 把止损上移到**新箱下轨 × 0.97**。
入场箱体不参与上移；只升不降。五个止损价逐档锁定利润：

```
4.07012 → 4.277991 → 7.606158 → 10.357078 → 12.777325
(锁定 -6.6%)  (锁定 -1.9%)  (锁定 +74%)   (锁定 +138%)  (锁定 +193%)
```

末档来源箱 388326（top 17.9688 / bottom 13.1725，底确认 06-12）：13.1725 × 0.97 = **12.777325**，精确吻合。
该箱 dead_date=2007-06-25——**同一根击穿止损的 K 线也终结了箱体**。

> **数据局限（如实注明）**：第 2/3/4 档对应的中间箱体行已被运行中回测进程的 stale 裁剪逻辑删除
> （`internal/store/repo_box.go`：未匹配的旧箱体定期清理；position/watch 引用的箱体保留，
> 这也是入场箱 165985 和末档箱 388326 仍在库中的原因）。三档触发价 ÷0.97 = 4.4103 / 7.8414 / 10.6774
> 应为当时各自新箱的下轨，但已无法回查箱体行本身。

### 7.3 全程无加码

`0017` 裁定：一律不加码——已持仓股再突破不生成买单。本笔 1–6 月仅此一个仓位（腿号 leg=1），
期间该股可能多次出现新箱体突破（如 3 月、5 月止损大幅上移所示），均不追加。


**为什么是 stop 而不是更聪明的高点卖出**：系统不做顶点预测。06 月该股仍在新箱体内时，止损在
12.78 锁定 +193%；箱体破位当日的跳空吃掉 2.3%，这是止损机制在 A 股涨跌停/跳空环境下的
**结构性成本**，不是缺陷。原书 O2：没有任何理由卖掉一支正在上涨的股票；反之，破位即走，不问原因。

## §11 诚实声明：本推演的边界

1. **回测模拟**：成交为 `sim:order` 模拟撮合，未含实盘滑点、部分成交、涨跌停无法成交等市场微观结构。
2. **价格口径**：全部为引擎后复权价（约为 raw ×1.92）；`daily_bar` 库存 raw 价（01-17 raw 收盘 2.27），
   两套价格不可混用（`docs/53`）。
3. **幸存者提示**：这是一笔盈利交易的完整解剖，不代表臂的期望收益；臂级结论以
   60 §4.3 六项统计清单的全窗口报告为准，不以单笔定优劣。
4. **未装部件**：D1（加码）未装——本笔无金字塔腿；D13（lifespan，`docs/66`）未接——
   本笔的持有期完全由箱体破位终结，无生命周期介入。
5. **数据裁剪**：中间三档止损上移的来源箱体已被运行中回测进程清理（§7.2），无法回查；
   watch 行为最终状态视图，非历史时点快照。
6. **回测进程仍在运行**：库内 id（signal/order/fill）随推进持续增长，本文引用的 id 以
   2026-11-07 取证时点为准，事后查询 id 可能漂移，按 code+date 定位为准。
