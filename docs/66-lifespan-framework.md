## §0 一句话

**把每一段走势登录「涨幅」与「时间」两条独立的统计分布；两条分布各给一个「已走过多少同类走势」的读数，取平均得余寿分位，换算成终止胜算，输出仓位比例与老化警告。**

回答一个问题：**「市场维持目前趋势的胜算有多少？」**（原书行 2998）
不回答：确切转折点、买卖信号、收益概率（原书行 3037、3039、7493）。

> **定义 D1 · 双轨定稿（用户 2026-11-08 拍板，不可推翻）**
> 余寿必须由**涨幅轨**与**时间轨**两条独立分布**取平均**得出。
> 只算时间轨的读数**不得称为余寿**、不得命名为 rank、不得进入任何资格闸门。
> 「现有建库脚本只有时间轨」是实现欠账（§8），**不改变本定义**，也不构成单轨版本的合法性。

**生成式结构 · 分类链**（用户 2026-11-08 22:27 口述定稿；内部结构名，不是框架名）：

> **太极 ＝ 天地万物的活法，在交易里就是「一段走势」**。它是本体、是活的，**不是标签**。
> 有了走势这个太极，人贴标签的心就来了：什么都要搞对立、搞矛盾。

| 层 | 生成 | 内容 | 原书出处 |
|---|---|---|---|
| **太极** | — | 一段走势：起点＝前一个同层重要高／低点，终点＝次一个重要高／低点 | 行 3014、3022、7285 |
| **两仪** | 太极生两仪 | **牛市 / 熊市**——第一刀对立标签（多头市场 / 空头市场，2 个背景态） | 行 7283–7285 雷亚六类前两类 |
| **四象** | 两仪生四象 | 同一阵营也分分合合：**牛市顺流 / 牛市逆流 / 熊市顺流 / 熊市逆流** | 行 7283–7285 的 4 类中期走势 |
| **八卦** | 四象生八卦 | 四象各再生短期**涨节奏 / 跌节奏** ＝ 2×2×2 ＝ 8 个结构位置（全表 §5） | 行 7543「三种趋势同时并存、方向可能相反」、行 7547「把短期放进中期与长期的前后关联」 |

> **「同是天涯沦落人，相逢何必曾相识」**：落进同一卦的走势，不问出身、不问哪只票、不问哪一年，归同一个分布——这是历史统计能成立的前提。
> **相逢的边界**：同卦可相逢，**跨市场不相逢**；「每一个市场都有各自的幅度与时间的几率分布结构」（行 7508），市场是分母，卦是桶（§3.3）。

**两条链，不许混**：

| 链 | 回答 | 落点 |
|---|---|---|
| **分类链**（上表） | 这段走势落在哪个结构位置 | §0 → §3.3 → §5 |
| **测量链** | 这个位置走到了什么年龄 | **§2 涨幅 + 时间双轨取平均** |

双轨**不是分类链的一层**，是施加在太极与每个分类节点上的量尺。用户 22:00 硬拍板的「双轨定稿」由 §2 D1 承载，**一字未动**；本次只把「两仪」从双轨改回牛市／熊市。

**分类自觉**（用户：「我们人就是恶心，分类呀、贴标签呀、排排名、算算命，没办法」）：
两仪 / 四象 / 八卦**全是人贴的标签，不是走势的属性**；「排排名」＝分位 `p`，「算算命」＝胜算 `odds`，二者只对**历史归类**说话，不对未来断言。
这是 §2.4 D3（rank ≠ 概率）、§2.5（余寿只发警告）、不变量 I6 / I7 的根。

### 1.3 术语（唯一口径）

| 术语 | 定义 | 口径 |
|---|---|---|
| **一段走势** | 起点＝前一个**同层**重要高点／低点；终点＝次一个重要高点／低点。未终止时终点＝当前 | 有起点、有终点才入样本 |
| **涨幅轨 extent** | 自起点沿本段方向推进的**涨跌幅 %**；下跌段取跌幅的绝对值，统一为非负「推进幅度」 | **基准是前一个同层重要高／低点**（行 7285），不是箱顶、突破价、建仓价 |
| **时间轨 duration** | 自起点至当前历经的**交易日数** | 交易日，不是自然日 |
| **池 pool** | `市场 × 层级 × 类别` 的样本集合，**只收已终止走势** | 三维度均不混池（§3.1、§3.3） |
| **分位 p** | `count(x_i < x_now) / N` | 严格 `<`；N≥30；值域 `[0,1)` |
| **余寿分位 p_life** | `(p_extent + p_time) / 2` | 结构位置，**不是概率** |
| **胜算 odds** | `(1 − p_life) : p_life` | 与原书 `1:1`、`1.63:1` 比较的唯一换算 |
| **平均剩余寿命** | 该池在 `p_life` 处，历史中位还能再走多久／多少空间 | 行 3012、7316、7320 |
| **仓位比例** | 连续量，随 `p_life` 上升单调下降 | 不是动作开关（行 7301、3069、7318、7487） |
| **太极** | 一段走势的**本体**（天地万物的活法）；有起点、有终点，**不是标签** | 与「一段走势」同物；分类链的起点 |
| **两仪** | **牛市 / 熊市** ＝ 2 个长期背景态 | 雷亚六类前两类，行 7283–7285 |
| **三层趋势** | 长期／中期／短期，**按持续期间定义**（§3.2） | 月／周／日只是观测采样 |
| **四象** | 牛市顺流 / 牛市逆流 / 熊市顺流 / 熊市逆流（＝ 顺势多 / 回调跌 / 顺势空 / 回调弹） | 路径式全名自带父级；**四象全部是正式池** |
| **八卦** | 四象 × 短期涨节奏／跌节奏 ＝ 8 个结构位置 | 行 7543、7547；全表见 §5 |
| **未定** | 长期处于窄幅盘整，方向无法归类 | 不进池、不算 rank、**框架弃权** |

旧定义的 `MALF` / `Wave` / `Range` / `span_bars` / `percentile_rank` / `velocity` 等原词**一律停用**；本文件不再保留历史对照列。旧词仅见于归档件。

## §2 测量链：涨幅 + 时间双轨（框架定稿）

> 本节是**测量链**，不是 §0 分类链的一层。分类链回答「这段走势落在哪一卦」，本节回答「这一卦走到了什么年龄」。
> 「两仪」在 §0 已归牛市／熊市；双轨在此独立成链，**D1 定稿一字未动**。

### 2.1 两条独立分布

对**每一个（市场 × 层级 × 类别）池**，分别建立：

```
E_pool = { extent_i   | 该池全部已终止走势 }     涨幅轨
T_pool = { duration_i | 该池全部已终止走势 }     时间轨
```

### 2.2 双轨读数

```
p_extent = count(e_i < e_now) / N
p_time   = count(t_i < t_now) / N
```

| 规则 | 内容 |
|---|---|
| 严格小于 | 等于当前值的样本不计入 |
| 样本门槛 | `N ≥ 30`；不足则**两轨全部留 None**，不 fallback、不补零、不扩池，附 reason_code |
| 防前视 | `终止可知日 ≤ as_of`；**当前未终止走势不进样本** |
| 值域 | `[0, 1)`，最大返回 `(N−1)/N` |
| 幅度基准 | 前一个同层重要高／低点（§1.3），一改基准分布即不可比 |

### 2.3 取平均 → 余寿分位 → 胜算

```
p_life = (p_extent + p_time) / 2
odds   = (1 − p_life) : p_life          # 「继续 : 终止」的胜算
```

> 原书原文：「根据历史资料计算目前走势幅度告一段落的几率，持续时间也做类似的计算，**再取两个几率的平均值**」（行 7437）。
> 原书两例：幅度 0.37 / 时间 0.38 → 平均 0.38 → 终止胜算 **1.63:1**（行 7441–7452）；幅度 0.73 / 时间 0.78 → 平均 0.76 → **3.17:1**（行 7454–7465）。
> 中位点：`p_life = 0.5` 时胜算 **5:5**（掷铜板），超过 0.5 后胜算 **< 1:1**（行 7485）。

### 2.4 双轨不可化简

| # | 铁律 |
|---|---|
| D1 | 缺任一轨即**不是本框架**；两轨必须取平均，不许任选一轨、不许加权、不许把涨幅当筛选用完就丢 |
| D2 | 两轨同池、同样本集、同 `as_of`，否则平均无意义 |
| D3 | `p_life` 是历史分位（结构位置），**不是「续涨概率」**；只有换算成 `odds` 才能与原书比较 |
| D4 | 样本不足时两轨一起留 None，框架退化为纯结构事实——这是诚实退化，不是 bug |

### 2.5 余寿只发警告

> 「我绝对不会以此预测当时走势的确切幅度与期限……这些结构在历史层面上显示几率的分布，以供你判断当前的市场趋势会持续或结束。」（行 3037、3039）
> 「统计分析并不同于水晶球，但它们确实可以提供市场老化的明显征兆。」（行 7493）

读数越往分布右侧，风险越高；它促使你去**检查基本面与指数互证**（行 3037、3043–3045），不是自动发出减仓单。

## §3 三层趋势、分池与联动

### 3.1 三套独立库（不混池）

每只票，月／周／日三个采样各跑一套同一个状态机（盘整 → 箱体 → 突破 → 一波 → 破位），**各自建库、各自排名、绝不混池**。月波期限中位约几月、日波约几天，量级差几十倍；混池会让日波永远「极年轻」、月波永远「极老」。

| 项 | 状态 |
|---|---|
| 库 | `var/lifespan/lifespan.db`，`wave_month` / `wave_week` 两表，与 darvas-box 主库分离，只读 |
| 脚本 | `scripts/lifespan_build.py` |
| 价格口径 | 后复权，源 `full_hist_adj.db` 的 `daily_bar_adj`（`data_meta adj_ready=1`） |
| 防前视 | 周／月 bar 日期＝期内最后一交易日（收盘可知日）；月方向取月 bar 收盘后状态；周标签只用 `date ≤ 周波诞生日` 的月 bar。抽查 541 条 0 错配 |
| 结构规则 | 同一状态机，N 根箱体窗口 / M 根出场轨：月 6/3、周 10/3、日 20/3，CLI 可调，建库写进 `meta` |
| 小样本读数（300 只） | 顺势多 n=1544 span p50=8 周、波幅 p50=+17.9%｜回调跌 n=1843 p50=7 周 −10.8%｜顺势空 n=1925 −11.7%｜回调弹 n=1910 +14.7%；月 UP n=1399 p50=8 月 +40.7%。**样本读数不作结论** |

> 上表「波幅」是旧口径（自箱顶突破价起算），**不是本定义 §1.3 的涨幅轨**；替换口径属 §8 实现欠账，定义以 §1.3 为准。
> 全仓引用 `66 §3.1` 指的即本节建库现状。

### 3.2 三层按持续期间定义

| 级别 | 持续期间 | 关心者 | 采样 |
|---|---|---|---|
| 短期趋势 | 数天～数周，通常 ≤14 交易日 | 交易者 | 日线 |
| 中期趋势 | 数周～数月 | **投机者（主战场）** | 周线 |
| 长期趋势 | 数月～数年 | 投资者 | 月线 |

出处：行 7539–7543、7283。**级别由持续期间定义，月／周／日只是观测采样**；「所有这三种趋势都可能同时存在，它们的方向可能相反」（行 7543）。长期趋势本身也要算「幅度与时间上的年龄」（行 7545）。

### 3.3 两仪生四象：六类分池

行 7283–7285 雷亚六类 ＝ **两仪**（多头市场 / 空头市场）＋ **四象**（各自的主升段 / 修正走势）。

| 两仪 | 四象（路径式全名） | 简称 | 原书对应 | A 股单向做多 |
|---|---|---|---|---|
| **牛市** | 牛市 / 牛市顺流 | **顺势多** | 多头市场主升段 | 唯一可做多的段 |
| **牛市** | 牛市 / 牛市逆流 | **回调跌** | 多头市场次级修正 | 降仓 / 观望，等折返衰老 |
| **熊市** | 熊市 / 熊市顺流 | **顺势空** | 空头市场主跌段 | 空仓（原书可做空） |
| **熊市** | 熊市 / 熊市逆流 | **回调弹** | 空头市场修正反弹 | 不碰 |

**四象全部是正式池**（§3.1 小样本已跑出四池读数）。每个池独立建 `E_pool / T_pool`，按 §2 出双轨读数。

> **相逢规则（§0）**：落进同一象的走势，不问个股、不问年份、不问此前路径，归同一分布；
> **市场是分母**——每个市场各有自己的一套四象分布（行 7508），跨市场不混池。

**次级折返的入池资格**（不许把噪声收进「回调跌」池）：

```
is_secondary_reaction = 逆长期趋势
                    AND 期限落在中期量级
                    AND 折返幅度落在前一波段的 33%–66%（数值待目标市场校准）
                    AND 不破前一个中期低点
```

> 原书自承「这个程序的最困难部分是区分次级折返走势与逆趋势的小型走势」（行 3022）。不满足者归「逆趋势小型走势」桶，**不进四象池**。33%–66% 的具体数值属段 C（§7），本定义只定结构。

### 3.4 联动契约（三层如何配合）

> 原书：「即使仅从事短期的交易，你也需要把短期趋势放在中期趋势与长期趋势的前后关联中来判断」（行 7547）。

| # | 契约 | 规则 |
|---|---|---|
| 1 | **统一时间轴** | 交易日为唯一原子坐标；上层 bar 的可知日＝期内最后一交易日（收盘后可知） |
| 2 | **嵌套链** | 每个下层走势记录 `parent_mid_wave_id` / `parent_long_wave_id`，按可知日挂到**当时已确认**的上层走势；上层盘整须显式记「无父波」，不得留空 |
| 3 | **单向传递** | 长期 → 方向 + 长期余寿 ＝ **资格 + 总仓位上限**；中期 → 四象标签 + 该段余寿 ＝ **节奏 + 权重**；短期 → 达瓦斯箱体突破／破位 ＝ **唯一触发**。上层不产生订单，下层不得反向改写上层状态 |
| 4 | **刷新与失效** | 定义 `as_of` 快照；每层状态每个可知日重算并向下广播；标签逐日刷新并保留历史版本，**禁止只在走势诞生日打一次**。上层方向翻转当日：冻结在途下层标签、停止新开仓；既有持仓按主干 O15「一次全出」处理，本框架不生成卖单 |
| 5 | **冲突裁决** | §5 八卦全组合表逐格写「允许 / 观望 / 冻结 / 弃权」；**「月线方向」是状态、「月级 p_life」是年龄，两列独立，不得互相替代** |
| 6 | **未定桶** | 长期窄幅盘整 → 标签 `未定` ＝ 不进池、不参与 rank、日层箱体突破照常触发但本框架**弃权**（不投赞成也不投否决） |

**三层余寿禁止加权求和成一个分**：资格 / 权重 / 时点是三种性质不同的量，且各层本就不混池。

## §4 输出与本项目接入方式

### 4.1 主输出（连续量）
