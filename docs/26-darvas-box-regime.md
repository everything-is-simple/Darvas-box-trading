# 26. 用达瓦斯箱体自身判大盘趋势（替代 200 日均线）

> 2026-10-22 设计文档。用户否决 200 日均线（"太慢，事后看不错，实战拉"），
> 要求改用达瓦斯自己的箱体理论判大盘牛熊，并做指数/个股同向验证。
> 本文档含**判别力实测数据** + 落地方案，供拍板。

## 0. 用户原始诉求（逐句拆解）

> "指数，三日定上轨，三日定下轨，我们再看这一个个箱体，是否抬着指数向上走。
> 指数再和个股做同向验证，只有同时处于升势才买；
> 卖点还是尊重箱体走势，加一条，大盘破就走。"

| 诉求 | 达瓦斯语言翻译 |
|---|---|
| 指数三日定上下轨 | 用 `box.Engine.Scan` 扫 `sh000001`，得指数自身箱体 |
| 箱体是否抬着指数向上 | 看指数箱体下轨是否逐级抬高（更高低点） |
| 指数/个股同向验证 | 买点门：`指数升势 AND 个股向上突破` 才买 |
| 卖点尊重箱体 + 大盘破就走 | 卖点门：个股箱体破位照旧，另加大盘转降势强平 |

## 1. 判别力实测（关键证据，全部来自五年真实数据）

### 1.1 直接用默认参数扫指数 → 失败（粒度过粗）

`box.Engine.Scan(sh000001, 默认参数)` 结果：全历史 8743 天仅 134 个箱体阶梯，
**2014-2018 五年 confirmed 箱体只有 8 个**：

| 年份 | confirmed 箱体数 |
|---|---|
| 2014 | 3 |
| 2015 | 3 |
| 2016 | 1 |
| 2018 | 1 |

根因：默认参数（三日确认 + 5% 最小宽度 + 放量突破）是**给个股调优**的，指数波动平缓，
被压缩成 1-3 个超大箱体（2016-2018 三年就 2 个箱体），「抬升/下降」样本太少，无判别力。

### 1.2 改「N 日低点抬升」→ 判别力极强（达瓦斯"更高低点"的连续化）

达瓦斯箱体的本质是"更高高点 + 更高低点"。指数不需要完整箱体，只需看
**近 N 日低点是否逐级抬升**——这就是"箱体下轨抬升"的连续化版本，仍是箱体语言。

**判据**：`60日最低价 > 前一日60日最低价×1.002 → 升势；< ×0.998 → 降势；否则震荡`。

与 MA200 方向一致率（越高越准）：

| 年份 | 20日 | 30日 | 60日 |
|---|---|---|---|
| 2014 | 85% | 89% | **92%** |
| 2015 | 64% | 70% | **82%** |
| 2016 | 62% | 60% | **74%** |
| 2017 | 74% | 74% | **80%** |
| 2018 | 80% | 90% | **100%** |

**结论**：60 日低点抬升是最优参数（五年平均 86% 一致），且**几乎无滞后**——
2014 牛市前夜 92% 命中（200 日线只有 54% 牛/46% 熊的滞后），2018 大熊市 100% 命中、
全年"抬升占比 0%"（从未上当）。

## 2. 关键陷阱：牛熊二元开关是错的，趋势三元才对

把 60 日低点标签叠加到五年 570 笔平仓交易，按**开仓日**归类：

| 年份 | 牛开仓净利 | 熊开仓净利 | **震荡开仓净利** |
|---|---|---|---|
| 2014 | +1,894 | -2,283 | **+62,221** ← 全年盈利都在震荡段 |
| 2015 | +56,233 | 0 | +28,859 |
| 2016 | -1,658 | +2,352 | **-12,129** |
| 2017 | -3,612 | +1,875 | **-30,147** |
| 2018 | 0 | +11,665 | **-73,768** ← 全年亏损都在震荡段 |

**核心发现**：

1. **70%+ 的交易落在「震荡」标签**，而震荡恰是盈亏最极端的段（2014 的 +6.2 万、
   2018 的 -7.4 万都来自震荡段）。
2. **「熊市开仓」其实没怎么亏，甚至小赚**（2018 熊开仓 +11,665）——因为真降势里
   系统已被止损/箱体破位压低了开仓。
3. **真正的病灶是"震荡市里瞎开仓"**：达瓦斯箱体突破只在**有趋势**时才有正期望。

### 2.1 情景模拟（净利口径）

| 门策略 | 五年净利 |
|---|---|
| 现状（无门） | +41,501 |
| 只做升势（震荡+降势都停） | +52,856 ⚠️ 但 2014 从 +61,832 砍到 +1,894 |
| **只砍降势（震荡照做）** | **+66,466** |

**结论**：门应是「**趋势三元**」，不是「牛熊二元」——真正要砍的是**降势**，
震荡要保留（2014 牛市前夜的盈利全在震荡段，砍了反而废掉最肥的启动期）。

## 3. 落地方案（推荐）

### 3.1 大盘趋势判据（达瓦斯箱体语言，三态）

| 状态 | 判据（60日低点） | 仓位操作 |
|---|---|---|
| **升势** | 60日低点逐级抬高 | 进攻：正常开仓，单笔放大 |
| **震荡** | 低点横盘（既不抬升也不下移） | 防守：只允许试探仓（1单位） |
| **降势** | 60日低点逐级下移 | 空仓/严格防守，不开新仓 |

### 3.2 两道门

- **买点门**：`指数升势 AND 个股向上突破` → 全仓买入；`指数震荡` → 仅试探仓；`指数降势` → 不开仓。
- **卖点门**：个股箱体破位照旧（尊重箱体走势），**另加**：持仓期间指数转降势 → 次日强制平仓。

### 3.3 待精确化的点（进入回测前必须补）

1. **卖点门的精确盈亏**：上文只统计了"影响笔数"（2018 42 笔 / 2017 18 笔），
   精确的"强平后盈亏"需要个股逐日收盘价 + 成本价口径，才能验证卖点门到底省不省钱。
2. **震荡市的"防守"粒度**：震荡占 70% 时间，若震荡只允许 1 单位，等于变相降杠杆，
   需要和"震荡照做但降势停手"（净利 +66,466）对比，选优。
3. **同向验证的个股侧**：个股的"升势"如何判定？是"个股自己箱体已 broken_up"（现有信号），
   还是"个股也满足 N 日低点抬升"？需明确，避免双重箱体判据打架。
