## 1. 系统溯源：原著规则 → 当前实现映射

### 1.1 原著方法论的本质

达瓦斯规则体系由 48 条可枚举规则构成（取证 Agent 从 OCR 全文提炼，见行号引用），其骨架是：

**箱体形成**（三日法则：连续 3 日新高不放量 → 上轨上移，反之确立下轨）→ **停损买单挂突破**（"buying on a scale-up stop" 贯穿全书，line 2078/4233）→ **金字塔加仓**（新箱体确立 + 相对放量，逐箱推进，强股集中度单调上升）→ **止损机械上移**（初始 = 被突破箱体上轨下方 1/8 美元，此后每确立新箱体随箱底上移）→ **破位清仓**。

作者自己从 telegram 理论与 Barron's 遴选中不断证伪迭代，最终形态 = **技术（箱体+量能）选时点 × 基本面（盈利≥行业增速）选方向**，外加三条保险：停损买单机制（不追高的本质）、快速止损（≤10%）、利润抽离 50%。

### 1.3 原著有、系统无（明确缺口）

1. **利润抽离 50%**（R28）——影响长期复利路径与回撤；
2. **基本面/行业强度**（R34-R38）——需要外部数据，系统定位为人工序；
3. **创历史新高硬门槛**（R08）——现为相对强度近似；
4. **熊市个股特例通道**（R40）——M8.8 刻意简化；
5. **杠杆**（R29）——明确放弃；
6. **5-8 关注 / 1-4 持有的双重上限**（R26/27）——只实现了前者。

`MinBoxWidth=0.05`、`buy.premium=1.03`、`sell.discount=0.97`、`box.volmult=2.0`、RS 窗口 20 日/阈值 1.2、换手 5000 万、宽度法五参数（window 20 / bull 0.55 / bear 0.40 / confirm 3 / min_history 60）、单位制八参数（50 单位切分）、`staledays=15`、flat_too_long、候选"太晚"4 日规则、M8.6 addon 第②通道（欧奈尔转引）。
