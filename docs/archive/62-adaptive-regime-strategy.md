# 62 · 市场状态自适应策略设计（Adaptive Regime Strategy）

> 定位：**把大盘感知从「单一 ma60 开关」升级为「广度 + 情绪 + 个股三层自适应」**的完整设计。
> 本文是 `docs/61`（广度信号源）的**落地设计**，不是新信号源——61 回答「用什么指标」，
> 62 回答「怎么把这些指标装进择时、仓位、选股，以及 ma60 去哪」。
> 权威关系：信号定义以 61 为准；参数键/值以 44 为准；实验排队以 60 为准；红线以 00 §9 为准。
> 状态：**设计定稿，待预注册（60 §批2 之后）。** 本文不含任何新参数键的最终值，所有阈值走 60 预注册。

---

## 0. 一句话

**用「全市场涨跌家数比 A/D」替代 ma60 做市场状态主开关；用「涨停/跌停家数」做情绪温度与恐慌反向阀；
用「箱体突破 + 相对强度 + 行业宽度」做个股/行业的强势识别，替代当前机械化下单。
牛（普涨）满仓铺开、熊（普跌）关闸空仓、猴（分化震荡）聚焦强势个股与抱团行业做结构性多头。**

## 1. 模块划分与数据流

### 1.1 五模块职责

| 模块 | 现有载体 | 职责 | 本设计改动 |
|---|---|---|---|
| **M1 数据层** | `internal/ingest` + `tdx` | 灌入日线、复权 | 新增 `breadth` 任务（只读源库，落 `market_breadth` 表） |
| **M2 广度引擎** | `regime.ClassifyDate`（内生宽度法，已存在但未接入择时） | 算 A/D 比、涨停/跌停/新高家数 | **数据源从「箱体事件流」改为「全市场当日涨跌家数」** |
| **M3 状态判定** | `regime.Regime`（Bull/Bear/Range 枚举已存在） | 牛熊猴三段分类 + 闸门开关 | 判定输入从 ma60 → A/D 比连续确认 |
| **M4 选股/打分** | `internal/planner` + `screen` | 箱体突破 + 相对强度 + 行业宽度 | 新增「强势个股/行业」加权分（见 §4） |
| **M5 仓位/风控** | `planner.buyOrder` + 阶梯制 | 单位数、闸门拦截、止损 | 仓位随状态缩放（满仓/半仓/空仓），止损不变 |

### 1.2 数据流（单向，无环）

```

   │ ingest（复权 adj_close）
   ▼
full_hist_adj.db ──┬── breadth 任务（只读）──► market_breadth 表
                   │     A/D 比 / 涨停数 / 跌停数 / 新高数
                   │
                   └── box.Scan（箱体识别，逐股）
                         │
                         ▼
                 ┌─────────────────────────────────┐
                 │  M3 状态判定（A/D 连续确认）       │──► Regime: bull/range/bear
                 └─────────────────────────────────┘
                         │
                         ▼
                 ┌─────────────────────────────────┐
                 │  M5 仓位/闸门（planner.buyOrder） │
                 │  牛=满仓 · 猴=半仓 · 熊=关闸       │
                 └─────────────────────────────────┘
                         │
                         ▼
                 ┌─────────────────────────────────┐
                 │  M4 选股打分（突破 + RS + 行业宽度）│──► 候选池排序
                 └─────────────────────────────────┘
                         │
                         ▼
                        成交 → 阶梯制单位数 → 止损/出场
```

**关键改动只有一处实质换源**：M2 的数据源从「箱体突破事件流」换成「全市场当日涨跌家数比」。
前者要等箱体成立（滞后一档），后者当日收盘即知（零滞后）。其余模块复用现有骨架。

## 2. 行情判定信号（三种状态 + 指标 + 阈值）

### 2.1 主开关：涨跌家数比 A/D（等权，每股一票）

```
A/D(t) = 当日上涨家数 / (当日上涨家数 + 当日下跌家数)    # 复权口径 adj_close 逐日比对
```

| 状态 | 判据 | 语义 | 动作 |
|---|---|---|---|
| **牛 Bull** | 连续 3 日 A/D ≥ 0.70 | 普涨 / 强反弹 | **满仓**，阶梯制照跑，子弹铺开 |
| **猴 Range** | 0.30 < A/D < 0.70 | 分化 / 震荡 | **半仓**，聚焦强势个股与抱团行业 |
| **熊 Bear** | 连续 3 日 A/D ≤ 0.30 | 普跌 / 恐慌 | **关闸空仓**，停开新仓（ma60 做不到的快关） |

> 连续 3 日确认复用现有 `regime.breadth.confirm=3` 机制，滤掉单日脉冲。
> 熊/猴仓位规则与现有约定一致（regime.go:7 注释）：熊关闸、猴半仓，仅日志区分。

> ⚠️ **上表阈值已作废，实施以 `docs/63` §5–§7 为准。** 2026-11-06 全窗实测（2005–2024，5,289 日）：
> 绝对阈值 `0.70/0.30` 覆盖 53.6% 的交易日，单阈值 + 连 3 日确认后实测 **牛 60.6% / 熊 39.1% / 猴 0.3%**，
> 猴市等于不存在。修正三处：
> ① **比值全部 z 化**（滚动 250 日），不用绝对阈值；
> ② 状态判定改 **双阈值迟滞状态机**（进牛 z≥+1.0，跌回 z<+0.3 才退），猴市回到 60–78%，切换 7.6–18.4 次/年（ma60 为 11.9 次/年）；
> ③ 大盘层补 **T2 涨幅强度 = 等权累计收益 − 上证累计收益**（与 A/D 相关性仅 r=0.17），
> 专治 2021-02-18 那类「A/D=0.632 看着是牛、强度 −18.8 其实是个股熊」的假牛顶。
> 判据实测：牛熊态后 20 日收益差 **+2.0~2.3pp**，高于 ma60 的 +1.3pp。

### 2.2 情绪温度计（赚钱效应面）与反向阀（亏钱效应面）

| 指标 | 定义 | 必选 | 判读 |
|---|---|---|---|
| **涨停家数** | 涨幅 ≥ 分板块涨停阈值（主板 10% / 创业 20% / 科创 20%） | 必选 | 情绪温度：高 = 有主线，骤减 = 退潮 |
| **跌停家数** | 跌幅 ≤ 分板块跌停阈值 | 必选 | 恐慌度量：暴增 = 该空仓的快关 |
| 百日新高家数 | `adj_high` > 前 100 日高点 | 可选 | 赚钱效应的「面」 |
| 大幅回撤家数 | 当日最高回撤 > 7% | 可选 | 普跌烈度 |

**宠儿存在（猴市可做多）** = 涨停家数高 且 百日新高家数扩散 且 A/D ≥ 0.50
**情绪退潮（该收手）** = 涨停家数骤减 且 跌停家数暴增 且 A/D ≤ 0.30

### 2.3 三类状态汇总表

| 维度 | 牛 Bull | 猴 Range | 熊 Bear |
|---|---|---|---|
| A/D 比 | ≥ 0.70（连 3 日） | 0.30~0.70 | ≤ 0.30（连 3 日） |
| 涨停家数 | 高且扩 | 中（有主线则高） | 骤减 |
| 跌停家数 | 低 | 中 | 暴增 |
| 新高家数 | 扩散 | 局部扩散 | 萎缩 |
| 仓位 | **满仓** | **半仓** | **空仓观望** |
| 选股 | 阶梯制照跑 | 聚焦强势个股/行业 | 不开新仓 |

## 3. 调仓规则（三态操作逻辑）

### 3.1 熊市：空仓观望为主

- **关闸**：A/D ≤ 0.30 连 3 日，`gate.breadth.mode=stop` 拦截所有新开仓（`buyOrder` 在 `planner.go:703-710` 处新增广度闸门，替代 `gate.ma60`）。
- **已持仓处理**：不追加大腿，已有仓位按原止损纪律正常离场（`stop`/`time_stop`/`stop_box`），**不恐慌清仓**——止损是既定的，恐慌清仓是新的择时，不引入。
- **快关信号**：跌停家数单日暴增可触发「额外确认」，但主开关仍是 A/D 比，跌停家数只作辅助。

### 3.2 牛市：力求最大化收益

- **满仓**：A/D ≥ 0.70 连 3 日，阶梯制照跑，单位数由「距 52 周高点四档 3/2/1/0.5」决定，不因牛市额外加杠杆。
- **不追拥挤**：牛市里个股也走箱体，仍按箱体突破入场，不因「牛市」放宽突破确认（防止牛市末尾追高）。
- **守住 MDD 锚**：攻态仓位 ≥ 35.5%、MDD ≤ −33.50%（docs/48 锚点）在牛市中依然要盯，牛市是收益来源也是回撤来源。

### 3.3 猴市：聚焦机构抱团的热门行业与强势个股

这是本设计最核心的差异化场景。猴市「指数不动、个股分化」，机械化下单（不看行业不看强势）正是当前亏损过大的根源。

- **半仓**：只放一半子弹，剩余现金等信号。
- **只做强势**：候选池加两道过滤（见 §4），把「当下宠儿」从「普涨的噪声」里筛出来。
- **行业宽度做温度**：某行业涨停 + 新高家数在扩散 → 该行业是抱团热点，其箱体突破信号**加重**；收缩 → 只是个股孤军，降权。
- **行业强度做过滤**：`行业强度(t) = 行业等权 60 日收益 − 上证同期收益`，只作**个股打分维度**，不作择时开关（行业轮动已判伪，见 §4.1）。

## 4. 增强识别强势行业与强势个股（替代机械化逻辑）

### 4.1 先划清红线：什么是「判伪过、不能做」的

- **行业轮动选行业**：已判伪（`docs/57 §6.5`），三窗口年内配对全不过、方向翻转。**不复活。**
- **行业仓位加权 / 追最强行业加分**：拥挤度风险（`docs/57 §5.5`），不做。
- **静态行业分组**：已证伪（`docs/57 §5.3`），不做。

### 4.2 能做的三件事（全部是「个股打分维度」，不是新择时开关）

**① 个股相对强度（RS，达瓦斯原文的「强者恒强」）**

```
RS(t) = 个股 60 日收益 − 上证同期收益    # 已有 screen.rs_excess_min=0.20
```
保留现有 `screen.rs_excess_min` 门槛，只做**过滤**：RS 低于门槛的突破信号不进池。

**② 行业宽度做温度（识别抱团，不预测轮动）**

```
行业宽度热度(t) = 行业内涨停家数 + 百日新高家数，环比是否在扩散
```
- 扩散 → 该行业的突破信号 **加分**（权重上调，不改单位数）。
- 收缩 → 该行业的突破信号 **降权**。
- **这是「识别当下谁被抱团」，不是「预测下一个轮到谁」**——后者才是已判伪的轮动。

**③ 箱体质量分层（识别强势个股的「突破质量」）**

在既有箱体维度上，给「突破质量」打分：突破时距 52 周高点的档位（t1/t2/t3）、箱体高度、
突破放量（若可免费取得）等。**猴市只放行高质量突破（t1/t2 档 + 窄箱 + 强 RS），
过滤掉 t4 远端低质量突破**——这一步直接呼应 A1 正在验证的「t4 消融」方向。

### 4.3 机械 → 自适应的替换对照

| 现状（机械化） | 本设计（自适应） | 机制 |
|---|---|---|
| ma60 单点择时 | A/D 比 + 涨停/跌停家数 | 广度主开关 + 情绪阀 |
| 不看行业 | 行业宽度做温度 | 识别抱团，不预测轮动 |
| 不看强势个股 | RS 门槛 + 突破质量分层 | 只做强者，猴市收窄到 t1/t2 |
| 机械满仓 | 牛满/猴半/熊空 | 状态驱动仓位缩放 |

## 5. ma60 的处理：改造替代 + 增强思路

### 5.1 ma60 的三个致命缺陷（为什么被替代）

| 缺陷 | 机制 | 后果 |
|---|---|---|
| 滞后 | 60 日均值，拐点晚 20–40 日 | 顶部满仓、底部空仓 |
| 被权重股劫持 | 上证市值加权 | 指数红、4800 票跌 |
| 单点 | 只回答「涨没涨」 | 分不清普涨牛 vs 结构牛 vs 猴市 |

现有 `gate.ma60.mode=stop`（`planner.go:96-110`）正是这个路子，所以「机械下单亏损过多」。

### 5.2 替代方案（主开关）

`gate.ma60` → `gate.breadth`（A/D 比连续确认），已在 §2 定义。这是**择时主开关**的替换。

### 5.3 ma60 的去处（不是删除，是降级复用）

| ma60 的角色 | 处理 | 理由 |
|---|---|---|
| 择时主开关 | **退役** | 滞后 + 被权重劫持 |
| **个股趋势过滤器** | **保留，但作用域从「大盘」收窄到「个股」** | 个股 MA60 可作「箱体之上的趋势确认」，个股层面没有权重劫持问题 |
| 上证 MA60 与「行业强度 60 日」对齐 | **保留作参照系** | 行业强度公式的分母是「上证同期收益」，ma60 作为「中期水位」参照 |

**增强思路**：ma60 不必丢弃，可作「**个股中期趋势一致**」的加分项——突破时个股收盘价在自身 MA60 之上，说明不是超跌反抽，而是趋势启动。这是把 ma60 从「大盘开关」改造为「个股质量过滤」的关键一步，且不违反「禁均线系统」红线（红线禁的是**用均线做择时/信号**，个股趋势确认是选股维度，需在 60 预注册时明确定义边界）。

### 5.4 改造后的完整框架

```
大盘层（择时）：A/D 比连续确认 → 牛/猴/熊 → 满/半/空仓   （替代 ma60）
情绪层（温度）：涨停/跌停家数 → 宠儿识别 / 恐慌快关
个股层（选股）：箱体突破 + RS 门槛 + 突破质量分层 + 个股 MA60 趋势确认（ma60 增强用）
行业层（温度）：行业宽度扩散 → 抱团识别（非轮动）
```

## 7. 一句话总结

**ma60 是「单点滞后、被权重劫持」的大盘开关，换成「涨跌家数比 A/D」做主开关；
牛满仓、猴半仓（聚焦抱团行业与强势个股）、熊空仓（关闸停开）；
ma60 从「大盘开关」降级复用为「个股趋势确认」；
强势识别靠「箱体突破 + RS + 突破质量 + 行业宽度温度」，全部是选股维度，不是已判伪的行业轮动。**
