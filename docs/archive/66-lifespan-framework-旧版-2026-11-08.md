## §0 一句话

**A 股单向做多，唯一的赚钱结构 = 「主趋势向上（月线）+ 中级趋势走顺势段（周线）」。**
lifespan 的全部价值 = 用历史概率回答两个问题：
1. 顺势段还能走多久（决定**什么时候撤**）
2. 回调段还要跌多久（决定**什么时候再进**）

lifespan 是**服务于 darvas-box 的只读基础设施**（三套库+寿命统计），不是并列的第二套选股系统，
**不产生订单**——主干订单全部由达瓦斯箱体产生（`65 §1.1`）。
**与 48（大盘状态）的关系（2026-11-08 订正）**：48 的 MA60 / 温1–温8 已被 `65 §3.3` 判为自创工程补丁、
从「原著实现」组成部分降级，因此 lifespan **不与任何市场层前置开关绑定**，也**不把大盘闸门当作必要前置过滤**。
解题钥匙在个股寿命；市场层指标若要启用，属**段 C（1b）**的预注册事项，不是原装系统的组成部分。

> **⚠️ 投影边界（2026-11-08）**：上面「解题钥匙在个股寿命」「不与市场层绑定」是**投影层的工程结论**，与原书相反——
> 原书先判大盘（指数互证 + 大盘平均寿命），再用相对强度选个股（终极定义 §1.2、§6）。
> 本投影层主动放弃市场层，是为了不改原著买卖点、不引入第二套选股系统。**这不是原书目的达成，是取舍**。
> 若要将市场层接回，须单独扩 `00 §9` 豁免边界并拍板，且全部排到段 C。

## §1 术语表（唯一口径，口语化定稿）

> 术语顺着「一笔交易的生命过程」长出来，每个词都对应「这一刻你在干什么」。
> **lifespan 是机制名，wavespan 是数字名，二者不重名。**

### 1.1 核心对象

| 术语 | 一句话含义 | 历史对照（旧定义原词，已归档） |
|---|---|---|
| **盘整** | 无方向、无上下轨的真空期，**不下单** | Transition |
| **箱体（box）** | 上下边界都清楚的震荡区间，**可交易** | Range |
| **箱顶（上轨）** | 突破它 → **买**；上轨**不随行情变**（历史买入点，用过了） | boundary_high_init |
| **箱底（下轨）** | 跌破它 → **卖**；下轨**会随行情上移**（移动止损） | boundary_low_now / guard |
| **一波（wave）** | 从突破箱顶到跌破箱底的一段同向行情 | Wave |
| **破位** | 跌破箱底，这一波结束 | Break |
| **拐点** | 一个高/低点（分形 k=2 确认） | Pivot |

> **溯源订正（2026-11-08 审查）**：旧定义的 `Transition` 有双边界与 candidate，不是「无轨真空」；`Range` 有 init/now 两层边界且 now 可演化；`boundary_high_init` 是 break 时冻结的过渡期上边界（判新波用），不是「历史买入点」。
> 本表是**达瓦斯箱体口径的口语化命名**，不宣称与旧定义语义等价。旧定义 `price_range` 是整数价格点数差、`progress_pct` 是波内推进比例，也都不是「涨幅%」。

### 1.2 lifespan 机制（总名称 + 下属三个量）

```
lifespan（寿命机制）—— 总名称，记录+统计每波活多久、涨多少、排第几
   ├─ wavespan = 一波的天数（时间维度）
   ├─ 波幅     = 一波的涨幅%（空间维度）
   └─ 涨速     = 波幅 ÷ wavespan（单位时间强度）
```

| 术语 | 一句话含义 | 历史对照（旧定义原词，已归档） |
|---|---|---|
| **lifespan（寿命机制）** | 整套「记录每波寿命 + 历史排名 + 概率」的机制 | Lifespan 层 |
| **wavespan** | 一波从生到死的天数 | span_bars |
| **波幅** | 一波的涨幅 % | price_range / progress_pct（口径不同，见 1.1 订正） |
| **涨速** | 波幅 ÷ wavespan | **旧定义无此词**（全 7 版零命中）；旧定义的对应量是 `stagnation_rank = span_bars/primitive_count`。涨速是 66 自创，勿再标为 MALF 原词 |
| **衰老度（rank）** | 当前 wavespan 在历史同类里的分位（0–1） | percentile_rank |

> **「双因子」精确分工（投影层口径，2026-11-07 定稿）**：本投影层是**双因子**，不是单因子。
> - **时间因子（wavespan）→ 排名**：衰老度 rank 唯一按 wavespan 算（§4.3 原文）。
> - **波幅因子 → 资格 + 读数**：涨速 = 波幅 ÷ wavespan（§1.2）是「磨」过滤判据（§1.4/铁律7）的唯一输入；波幅本身进分池分布表（p25/p50/p75）作为空间维度读数，与 span 并列报告。
> 一句话：**「排第几」只看时间，「该不该看」用波幅的派生量涨速过滤**。
>
> **⚠️ 与定义层的差别（2026-11-08）**：完整定义是**幅度轨 + 时间轨各自算分位、取平均** `p_life=(p_extent+p_time)/2`（终极定义 §2.3，原书行 7437）。本投影层**只保留时间轨**，波幅不进 rank；这是投影损失清单第 ② 项。
> 若日后要把幅度轨接回，属**定义层补齐 + 段 C 预注册**，不得借本次文档改动提前起臂。

### 1.3 三级走势（责任分工）

| 级别 | 术语 | 看哪个周期 | 口语责任 |
|---|---|---|---|
| 长线 | **主趋势** | 月线 | **「干不干」**——大方向对不对 |
| 中线 | **中级趋势** | 周线 | **「什么时候干」**——顺/逆主趋势的哪一段 |
| 短线 | **短期波动** | 日线 | **「怎么干」**——精确买卖点 |

**中级趋势的两个方向段**（不是「次要趋势」——那个词会误读成「不重要」，且掩盖「逆势」本义）：

| 方向词 | 含义 |
|---|---|
| **顺势段** | 中级趋势**顺着**主趋势走的那一段（月涨 + 周涨） |
| **回调段** | 中级趋势**逆着**主趋势走的那一段（月涨 + 周跌） |

> 道氏原义：secondary = 主涨势里必然出现的**逆势折返**，幅度为主走势的 **33%–66%**，不破前一个中期低点。
> 我们用「顺势段/回调段」两个方向词接住这层本义，用「中级趋势」接住「级别」。
>
> **⚠️ 级别定义订正（2026-11-08）**：原书三级按**持续期间**定义——短期数天～数周（通常 ≤14 交易日）、中期数周～数月、长期数月～数年（终极定义 §3.1，原书行 7539–7541）。**月/周/日只是观测采样，不是级别本身**。
> 本投影层因工程简化把二者绑定，须承担「同一段行情在三个周期被识别成三套互不相干的波」的后果；补齐嵌套见 §3.6。
> 另：33%–66% 与「不破前一个中期低点」目前**只写在注释里、未作入池资格**（§4.1 只看方向）。补齐见 §4.6。

### 1.4 过滤判据

| 术语 | 一句话含义 |
|---|---|
| **磨（磨蹭）** | wavespan 长但涨速低 → **无效标的，过滤** |

### 1.5 生成式结构速览（定义层口径，投影层只用到前两层）

```
太极  一段走势（有起点、有终点、未分方向与年龄）
        └ 原书：把每一个市场走势归类、登录幅度与期限（行 3014、3022、7285）
  ▼
两仪  幅度（空间）× 期限（时间）—— 双轨独立分布、取平均
        └ 原书行 7437「幅度几率 + 时间几率，再取两个几率的平均值」
        └ 【投影层只保留期限轨】
  ▼
四象  长期方向 × 中期方向 = 顺势多 / 回调跌 / 顺势空 / 回调弹
        └ 原书行 7283–7285 雷亚六类 = 2 背景态 + 4 类中期走势
        └ 【投影层只实现前两象，见 §4.6】
  ▼
八卦  长期 × 中期 × 短期 = 2³ = 8 种方向组合（结构位置全表）
        └ 原书行 7543、7547；全表见终极定义 §4.1 与本文件 §5.1
```

> 命名「两仪余寿」：余寿＝原书唯一方法名（平均剩余寿命 / life expectancy）；两仪＝原书第一刀（幅度／期限）。
> 不取「太极／混元」：那是未分之一，原书从已分之一的第一刀起。等价读法：四象各以分布中位点分老少，4×2 亦为八卦（`p_life=0.5` 即老少之界，原书行 7485）。

## §2 交易的生命过程（术语与动作一一对应）

```
        ┌─────────────────────────────────────────────┐
        │                                             │
        ▼                                             │
    ┌────────┐  突破箱顶   ┌──────────┐  破位   ┌──────┴──┐
    │  盘整   │ ─────────► │ 一波上涨中 │ ─────► │  盘整   │
    │ (无箱体) │            │ (wave活着) │        │ (无箱体) │
    └────────┘            └──────────┘        └─────────┘
         ▲                      │                    │
         │               箱体确立(走出一波)           │
         │                      ▼                    │
         └──────────────── 新箱体 ───────────────────┘
```

| 阶段 | 动作 | 术语 | 是否动钱 |
|---|---|---|---|
| 0 | 股价无方向晃 | 盘整 | ❌ 不下单 |
| 1 | 边界清楚、可识别区间 | 箱体（箱顶 / 箱底） | ❌ 只盯着 |
| 2 | 收盘突破箱顶 | **一波诞生 = 买入** | ✅ **买** |
| 3 | 上涨中，每天更新 | wavespan / 波幅 / 涨速 | ✅ 持有 |
| 4 | 每时每刻看历史分位 | 衰老度（rank） | ✅ 决定加/减 |
| 5 | 收盘跌破箱底 | 破位 = 卖出 | ✅ **卖** |
| 6 | 回到无方向 | 盘整（循环） | ❌ |

**核心约束**：箱顶（上轨）不随行情变，是「进」的门；箱底（下轨）随行情上移，是「出」的门。达瓦斯从不在盘整里下单，只在「新箱体确立 + 突破箱顶」那一刻买。

## §3 三套库的运转（月 / 周 / 日 分周期独立）

每只票，月/周/日三个周期各跑一遍**同一个状态机**（盘整→箱体→突破→一波→破位），各自产出一套波记录，**独立建库、独立排名、绝不混池**。

```
库（每只票三套，分周期，不混池）：
  月库 ── 主趋势的波记录：wavespan / 波幅 / 涨速 / 衰老度
  周库 ── 中级趋势的波记录：同上 + 「顺势段/回调段」标签   ← 解题核心
  日库 ── 短期波动的波记录：同上
```

**铁律（不混池）**：月波的 wavespan 中位 ≈ 几个月，日波 ≈ 几天，量级差几十倍。混池排名会让日波永远「极年轻」、月波永远「极老」，排名彻底失真。

## §4 核心：顺势段 / 回调段 分池概率统计

> **这是 lifespan 的解题关键**。全章展开。

### 4.1 标签判定（防前视）

给每个周波打「顺势段 / 回调段」标签，只用「那一刻已确定的月线方向」：

```
主趋势（月线）方向 = 月线波自己的状态（UP 波 = 涨，DOWN 波 = 跌）
  —— 纯靠月线箱体的突破/破位判定，不用均线、不用指数，与达瓦斯同源。

月线向上时：
  周线波向上 → 顺势段（做多这一段）
  周线波向下 → 回调段（避开这一段）

月线向下时：
  周线波向下 → 顺势段（A股不能做空 → 空仓观望）
  周线波向上 → 回调段（反弹，不碰）
```

**A 股单向做多 → 只在「月涨 + 周顺势」这个组合开多，其余一律观望。**

> **⚠️ 缺口（2026-11-08 审查）**：本判定**只看方向**、没有折返结构资格。原书明说「最困难部分是区分次级折返与逆趋势的小型走势」（行 3022），并要求折返幅度 33%–66% 且不破前一个中期低点。
> 补齐见 §4.6；**33%–66% 的具体数值属段 C 待填，不得现在定死**。

### 4.2 两个池子分开统计

| 池子 | 统计内容 | 回答的问题 |
|---|---|---|
| **顺势段池** | 历史所有「月涨+周涨」波的 wavespan / 波幅 / 涨速分布 | 涨势还能走多久 |
| **回调段池** | 历史所有「月涨+周跌」波的 wavespan / 波幅分布 | 跌势还要多久才结束 |

两个池子**独立排名**，衰老度各自算各自的，不合并。

### 4.3 历史规律（解题链）

**顺势段池 → 决定什么时候撤：**

```
当前处于顺势段，wavespan 已走 T 天
→ 查顺势段池：历史走过 T 天的顺势段，中位还能再走 X 天
→ 衰老度 rank = T 在顺势段池的分位
→ rank 低 = 顺势段年轻，继续持有/加仓
→ rank 高 = 顺势段快到头，准备在转回调前撤
```

**回调段池 → 决定什么时候再进：**

```
当前处于回调段，wavespan 已走 T 天
→ 查回调段池：历史走过 T 天的回调段，中位还要再跌 X 天
→ 当回调段衰老度够高（快到头）= 「回调即将结束、顺势段即将重启」的进场预兆
```

### 4.4 两个池子的切换 = A 股做多的完整节奏

```
顺势段（持有做多）──衰老度升高──► 预判转回调 ──► 减仓/离场
     ▲                                      │
     │                                      ▼
     │                              回调段（空仓等）
     │                                      │
     └──回调段衰老度够高（快结束）──◄─────────┘
                重新进场做多
```

> **哲学边界（2026-11-08 补）**：原书明说余寿「不预测确切转折点、只发警告、促使留意基本面变化」（行 3037、3039、7493），输出是连续仓位比例。
> 本节把预兆写成「减仓/离场」「进场预兆」是**投影层的动作化表述**，不是原书原义；§4.5 动作表更须遵守接入状态注的时序约束。

### 4.5 三判据速查

| 判据 | 顺势段衰老度 | 动作 |
|---|---|---|
| 年轻 | rank < 0.50 | 持有，可加仓 |
| 转老 | 0.50 ≤ rank < 0.75 | 停加仓，观察 |
| 已老 | 0.75 ≤ rank < 0.90 | 只减不加 |
| 极老 | rank ≥ 0.90 | 主动减半，余仓等破位再出 |

| 判据 | 回调段衰老度 | 动作 |
|---|---|---|
| 年轻 | rank < 0.50 | 继续空仓等 |
| 转老 | rank ≥ 0.50 | 关注进场窗口 |
| 极老 | rank ≥ 0.90 | 回调大概率近尾声，准备再进 |

> **接入状态注（用户 2026-11-08 裁定）**：上表「已老 / 极老」两档的减仓动作（对应 D13 ③④）

## §9 与 65 / 64 的关系（基础设施 + 决策闸门 双层）

lifespan 在重构计划里是**双层落点**，不是单点：

| 层 | 落点 | 性质 | 时机 |
|---|---|---|---|
| **基础设施层** | 65 阶段 0/1 | 建月/周/日三套库 + 顺势/回调分池统计，**零机时**（用现有 adj 数据），与 K1 并行 | **提前**（现在就能做） |
| **决策闸门层** | 65 **D13 臂**（阶段 3 装油门之后） | 寿命闸门进引擎：进场资格 rank<0.5 + 加仓资格 + 持仓衰老度调松紧 | **后置**（R24：正确物种上验证） |
