## 2. 🔁 初版口径错误的纠正

### 2.1 "主力通道未触发"是误读

- **初版错误**：称 main_fills=0 三年未触发。
- **事实**：main_fills = 3/1/5/2/3，主力通道通过 leg3（addon）开过火。
- **真正的事实**：**leg2（确认单，原著第二条买入）五年全 0**——这是规则层特性，且 M8.6 evo 的 leg2 也是 0（2014/2015/2016 全 0）。即"确认单在 A 股 2014-2018 从未触发"是两个版本共有的，**不是 M8.8 的问题，是 leg2 触发条件（新箱体突破+无持仓新入场）在快涨快跌节奏下样本稀少**。

### 2.2 M8.8 vs M8.6 收益对比口径不齐

- **M8.6 evo**：固定 probe 10%（每票 ~10% 名义）
- **M8.8**：单位制，熊猴 1U=2%、牛 2U=4%（2014-2018 大部分时间非牛 → 多数时候 2%/票）
- **仓位基数差约 5 倍** → 直接比收益/回撤不公平：
  - M8.8 收益低（2014: +26% vs +42%）← 仓位小 5 倍是主因
  - M8.8 回撤低（2014: -3.7% vs -14%）← 仓位小 5 倍是主因
- **公平对比看卡玛比**：M8.8 在 2014（7.18 vs 3.06）、2015（1.82 vs 1.63）风险调整后**优于** M8.6。2016 两者都负收益，M8.8 少亏少回撤双优。
- **结论**：M8.8 不是"牛市收益不及 M8.6"，而是"用更小仓位换更低回撤，风险调整后更优"。

### 2.3 2017 -0.94% 是设计特性不是失败

- docs/13 §2.3 **早在立项时就披露并接受**：2017 是分化蓝筹牛（少数蓝筹独涨、多数个股阴跌），宽度法反映"多数个股状态"→ 判熊猴 → 轻仓。
- 2017 日志实测：体制猴 166 行、牛 78 行（约 32% 天数判牛），主力预算大部分时间未启用。
- 现金底线 73.9%（五年最高）——系统诚实表达"分化行情本就该轻仓"。
- 这是达瓦斯"做多数个股箱体突破"策略在分化市的**固有代价**，不是 bug。

**M8.8 可以转正**，但需接受三个已知特性：
1. 2017 分化牛按设计轻仓（docs/13 §2.3 已披露）

3. 仓位保守（2% 单位制）→ 绝对收益低于满仓策略，但卡玛比更优、现金底线更厚

**若用户不接受特性 1（分化牛错过）** → 路径B：调宽度阈值（bull_thresh 0.55→0.45）重跑五年对照，属宪法级变更需拍板。
