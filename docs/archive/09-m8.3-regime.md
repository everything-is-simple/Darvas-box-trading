## 1. 定位与目标

把 M8.2 撮合器模拟出的成交数据，按**牛/熊/猴**市场体制切段，输出权益曲线/回撤/胜率/
暴露时间的 HTML 报告——为「大盘闸门要不要加」提供**证据**，不做主（PROMPT P4 附加纪律 3：
回放只给证据，大盘闸门属新规则，由用户拍板）。

## 2. 体制标注规则（核心决策 · 箱体法 · 禁摘樱桃）

**要求**：客观、事先、可复现——任何日期的体制只能用「该日期及之前」的数据判定，
禁止事后看结果挑窗口（樱桃挑选）。

**规则（箱体法，2026-10-19 用户拍板）**：用**达瓦斯箱体引擎**给 sh000001 上证指数标箱体，
复用判断个股的同一套工具（单一理论，零新概念、零额外调参）：

```
指数向上突破箱体（broken_up）   → 牛（上涨市场）
指数向下破位（broken_down）     → 熊（下跌市场）
箱体内（forming/confirmed）     → 猴（震荡）
```

突破/破位是**事件**（BrokenDate 当日判定，只用当日及之前数据）；事件后延续该方向，
直到反向事件。箱体参数与 boxscan 完全一致（box.volmult/box.volwindow/buy.premium/
MinBoxWidth），**不给指数单独调参**——判断市场与判断个股是同一个工具。

**为什么弃动量、改用箱体法（2026-10-19 用户点破）**：
- 动量法本质是「过去 N 日涨跌幅」的均线式指标，带着「窗口/阈值」这些达瓦斯原书里
  没有的东西，且对温和行情太迟钝（120 日对 2024 政策牛标不出牛）。
- 达瓦斯本人判断「上涨市场」看的就是**指数箱体突破创出新高**，不是均线/动量。
- 箱体法复用现有引擎、参数已校、与交易信号同源，彻底守住单一理论。

**实测效果**（sh000001，2024-01~2026-10，673 日）：6 个事件——
2024-02-05 熊（年初暴跌）、**2024-09-26 牛（政策牛，精确捕捉）**、2025-04-07 熊（关税
暴跌）、2026 年 3 次熊破位（高位震荡回调）。动量法捕捉不到的政策牛，箱体法一击即中。

**已知代价**：指数波动小，箱体识别 invalid 偏多（34 箱体中 27 个 invalid），但不影响
牛熊事件（broken_up/broken_down 独立判定）。指数是否需单独调箱体参数，留作观察。

## 3. 分体制聚合统计口径

- **切段**：权益曲线按「连续同体制日」切成段，每段统计天数/收益率/最大回撤/成交笔数/
  胜负/暴露天数。
- **收益率**：段末权益 / 段首权益 - 1（复利合并到体制汇总）。
- **最大回撤**：段内 equity_snapshot.drawdown 最负值。
- **成交归因**：fill 按 fill.date 归入当日体制。
- **胜率**：closed position 按 close_date 归因，realized_pnl > 0 为胜。
- **暴露时间**：段内有持仓（market_value > 0）的天数占比。

---

## 4. 报告结构（HTML，零外部 JS）

1. 总览：交易日数、起点权益、总收益率、最大回撤。
2. 分体制汇总表：牛/熊/猴各一行（段数/天数/收益率/最大回撤/成交/胜率/暴露时间）。
3. 分段明细表：每个连续同体制段一行。
4. 权益曲线：SVG 散点折线，点色=当日体制（红牛/绿熊/黄猴，中国涨红跌绿惯例）。

## 5. 已知限制与后续

- 代理选择：只用 sh000001，未考虑个股分化（结构性行情下指数可能失真）。后续可加
  深证成指/全A等权，但初版单一代理够「大盘闸门」决策。
- 数据覆盖：perf_test.db 仅 2024-01 起（2.7 年）。跑 2014-2026 全历史需先从 TDX 灌
  全量多年数据（另一任务）。
- 指数箱体参数：当前与个股同参（MinBoxWidth 5% 等），指数 invalid 偏多；是否单独调参
  留观察，不提前引入「调参焦虑」。
