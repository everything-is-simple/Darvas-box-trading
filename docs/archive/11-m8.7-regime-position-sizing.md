# M8.7 仓位随市场牛熊猴缩放（达瓦斯「众人恐慌我更恐慌」落地）

> 状态：已立项（2026-10-20，用户拍板）
> 类型：策略规则变更（非参数微调），观察期内 scratch 研究，验证有效后再谈上线

## 一、立项依据

达瓦斯原书第一道工序（line 2690 读者问答）：15分钟扫行情表**第一步就是看
「道琼斯工业指数表示的市场整体走势」**，其次才选强势行业/个股。即「看大盘定基调」。

《简简单单做股票》（line 3666）：仓位规则的目的「让你在**盈利的时候仓位保持在重仓状态**」，
反对「跌势重仓、升势轻仓毫无章法」。

两书方向一致（升势重仓、跌势轻仓、看大盘定基调），但**均未给出牛熊猴→仓位的量化数字**。
本项目将其显式化为可回测的规则——符合系统「单一事实源、参数显式化」原则。

用户核心表述：达瓦斯最高原则 =「众人恐慌我更恐慌，众人贪婪我更贪婪」，
始终保持冷静，随市场变化缩放仓位。

## 二、规则定义

### 2.1 单一指数晴雨表（2026-10-20 用户拍板简化）

| 项 | 值 |
|----|----|
| 晴雨表指数 | **上证指数 sh000001（单一指数）** |
| 标注规则 | 复用 `regime.LabelBoxes`（箱体法）：向上突破箱体=牛、向下破位=熊、箱体内=猴 |
| 无数据降级 | 上证指数在回测日无数据 → 判猴 range（中性仓位） |

> 历史：初版用四指数（上证+深成+创业板+科创50）多数投票，用户拍板放弃——只为验证
> 达瓦斯策略，不做复杂化，晴雨表只看上证指数一个。

### 2.2 仓位系数（用户拍板）

| 市场状态 | 仓位系数 | 语义 |
|---------|---------|------|
| 牛 bull | **2.0** | 众人贪婪我更贪婪 |
| 猴 range | **0.5** | 震荡中性，轻仓试单等方向 |
| 熊 bear | **0.2** | 众人恐慌我更恐慌，大幅缩仓（留小仓捕捉个股强势，对齐达瓦斯1957罗瑞拉德） |

### 2.3 应用方式

planner.Build 计算仓位时，把仓位系数乘到**风险预算**上：
`effectiveRiskPct = riskPct × regimeMultiplier(当日市场状态)`。

- 乘在风险公式的 riskPct 上（leg1/leg23），使试探仓、加码规模整体随市缩放；
- 加码后的单股上限（risk.maxpos）**也乘系数**（牛市允许更大单股仓位）；
- 止损规则不变（达瓦斯纪律：止损只升不降，与仓位无关）。

## 三、关键实现点

1. **盘中可用**：regime 现为「事后分析」函数。需新增 `regime.ClassifyDate(ctx, st, date)`
   实时标注接口——读上证指数至 date 的日线，LabelBoxes 标牛/熊/猴 → Regime。
   （复用同一套 box 引擎 + 参数，单一理论；只用 date 及之前数据，零未来信息。）

2. **接入点**：`planner.Build`（internal/planner/planner.go:43）在取 equity 后、
   构造订单前，调用 ClassifyDate 得当日 Regime，算 multiplier 传入 buyOrder。

3. **参数新增**（migration 0009）：
   - `regime.mult.bull = 2.0`
   - `regime.mult.range = 0.5`
   - `regime.mult.bear = 0.2`
   - `regime.indices = "sh000001"`（单一上证指数）

4. **同步**：contract.go 若有改动 + docs/00 §4.1 + docs/01 §6 + docs/04 参数表同 commit 同步。
