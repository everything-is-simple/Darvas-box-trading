## 实验一：大赢家加仓 A 类分析（零成本，先做）

> ✅ **已收官（2026-11-03）**：无 edge，坐实「均等首买 + 不加码」，关闭话题，不立项 B 类。
> 详见 `docs/experiments/e17_bigwinner_addon_a_report.md`。
> 结论：54 笔大赢家（baseA 新基线），MFE 随再突破次数单调升（71%→85%→87%）是「涨得多→持有久→突破多」
> 的幸存者偏差内生性；换成落袋净利检验，三带间 p=0.83~0.93 完全无差异，
> 且每笔净利中位数随次数下降（14,939→12,248→11,500）。加仓无概率依据。

**要回答的问题**：牛市仓位打不满、赚不了大钱，是不是因为「均等首买 + 一律不加码」？
能不能在连续突破时安全加仓？

**数据来源（只读，不重算不改回测器）**：
- 14 年回测库 `var/bt/base/bt_baseA_<year>.db`（2005–2018，新基线阶梯制）
- 大赢家口径：**MFE > 50%** 的已平仓持仓（MFE = 持仓期最高价/成本 − 1，复刻 e17_giveback）
- 突破信号密度：持仓期内 `box.broken_date` 落在 [opened_date, closed_date] 的**再突破次数 / 持有天数**
  （box 表的 broken_date 才是真实突破，signal 表 stage=watching 只是观察态不可用）

**统计口径（严格复刻 docs/29 §647）**：
1. 取 14 年全部大赢家（MFE>50%），每笔算**突破信号密度** =
   持有期内该 code 被突破的 box 数（`box.broken_date ∈ [opened, closed]`）/ 持有天数。
2. 分三带「稀疏 / 中等 / 密集」（分带切点预设，禁按结果挪），
   看各带的 **MFE（后续涨幅）与最终 realized_pnl** 分布。
3. 每带必报：笔数 n、MFE 中位数、每笔净利中位数、剔除前三净利、
   胜率、保本胜率、利润集中度。

**判定门槛（docs/29 §八）**：
- 若「密集带」MFE / 每笔净利**显著**高于稀疏带（且剔除前三后仍成立）→
  「连续突破」本身是更强做多信号，加仓有概率依据 → 立项 B 类（恢复加仓逻辑 + 回测）。
- 若各带差异落在噪声内 → 加仓无 edge，**彻底坐实「不加码」，关闭此话题**。

**注意（docs/29 §653–657）**：与「量化时代不需要金字塔」的旧定调表面冲突，
但那次的依据是「A 股一加就是顶」的**叙事**，非概率统计。本实验用分布重新裁决，
禁止凭直觉直接改代码。

**产出**：
- `scripts/e17_bigwinner_addon_a.py`（生成器，只读回测库）
- `docs/experiments/e17_bigwinner_addon_a_{report.html,report.md,data.json}`
